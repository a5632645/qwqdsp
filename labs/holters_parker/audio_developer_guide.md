## 一、音频开发为什么要关注 Holters–Parker 算法？

在音频插件、合成器、采样器与重采样引擎中，**采样率转换（SRC, Sample Rate Conversion）** 是最基础但也最消耗性能的组件。

### 1.1 传统多相 FIR 重采样的痛点
工业界标准重采样库（如 `libsamplerate` / `soxr` / 窗函数 Sinc 插值）绝大多数采用**多相 FIR 滤波器组（Polyphase FIR）**。在固定整数倍（如 44.1k $\to$ 88.2k）时，多相 FIR 表现极佳；但一旦遇到以下场景，传统 FIR 就会遇到瓶颈：

1. **变采样率 / 调制场景（BBD 模拟、磁带颤音、实时变调 Pitch Shifting）**：
   比率随时间平滑变化时，多相 FIR 必须在连续相位的多相分支之间频繁插值或切换，容易引发调制失真和高频相位调制噪声。
2. **大延迟与前置缓冲**：
   高质量的急剧截止 FIR 通常需要几十到上百个抽头，引入明显的群延迟（对于实时吉他效果器、低延迟监听往往无法接受）。
3. **计算与内存开销**：
   高品质非整数比率要求庞大的 FIR 系数表，占用大量 L1/L2 缓存。

### 1.2 Holters–Parker 算法：破局思路
在 DAFx-18 论文 *A Combined Model for a Bucket Brigade Device and its Input and Output Filters* 中，Martin Holters 与 Julian D. Parker 提出了一种令人眼前一亮的全新方案：

**“与其设计昂贵的多相 FIR，不如直接把模拟电路的低通滤波器（如连续时间模拟椭圆滤波器）通过改进的冲激不变变换（Modified Impulse-Invariant Transform）离散化为一组单极点复数子系统，直接在任意连续时间点采样取值！”**

```
       ┌────────────────────────┐
x[k] ──► 单极点复数状态机 (递归递推) ├─► 在任意分数时刻 d 直接求值 ──► y[n]
       └────────────────────────┘      y(n) = Σ Re( X_m · exp(λ_m · d) )
```

### 1.3 相比多相 FIR 的降维打击优势

| 维度 | 传统多相 FIR (Polyphase FIR) | Holters–Parker (IIR 连续态重采样) |
| :--- | :--- | :--- |
| **计算复杂度** | 随阻带深度与过渡带急剧变陡，抽头数可达 $64 \sim 512+$ | 复杂度只与模拟极点数有关：**$O(M)$，通常仅 11~31 个一阶节点**，完全与比率无关！ |
| **前置群延迟** | 几十到上百样点（线性相位一半长度） | **极小物理因果延迟**（无前置 FIR 缓冲，输入即刻驱动输出） |
| **动态变比率** | 复杂的分支插值，易引入调制瞬变噪声 | **天然支持任意分数时间采样**，时间步长 $t$ 可连续变化，零跳变 |
| **应用扩展** | 仅做重采样 | 该单极点状态模型与抗混叠波形合成（BLEP / PolyBLEP）天然共用底层架构 |

## 二、算法核心数学模型：连续冲激不变变换与状态机

很多开发者看到“冲激不变”、“连续域重构”会觉得数学深奥，其实它的离散实现极度清爽优美。

### 2.1 连续冲激串假想
将输入序列 $x[k]$（采样周期 $T=1$）视为连续时间上的理想加权冲激串：

$$x(t) = \sum_{k} x[k] \cdot \delta(t - k)$$

### 2.2 模拟低通原型的部分分式分解
选取一个连续时间的稳定严格真低通滤波器 $H(s)$（如 25 阶模拟椭圆低通）。通过部分分式展开（Partial Fraction Expansion）：

$$H(s) = \sum_{m=1}^{M} \frac{r_m}{s - p_m}$$

其连续时间冲激响应就是一组指数衰减的叠加：

$$h(t) = \sum_{m=1}^{M} r_m e^{p_m t} \quad (t \ge 0)$$

### 2.3 状态机更新（整数拍输入推进）
对每个复数极点 $p_m$，定义单极点状态 $X_m$。每到来一个输入样本 $x[k]$，状态机沿输入时间轴递推一次：

$$\bar{p}_m = e^{p_m} \quad (\text{单位步长衰减因子})$$

$$X_m[l] = \bar{p}_m \cdot X_m[l-1] + c_m \cdot x[l]$$

其中 $c_m$ 为注入系数（与留数 $r_m$ 相关）。

### 2.4 任意未来分数时刻的瞬时求值
现在，假设下一个输出样本 $y[n]$ 落在连续时间位置 $t = l + d$（其中 $l$ 是已处理的最后一个输入样本下标，$d \in [0, 1)$ 是**小数时间偏移**）。

无需任何 Sinc 卷积！无需多相查表插值！$y[n]$ 的数值直接就是当前状态向前漂移 $d$ 时间后的精确值：

$$y(l + d) = \sum_{m} \text{Re} \left\{ X_m[l] \cdot \bar{p}_m^d \right\}$$

由于共轭对成对出现，工程上只存上半平面的单侧复数极点，留数乘以 2 并取实部即可。

## 三、核心避坑一：开源 NonIntegerSRC 的致命接线 Bug

在 GitHub 上，`NonIntegerSRC`（Jatin Chowdhury 开发，GPLv3）常被很多音频开发者用作 Holters–Parker 论文的参考代码。它宣称“比 libsamplerate 快 10~40 倍”。

然而，`qwqdsp/labs/holters_parker/NonIntegerSRC_notes.md` 与复现实验给出了**触目惊心的实测真相**：

### 3.1 致命的断线 Bug：状态被更新却从未被读取
在 `NonIntegerSRC` 的主活动代码分支中：
```cpp
// NonIntegerSRC 内部数据流伪代码
x = p_bar * x + acc;        // 每一拍正确递推了状态 x
out = y_old + Re(acc);     // ！！！注意这里：输出用的是累加器 acc，x 根本没接进输出！
```
- 状态变量 `x` 在循环中不断计算，但**从未被用于生成输出**；
- 稳态项 `calc_h0()` 虽然写好了，但**从未被调用**；
- 整个输出实质上退化成了：**零阶保持（ZOH）加上一个微弱的数值修正**。

### 3.2 实测数据：完全丧失抗混叠能力
运行 `python noninteger_src_repro.py` 进行降采样测试（$96\text{ kHz} \to 48\text{ kHz}$，输入 $30\text{ kHz}$ 单音，理论上必须彻底滤除，否则将混叠折回至 $18\text{ kHz}$）：

| 实现版本 | 18 kHz 混叠泄漏幅度（满幅 1.0） | 结论 |
| :--- | :--- | :--- |
| **NonIntegerSRC 活动分支（as-coded）** | **1.0057** | **完全没有滤波！混叠 100% 穿透** |
| 朴素零阶保持 ZOH（对照基准） | 1.0000 | 与 ZOH 几乎完全一样 |
| **qwqdsp 的 `ResampleIIR`（正确接线）** | **0.0002（-74 dB）** | **精准衰减滤除** |

### 3.3 经验警示
1. **不要直接照抄 `NonIntegerSRC` 的滤波运算代码**；
2. 其有价值的部分仅在于：验证了论文 Table 1 的极点参数数值，以及提供了一种利用 SSE `__m128` 一次并行计算 4 个一阶复滤波器的 SIMD 思路。

## 四、双真原型与直接项 $d$：能实现吗？怎么实现？

在很多数字信号处理讨论中，人们常认为“冲激不变法只能处理分母阶数大于分子的严格真原型，含直接项（分子分母同阶）的双真原型在数学上无法采样”。

实验室在 `algorithm.md` §9 与 `direct_term_study.py`（尤其是 `step4()`）中进行了深入推导与数值验证：**在 Holters–Parker 的狄拉克模型下，含直接项的滤波器不仅完全可以实现，而且能够精确闭式实现，完全不需要额外的连续插值器！**

### 4.1 什么是直接项 $d$？
当低通原型的分子多项式阶数等于分母多项式阶数时（$H(s) = B(s)/A(s), \deg(B) = \deg(A)$），例如**未经修正的偶数阶模拟椭圆低通**：
部分分式展开会出现一个常数直通项 $d$：

$$H(s) = \sum_{m} \frac{r_m}{s - p_m} + d, \quad d = \lim_{s \to \infty} H(s) = \frac{b_0}{a_0} \ne 0$$

对于阻带深度为 $r_s$ 的偶数阶椭圆滤波器，直接项大小恰好等于阻带波纹电平：

$$d = 10^{-r_s / 20}$$

（例如 $r_s = 40\text{ dB}$ 时 $d = 0.01$；$r_s = 80\text{ dB}$ 时 $d = 10^{-4}$）。

### 4.2 含直接项的滤波器怎么精确实现？（狄拉克模型下的命中点叠加）
将连续冲激响应写出：

$$h(t) = h_p(t) + d \cdot \delta(t), \quad h_p(t) = \sum r_m e^{p_m t}$$

很多开发者卡在“$\delta(t)$ 怎么采样”的问题上。但请注意 Holters–Parker 算法的基本假设：**输入信号被建模为狄拉克冲激串 $x(t) = \sum_k x[k] T \delta(t - kT)$**。
直接项对输出的贡献为：

$$y_d(t) = d \cdot x(t) = d \sum_k x[k] T \delta(t - kT)$$

这意味着：**直接项在时间轴上的物理支撑仅存在于输入时间栅格点上**！

假设输入采样率与输出采样率为既约有理比 $f_{in} : f_{out} = p : q$（即输出时间步进 $T_{out} = \frac{p}{q} T_{in}$），输出样本时刻为 $t_n = n \cdot \frac{p}{q}$：

1. **当且仅当 $q$ 整除 $n$ 时**（即输出序号为 $q$ 的整数倍 $n = q \cdot k$），输出时刻 $t_{qk} = p \cdot k$ **精确命中** 输入时刻栅格点。此时直接项的冲激贡献在离散化后精确为：
   $$y_d[q \cdot k] = d \cdot x[p \cdot k]$$
2. **在其所有非命中时刻**（$q \nmid n$），输出时刻落在两个输入栅格之间，冲激串在这些时刻的理论值就是 $0$。

#### 精确实现三步法（`direct_term_study.py:step4()`）

```
步骤 1：状态迭代计算严格真部分 H_p(s)
   X_m ← X_m · exp(λ_m) + c_m · x[k]
   y_nod[n] = Σ Re( X_m · exp(λ_m · d_n) )

步骤 2：命中点叠加直接项（每 q 个输出命中一次）
   y_fix[n] = y_nod[n]
   for n = 0, q, 2q, 3q, ...:
       k = n / q
       y_fix[n] += d * x[p * k]

步骤 3：输出 y_fix 即为完整的含直接项输出！
```

**实测验证数据**（$N=6, r_p=0.1\text{ dB}, r_s=80\text{ dB}, d=10^{-4}$，采样率 $20\text{ Hz} \to 8\text{ Hz}$，既约比 $p:q = 5:2$）：
- 基音增益与解析连续原型响应 $|H(j\omega)|$ 吻合到 **$0.06\text{ dB}$**；
- 命中点直接项在输出频谱上的贡献严格等于理论解析值 $d/q = -86.0\text{ dB}$；
- 该算法完全因果、无前置延迟、且**不需要任何连续插值器**。

### 4.3 为什么工程上依然优先推荐严格真原型（Möbius 修正）？
既然含直接项完全可以精确实现，为什么很多工业库依然倾向于消除 $d$？

1. **阻带泄漏与镜像折射**：
   直接项本质上是 $|H(j\infty)| = d$。如果滤波器阻带要求不高（如 $r_s = 40\text{ dB}$ 时 $d=0.01$），直接项会以 $-40\text{ dB}$ 的电平将输入镜像泄漏到输出带内；
2. **无理比率或动态调制下的判定复杂度**：
   命中判定依赖既约整数比 $p:q$（必须用整数计数器累加，不能用浮点加法以防舍入漂移）。在平滑调速（如动态变比率）场景下，$p:q$ 频繁变动甚至非有理，追踪命中点相对繁琐；
3. **工程上的极致解法：Möbius 变换的偶数阶修正**：
   - **奇数阶椭圆**：天然满足严格真（$d \equiv 0$）；
   - **偶数阶椭圆**：在设计原型阶段应用基于 Möbius 变换的修正（`IIRDesign::Elliptic(..., even_order_modify = true)`）：
     $$s'^2 = \frac{(1 - k^2 \text{sn}_L^2)(s^2 + \text{sn}_L^2)}{\text{cn}_L^2 (1 + k^2 \text{sn}_L^2 s^2)}$$
     该公式将最高传输零点严格搬移至无限远处 $\infty$，使得 $d \equiv 0$，同时完美保持通带与阻带的双等波纹特性。
   - **收益**：既消除了直接项的高频泄漏，又完全免去了实时代码中判断命中点和叠加直接项的逻辑分支，让实时处理代码更加精简紧凑。

## 五、核心避坑三：参数缩放与增益的常见认知误区

在将连续原型应用到不同采样率和截止频率时，许多开发者会由于直觉产生严重错误。

### 5.1 误区一：换截止频率时，直接项 $d$ 也跟着缩放？
**答案：绝对不要缩放 $d$！**
将原型频率轴缩放 $k$ 倍（$H_{\text{new}}(s) = H(s/k)$），代入部分分式：

$$H(s/k) = \sum \frac{r_m}{s/k - p_m} + d = \sum \frac{k \cdot r_m}{s - k \cdot p_m} + d$$

| 参数项 | 截止缩放规则 | 说明 |
| :--- | :--- | :--- |
| **极点 $p_m$** | $\times k$ | 极点随带宽等比例移动 |
| **留数 $r_m$** | $\times k$ | 留数必须与极点同乘 $k$，否则直流增益会改变 |
| **直接项 $d$** | **严格保持不变** | 因为 $s \to \infty$ 时极限始终为 $d$ |

如果误将 $d$ 也乘以 $k$，高频阻带电平就会被放大 $k$ 倍，彻底破坏滤波器的衰减特性。

### 5.2 误区二：输入样本需要乘以“上采样倍数 $L$”吗？
**答案：绝对不需要！**
在传统离散多速率信号处理中，插零上采样后需要补 $L$ 倍的直流增益（或输入乘 $L$）。
但 Holters–Parker 模型是**直接在连续时间上做冲激强度卷积**：
在归一化 $T=1$ 下，每个输入样本的冲激权重就是信号自身值 $x[k]$。实测表明（见 `algorithm.md` §9.5）：无论从 48k 升至 96k（$L=2$）还是升至 192k（$L=4$），输入直接注入 $c_m \cdot x[k]$ 时，输出通带增益严格恒等于 1.0000。

## 六、工程落地精要与误差预算（LUT / 精度 / 漂移）

在 `qwqdsp/include/qwqdsp/fx/elliptic_blep.hpp` 的实际生产级 C++ 实现中，有几个关键工程考量：

### 6.1 分数衰减项 $\bar{p}_m^d$ 的查找表（LUT）设计
在每个输出采样点计算 $\bar{p}_m^d = \exp(p_m \cdot d)$ 时，若每次都调用标准库的 `std::exp`，会导致 CPU 算力大幅消耗。

`EllipticBlep` 将小数间隔 $d \in [0, 1)$ 划分为 $N$ 份（默认 $N = 128$），预先计算好表格：
- 节点处直接查表；
- 节点之间采用一次线性插值（Lerp）。

**误差预算实测**：
查表插值误差呈现严格的二阶收敛（$\sim |p|^2 / (8N^2)$）：
- $N=8$ 档：误差 $-37\text{ dB}$；
- $N=32$ 档：误差 $-61\text{ dB}$；
- **$N=128$ 档：误差达到 $-85\text{ dB}$（$5.4 \times 10^{-5}$）**；
- 结论：对于 32 位浮点（float32）音频流，**128 步进的 LUT 精度已远超出浮点本身的底噪**，无需更大开销。

### 6.2 Float32 与 Double 的选择考量
单极点状态递推 $X \leftarrow \bar{p} X + c x$ 在时间轴上是无限递归的。
实测长音频（16384 样本）下的误差累积：
- **`float` 模式**：由于单精度每次极点旋转相位的舍入误差积累，漂移误差随时间呈现线性累加，最大误差约 $1.9 \times 10^{-3}$（主要体现为微小的微相移，幅度误差小于 $10^{-6}$）；
- **`double` 模式**：全频段与理论解析值最大误差仅 **$6.4 \times 10^{-15}$**（极限机器精度）。
- **选型建议**：实时吉他效果器/合成器推荐 `float` 以最大化利用 SIMD；高精度离线母带重采样器推荐传入 `double`。

## 七、音频场景选型与仓库代码对照

### 7.1 算法选型全景图

```
你的音频开发任务是什么？
 ├─► 实时变采样率 / 调制场景 (BBD 延迟、Chorus/Flanger、磁带机模拟、动态移频)
 │    └─► 【强烈推荐】Holters–Parker 重采样 (`ResampleIIR` / `EllipticBlep`)
 │         ├─ 优势：无多相 FIR 切换爆音，零前置群延迟，极低算力开销
 │         └─ 核心注意：确保低通原型为奇数阶或偶数阶 Möbius 修正版 (严格真)
 │
 ├─► 固定倍率母带级转码 (如 44.1 kHz 转换为 96 kHz 离线高精度导出)
 │    └─► 推荐线性相位多相 FIR 或 Holters–Parker double 模式 (`BestCoeffs<double>`)
 │
 └─► 虚拟模拟（VA）合成器的抗混叠脉冲生成
      └─► 直接复用 `EllipticBlep` 的 `Add()` 与冲激不变核，做极低延迟的带限波形合成 (BLEP)
```

## 八、总结与速记口诀

1. **Holters–Parker 算状态不插值，单极点复数递推 $O(M)$ 算力超省。**
2. **严防 NonIntegerSRC 伪参考，断线 Bug 等同零阶保持不抗混叠。**
3. **含直接项 $d$ 可用命中点叠加精确实现；工程上用 Möbius 修正消除 $d$ 更纯净省事。**
4. **频率缩放极点留数同乘 $k$ 但 $d$ 保持不变；输入信号绝不乘上采样倍数 $L$。**
5. **分数查表 128 档精度足够 $-85\text{ dB}$，高保真母带选 double 消除相位漂移。**
