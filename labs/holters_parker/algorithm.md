# Holters–Parker 重采样：算法描述

本文档描述论文 *A Combined Model for a Bucket Brigade Device and its Input and Output Filters*
(DAFx-18, <https://www.dafx.de/paper-archive/2018/papers/DAFx2018_paper_12.pdf>) §3.1 的「输入滤波器 / Dirac 形式」，
也就是 `qwqdsp/fx/resample_iir.hpp` + `elliptic_blep.hpp` 实现的算法。论文的另一半（§3.2，输出滤波器 /
矩形保持形式）见 §8。

## 1. 记号

| 符号 | 含义 |
|---|---|
| `x[k]` | 输入样本，采样率 `f_in`，周期 `T = 1/f_in` |
| `y[n]` | 输出样本，采样率 `f_out`，周期 `T_out = 1/f_out` |
| `ρ = f_in/f_out` | 每个输出样本对应的输入样本数（`>1` 抽取，`<1` 插值） |
| `p_m, r_m` | 模拟原型 `H(s)` 的第 `m` 个简单极点与留数（复共轭成对） |
| `p̄_m = e^{p_m T}` | 极点经冲激不变映射后的每样本衰减/旋转 |

**归一化**：实现取 `T = 1`（输入周期为一个单位），一切频率都是 rad/sample。

## 2. 模型

离散信号被当作连续时间上的加权冲激串（"上采样到无穷"的等价说法）：

```
x(t) = Σ_k x[k]·T·δ(t − kT)                                        (1)
```

乘 `T` 是为了让 `∫x(t)dt = Σ_k x[k]`（把样本值变成冲激强度）。

滤波器取**严格真、极点简单**的有理函数，部分分式展开：

```
H(s) = Σ_m r_m/(s − p_m)                                           (2)
h(t) = Σ_m r_m e^{p_m t}   (t ≥ 0)，  0   (t < 0)                  (3)
```

重建出的连续信号与输出：

```
y(t) = Σ_{k: kT ≤ t} T·x[k]·h(t − kT)
     = Σ_m r_m · T · Σ_{k: kT ≤ t} x[k] · e^{p_m(t−kT)}             (4)
y[n] = y(n·T_out)                                                  (5)
```

**这就是全部**：滤波（用 `H` 抗混叠/抗镜像）+ 在新栅格上取样，两步合一。

## 3. 状态与递推

第 `m` 支路在整数输入时刻 `l` 的状态：

```
X_m(l) = T · Σ_{k ≤ l} x[k] · p̄_m^{l−k}                            (6)
```

每来一个输入样本更新一次：

```
X_m(l) = p̄_m · X_m(l−1) + T·x[l]        X_m(−1) = 0                (7)
```

**这个状态是充分统计量**：任意未来时刻 `t = (l+d)T`（`d ∈ [0,1)`）的输出可直接由它给出，

```
y((l+d)T) = Σ_m Re{ r_m · p̄_m^d · X_m(l) }                          (8)
```

验证（把 (6) 代入）：`p̄_m^d·X_m(l) = T Σ_{k≤l} x[k] e^{p_m(t−kT)}`，再乘 `r_m`、对 `m` 求和即得 (4)。

> 取 `Re` 需要系数表的约定：**共轭极点对只存一支、留数乘 2**（论文 §3.3 的 `β = 2T|r|` 同理）。
> 因此滤波器状态是复数的。

## 4. 算法（伪代码）

```
l = 0; d = 0                                  # 当前时刻 t = l + d，单位 = 输入周期
for n = 0, 1, 2, ...:
    y[n] = Σ_m Re{ r_m · p̄_m^d · X_m(l) }      # (8)：分数位置直接取值
    t   += f_in / f_out                       # 下一个输出时刻
    l'   = floor(t);  d = t − l'
    for k = l+1 .. l':                        # (7)：把状态推过中间那些输入样本
        X  ← p̄ ∘ X + c ∘ x[k]                 # ∘ = 逐支路
    l = l'
```

起点 `t = 0`，即输出与输入第 0 个样本对齐，**无前置延迟/缓冲**。

## 5. 滤波器怎么选（截止频率的唯一约束）

`y[n]` 是对 `y(t)` 的采样，而 `y(t)` 的频谱是输入谱以 `f_in` 为周期重复、再被 `H_a(jω)` 整形
（式 (4) 的 `Σ_k δ(t−kT)`）。要不产生混叠/镜像：

- **通带** `[0, min(f_in,f_out)/2)` 内 `|H_a| ≈` 期望响应（通常 1）；
- **从 `min(f_in,f_out)/2` 起**迅速衰减到规格要求（如 −80 dB）。

两个方向分别看：

- `f_out < f_in`（抽取）：输入在 `[f_out/2, f_in/2]` 的内容会折回输出带 → 必须由 `H_a` 杀掉；
- `f_out > f_in`（插值）：冲激串的镜像落在 `f_in − f`（`f < f_in/2`），它 `< f_in < f_out/2`，
  **不折叠、直接落在输出带内** → 也必须杀掉。

故截止点取 `min(f_in,f_out)/2`。注意这是**连续域**的频率约束 —— 见 §7。

三个比率的输入/输出频谱图见 `output/spectrum_*.png`（脚本 `plot_resample_spectrum.py`，用仓库真实的
`BestCoeffs`）：抽取方向 `d=0` 时带外输入被压到 −87 dB；插值方向镜频被压到 −70 dB 以下；
而 `d=1e-2` 的直接项会让 30 kHz 以 −40 dB 折到 18 kHz、让 20 kHz 的镜像以 −45 dB 出现在 28 kHz。

## 6. 实现要点（对照 `elliptic_blep.hpp`）

| 事项 | 做法 |
|---|---|
| 复数状态 | 直接存 `std::complex` 数组，不做论文 §3.3 的实系数二阶合并；式 (8) 的 `Re` 在求和处取 |
| `p̄_m^d` | `d ∈ [0,1)`，查表 + 线性插值：`partial_step_poles_[s][i] = exp((s/N)·p_i)`（`N = kPartialSteps`）；`Step()` 用第 `N` 项（精确的 `p̄`），`Get(d)` 在相邻项间插值 |
| 系数量纲 | 归一化 `T = 1`：式 (7) 的 `T·x[l]` 变成 `c_m·x[k]`，其中 `c_m = r_m × 频率缩放`（`T` 已并进缩放），即 `impluse_coeffs_`；式 (8) 的 `p̄_m^d` 即 LUT |
| 相位簿记 | `phase_inc_ = f_in/f_out`，运行量 `t` 拆成整数 `l` 与分数 `d`；输出 `n` 对应 `t = n·f_in/f_out` |
| 滤波器设计 | 仓库用椭圆低通：`resample_coeffs.h` 的 `Fast/Median/BestCoeffs`（11/25/31 阶，截止/阻带由 `fpass/fstop` 给出），由 `notebooks/holters_parker_coeff.ipynb` 用 `scipy.signal.ellip(analog=True)` + `residue` 生成 |
| 截止缩放 | `SetCutoffByFpass(min(target_fs, source_fs)/2, source_fs)` → 把原型所有 `p_m, r_m` 同乘 `scale = ω_c/fpass`（模拟域频率缩放） |

## 7. 代价、精度与性质

- **代价 O(M) 每样本，与比率无关**：每个输出样本做 `⌊f_in/f_out⌋` 次式 (7)（每支路一次乘加）
  + 一次式 (8)（`M` 次复乘 + 取实求和）。对比：分数延迟 FIR 的抽头数随过渡带变窄而增长。
- **用的是连续原型 `H_a(jω)`，不是离散的 `H(e^{jω})`**：`p̄ = e^{pT}` 是冲激不变映射，
  放到 digital 域看会把模拟阻带折回带内；但算法从不在 digital 域用它，只在连续域取任意时刻的值。
  所以通带波纹、群延迟（椭圆 IIR 非线性相位）就是 `H_a` 的，且没有额外的采样率相关滤波引入的调制失真。
- **LUT 插值误差** ~ `|p_m|²/(8N²)`，二阶收敛；实测 `N=128` → 5.4e-5（−85 dB）。
- **浮点累积**：状态递推的舍入随样本数线性累积；实测 float32、16382 样本 ~2e-3 峰值，double → 1e-15。
  `TSample` 是模板参数，需要更高精度直接换 `double`。
- **映射平移不变**：输入移 1 个样本 ⟺ 输出移 `f_in/f_out` 个样本（单位冲激输入的输出
  逐点等于 `h_a(n·f_in/f_out)`，已验证到 1e-16）。

## 8. 论文的另一半（§3.2，输出滤波器 / 矩形保持）

BBD 的**输出**是采样保持（矩形脉冲）而非冲激，所以论文对输出侧改用阶跃分解
（`n` 取奇数，`t_n` 为 BBD 输出跳变时刻）：

```
Δ(n)        = y_BBD(t_n) − y_BBD(t_{n−1})                                   (9)
x_out,m(k)  = p̄_out,m · x_out,m(k−1) + Σ_{t_n ∈ ((k−1)T, kT]} g_out,m(d_n)·Δ(n)   (10)
g_out,m(d_n)= (r_m/p_m) · p̄_out,m^{1−d_n}                                     (11)
y(k)        = H_0 · y_BBD,old + Σ_m x_out,m(k),   H_0 = −Σ_m r_m/p_m         (12)
```

与 §3.1 的差别只在两处：**输入侧怎么进入滤波器**（Dirac 权重 `T·x[k]` vs 阶跃权重 `Δ(n)`），
以及**哪一侧在变速率**（§3.1 在输出侧任取时刻，§3.2 在输出侧的固定栅格上累加输入侧的跳变）。
`H_0` 是保持值的稳态增益。

## 9. 原型为什么必须严格真（直接项 `d`）

部分分式里可能多出一个常数项：

```
H(s) = Σ_m r_m/(s − p_m) + d          （deg(num) = deg(den) 时，如偶数阶椭圆）
```

此时 `h(t) = Σ_m r_m e^{p_m t} + d·δ(t)` —— **`h` 不再是函数**，§2 式 (4) 的"在 `t_n` 取值"随之失去定义。
另一方面 `d = |H(j∞)|`：`d ≠ 0` 意味着 ≥ `min(f_in,f_out)/2` 的频率**以增益 `d` 原样通过**，
而 §5 要求那里被衰减（镜频/混叠正是在那里）。

对冲击串输入，直接项的贡献是 `d·x_train(t)` —— 一个只在输入栅格上非零的分布。按"冲激在自身位置的
采样值 = 其权重"（`T` 已归一化）取样本：

- `t_n` **恰好落在输入栅格**上时，采样值 `d·x[k]` 恰好等于理想值 `d·x_buf(t_n)`（因为 `x_buf(kT) = x[k]`）；
- 其余时刻理想值是 `d·x_buf(t_n) ≠ 0`，而这里是 0。

即"直接项 = 冲激串"在频域等价于**零插值（zero-stuffing）**：插值方向会在 `f_in − f` 上产生一条与信号**等幅**的镜像。

| 比率 | 输出/输入栅格重合率 | 直接项表现 | 实测 |
|---|---|---|---|
| 96k→48k | 100% | 每个输出样本都等于理想值 | max\|模型 − 理想\| = **0** |
| 48k→96k | 50% | 一半正确，其余缺失 → `f_in − f` 镜像 | 10 kHz 与 38 kHz 等幅 4.95e-3（`d=1e-2`） |
| 48k→44.1k | 0.2%（≈仅 n=0） | 等于被**静默丢弃** | 非零占比 0.1%，max 差 = `d` |

（上面三个比率的图：`output/direct_term_*.png`，脚本 `plot_direct_term.py`。
注意第三行的命中率是**浮点累积路径**的实测值 0.345%（13/3763）——结构上 `48000/44100 = 160/147`
每 147 个输出该命中一次，但二进制舍入使绝大多数落空，剩下的是**孤立**命中，也就是孤立尖峰。）

| 原型 | `d` |
|---|---|
| 奇数阶椭圆 | 0（严格真） |
| 偶数阶椭圆 | **`10^(−rs/20)`**（实测 n=6/rs=80 → 1.0e-4，rs=40 → 1.0e-2，rs=100 → 1.0e-5） |

**结论**：`d ≠ 0` 既让 `h` 含 δ（采样步骤不成立），又让镜频原样通过，所以

- SRC 原型应当**严格真**（`|H(j∞)| = 0`）；"部分分式不能有直接项"是**正确的建模约束**，不是库的缺陷；
- 若手上是双真原型（偶数阶椭圆），可以在**设计阶段**修掉它 —— 见下节；
  事后**丢掉 `d`**（即用 `H − d`）是下策：代价是通带 ~`d` 的偏差 + 阻带最坏 **+6 dB**
  （`max|H−d| ≈ 2·10^(−rs/20)`，实测 n=6/rs=80 → +5.8 dB、rs=40 → +5.1 dB）。

### 9.1 偶数阶椭圆原型的修正（已实现于 `iir_design.hpp`）

`IIRDesign::Elliptic(..., even_order_modify = true)` 给出严格真的偶数阶椭圆原型。
做法是 `ω²` 上唯一的 Möbius 变换（同时满足"最低反射零点 → 0、最高传输零点 → ∞、`ω = 1` 固定"）：

```
s'² = (1 − k²·sn_L²)·(s² + sn_L²) / (cn_L²·(1 + k²·sn_L²·s²))
```

其中 `sn_L = sn(K/N)` 就是最低反射零点（对偶地 `1/(k·sn_L)` 是最高传输零点，而 `sn_L` 恰好是设计循环里
最后一段 `arg = K/N` 已经算出的 `sn`，无需额外求根）。

结果（`n=6, rp=0.1 dB, rs=80 dB` 实测）：`N` 个极点仍在左半平面、`N−2` 个有限零点（最后一节零点在 ∞）、
`|H(0)| = 1`、通带 `[0,1]` 纹波 `[0.9886, 1] = [−0.1 dB, 0 dB]`、阻带恰为 `−80.00 dB`；
`ω = 1` 处仍是 `−rp dB`（与仓库 Chebyshev1 的偶数阶修正同一约定）。
代价：少一个传输零点，阻带边沿由 `1/k` 略微外移（实测 2.126 → 2.260）。

> 注：Wikipedia *Elliptic filter* §Even order modifications 给的是**两条分开的**式子
> （`R' = sqrt((R²+ω_LO²)/(1−ω_LO²))` 与 `R' = sqrt((ω_HI²−1)R²/(ω_HI²+R²))`）；
> 直接把它们按不同顺序/参数复合都不能同时保住两条边沿的等波纹（实测通带会变成 0.997~1.042）。
> 上面这条单一 Möbius 式子是等价目标下的正确形式，已由规格逐位验证。

### 9.2 直接项要"生效"需要什么

直接项乘的是**插值后的信号**，不是冲激串：

```
y[n] = [H_p 通路] + d·x_buf(t_n)
```

- `t_n` 落在输入栅格上时 `x_buf(t_n) = x[k]`（不需要插值）→ 补 `d·x[k]` 是**精确**的；
- 其他时刻 `x_buf(t_n)` 需要插值（理想插值还是非因果的，实际实现必须带延迟）→
  单极点状态机（因果、只有 `p̄` 的幂）给不出来。

**命中位置对有理比率是精确可判定的**：`f_in/f_out = p/q`（既约）时 `t_n = n·p/q`，
命中 ⟺ `q | n`，即**每 `q` 个输出命中一次**（`20Hz→50Hz = 2/5` → 每 5 个；
`48000→44100 = 160/147` → 每 147 个）。用整数相位（`phase_num mod q`）追踪即可精确命中，
不依赖浮点。实测：`2/1` → 100%，`1/2` → 50%，`160/147` → 0.700%（浮点累积路径会得到 0.345% 的乱命中）。

但**"命中判定精确" ≠ "直接项正确"**：非命中点仍缺 `d·x_buf`。实测（`d = 1e-2`，48k→96k，10 kHz 单音）：

| 实现 | 误差 |
|---|---|
| 只在命中点补 `d·x[k]` | ≈ `d`（1.0e-2，与频率无关） |
| 复用滤波通路 `(1+d)·A` | ≈ `d·\|∠H_p(ω)\|`：100 Hz 2.5e-4 → 20 kHz 2.0e-2 |
| **输入/输出栅格重合**（`f_in/f_out ∈ ℤ`） | **0** |

`(1+d)·A` 的误差来源：它把 `H_p` 的相位（椭圆通带内约 1 个样本的群延迟）乘进了 `d` 项，
而理想情形里 `d` 项是**不带延迟**的（它乘的是零延迟的理想插值）。

**结论（已修正）**：关键是要说清按**哪个模型**实现。HP 原文的模型是「输入 = 狄拉克串」，
此时直接项就是 `d ×` 冲激串 —— 它在时间上**只支持在输入栅格上**，于是：

- 输出时刻落在输入栅格上时（`f_in/f_out = p/q` 既约 → 每 `q` 个输出一次，`t_{q·n} = p·n`），
  它的贡献**精确等于** `d·x[p·n]`；
- 其余时刻贡献 0 —— 这是**模型自身**的答案，不是实现缺陷；也因此**不需要任何插值器**
  （见 §9.4 的精确实现）。

另一种「带限输入」的解释（把输入看成连续信号 `x_buf`）会要求 `d·x_buf(t_n)`（处处非零、
光滑、振幅 `1·d`），那才需要插值通路；两种解释**只在栅格点之间的那部分**有差别。
无论按哪种，`d ≠ 0` 都意味着原型把整个输入频带以增益 `d` 放过，抽取时的混叠是固有的
（但注意：一旦在输出率上采样，"全部镜像折叠"与"基带自身的折叠"给出同一个周期延拓，
所以两者在**输出样本**上一致 —— 差别只在类连续的中间时刻）。

### 9.3 直接项要不要缩放？

**不需要**，三个方向都实测过：

| 缩放 | `d` 的变化 |
|---|---|
| 原型设计在哪个绝对频率（`fpass` = 1 / 10 / 1000 / 48000） | 恒为 `0.01` ✓ |
| 代码的 `SetScale`（极点、留数同乘 `scale` = 0.1 / 1 / 2.5） | `H_scale(j∞)` 恒为 `1.000000e-02` ✓ |
| 换 `f_s` | 无关：设计在 rad/sample 归一化，换 `f_s` 只改 `scale`、只动极点 ✓ |

原因：`H_k(s) := H(s/k)` 的 `s→∞` 极限就是 `H(∞) = d`，与 `k` 无关。所以
**不要把 `d` 塞进「会和留数一起乘 `scale`」的数组**（`impluse_coeffs_` 的约定是 `coeff*scale`）。

区分论文的约定：论文把输入写成权重 `ū(k)·T_s` 的冲激串，于是 `h[n] = T_s·h_a(nT_s)`，
直接项的离散权重是 `T_s·d` —— 但**整个响应**都乘了 `T_s`（相对权重不变）。仓库的约定是
`T = 1`、输出就是信号值，所以 `d` 不缩放（实测：命中点补 `d·x[k]` 与理想 `d·x_buf` 逐位相等）。

**真正随截止/采样率变的是"有效 `d`"**：离散实现承受的是 `|H|` 在**镜像频率**
（插值：`k·f_in ± f`；抽取：`[f_out/2, f_in/2]`）处的值，而它落在阻带等波纹的不同相位上
（48k→96k、10 kHz 音的镜像在 38 kHz，`d = 1e-2`）：

| 通带边沿位置 | `\|H\|` @38 kHz |
|---|---|
| 0.25·(f_in/2) | 9.618e-3 |
| 0.5·(f_in/2)（标准） | 8.492e-3 |
| 0.75·(f_in/2) | 6.683e-3 |
| 1.0·(f_in/2) | 4.295e-3 |

所以压低镜像要靠 `rs` 更大或 `d = 0`，**不是在 `d` 上乘系数**。换比率会改变 `min/2`
（截止位置）→ 镜像相对波纹的相位变了 → 有效衰减跟着变，这就是"和采样率/截止有关"的那个真实现象。

修正（`d = 0`）的收益要如实说：它把最后一个传输零点搬到 ∞，但该零点在 48k 输入下约 78 kHz，
常规镜像带（25–96 kHz）在它下面，所以镜像处只从 3.81e-3 改善到 2.49e-3（38 kHz）。
**修正的主要收益在时间域**：`d = 0` 时直接项根本不存在，§9.2/§9.4 的命中点叠加也就免了。

#### 截止频率缩放时 `p_m` / `r_m` / `d` 各自怎么变

"截止频率乘 `k`" 就是频率轴拉伸 `k` 倍，即要 `H_k(s) := H(s/k)`。代入部分分式：

```
H(s/k) = Σ_m r_m/(s/k − p_m) + d = Σ_m (k·r_m)/(s − k·p_m) + d
```

于是规则是**唯一**的：

| 量 | 缩放 |
|---|---|
| 极点 `p_m` | **× k** |
| 留数 `r_m` | **× k** |
| 直接项 `d` | **不变** |

实测（`N=6, rp=0.1 dB, rs=80 dB`，`k = 2.5`）：

| 写法 | 结果 |
|---|---|
| 极点、留数同乘 `k`、`d` 不动 | 在 `kω` 处与原型**逐点相同**（rtol 1e-13 ✓）；截止恰落在 `ω = k`；直流增益不变 ✓ |
| 只缩极点 ✗ | 极点项被压 `1/k`（直流处 0.3955 而非 0.9886 ✗），而 `d` 项没缩 → 增益与形状都错 |
| 三个都缩 ✗ | 高频端变成 `k·d = 2.5e-4` ✗（直接项错 `k` 倍） |

实现（仓库约定：rad/sample、`T = 1`）：

```
scale = w / fpass        w = 2π·(目标截止 Hz)/fs_in,  fpass = 原型通带边沿(rad/s)
λ_m = p_m · scale        // 极点
c_m = r_m · scale        // 注入用的留数（状态递推 X ← X·exp(λ) + c·x[k]）
d   = d                  // 不乘 scale！
```

> 别和 §9.1 的偶数阶修正混淆：那里是**根位置的重映射**（`ω²` 上的 Möbius 变换），
> 对 `p_m`、`r_m` 各自给出新的复数，**不是**乘一个系数；而这里是纯粹的模拟频率缩放。

### 9.4 带直接项的正确实现（`labs/holters_parker/direct_term_study.py` 的 `step4()`）

按 HP 原文的狄拉克模型，直接项可以**精确**实现，不需要任何插值器：

1. **无 d 输出**：用严格真部分 `H_p(s) = Σ_m r_m/(s − p_m)`，按单极点状态迭代，
   在新采样率的时刻取值（= §4 的循环，与仓库 `ResampleIIR` 同一套）：

   ```
   X_m ← X_m·exp(λ_m) + c_m·x[k]                  λ_m = p_m·w,  c_m = r_m·w,
   y[n] = Σ_m Re( X_m·exp(λ_m·d_n) )              w = 2π·min(f_in,f_out)/2 / f_in
   ```

   （`d_n ∈ [0,1)` 是第 n 个输出时刻相对于最后一个已消费输入样本的小数偏移。）

2. **直接项**：`f_in : f_out = p : q`（既约）时，输出第 `q·n` 点恰好落在输入第 `p·n` 点上
   （因为 `t_{q·n} = q·n·(p/q) = p·n`），于是

   ```
   y[q·n] += d · x[p·n]        n = 0, 1, 2, …
   ```

   例：`20 : 50 = 2 : 5` → `y[5n] += d·x[2n]`；`20 : 8 = 5 : 2` → `y[2n] += d·x[5n]`。

3. 先算完无 d 的 `y`，再叠加第 2 步。

**实测**（`N=6, rp=0.1 dB, rs=80 dB` 缩放到截止 4 Hz；`20 → 8 Hz` 即 `5:2`）：

| 量 | 结果 |
|---|---|
| 基音 2.5 Hz 的电平 vs 解析 `\|H\|` | 吻合到 **0.06 dB**（状态迭代实现正确 ✓） |
| 直接项在输出率上的内容 | 2.5 Hz 与 1.5 Hz 各 **−86.0 dB** = `d/q` ✓ |
| 输出里唯一显著杂散 | 1.5 Hz **−66.3 dB** —— 来自 `H_p` 通路在镜像频率（17.5/22.5 Hz 折到 1.5 Hz）的泄漏，**与直接项无关** |

**⚠ 本节的核心坑：构造对照用的「类连续信号」时，两个"零插值"数组的幅度约定不同，不能混用。**

```
y = [无 d 输出] + d × [插零后的高采样信号]
```

| 数组 | 样本值 | 为什么 |
|---|---|---|
| 喂给**滤波器**的那份 | `L·x[k]`（别处 0） | 它是狄拉克串的离散表示：权重 `T·x[k]` 放在间距 `h = T/L` 的细网格上 → 值 `= (T/h)·x[k] = L·x[k]` |
| 直接项乘的那份 | **`x[k]`**（别处 0） | 它就是"插入零"本身，幅度保持 1；于是直接项在栅格上的尖峰是 `d·x[k]`（= `1·d`） |

把前者拿去当后者，直接项就**大了 `L` 倍**（实测 `d·(L−1) = 0.819`，即 72 dB），
且在细网格上被当成"信号值"抽取时会给出 `−7.7 dB` 的假杂散（真的只该是 `−86 dB`）。
修正后，「细网格抽取」与「状态迭代 + 命中点叠加」两条路径**逐位一致**（都是 `d/q = −86.0 dB`）。

### 9.5 喂给滤波器的输入要不要乘上采样倍数？

**不要。** HP 采样器不是"插零 + 离散滤波"，而是直接在连续域上求卷积

```
y(t) = Σ_k T·x[k]·h(t − kT)
```

在归一化单位（rad/sample、`T = 1`）下，每个输入样本就注入 `c_m·x[k]`，与 `fs_out/fs_in` 无关。
实测（单位幅度正弦输入，`N=6, rp=0.1 dB, rs=80 dB`，截止 = `min(fs)/2`）：

| `fs_in → fs_out` | `L` | 实测幅度 / 解析 \|H\| |
|---|---|---|
| 48000 → 96000 | 2 | 0.9988 |
| 48000 → 192000 | 4 | 0.9995 |
| 96000 → 48000 | 0.5 | 0.9988 |
| 44100 → 48000 | 1.088 | 0.9999 |
| 48000 → 44100 | 0.919 | 0.9999 |

比值恒为 1、且与 `L` 无单调关系 ⇒ **没有**与上采样倍数有关的增益 ✓。仓库的 `ResampleIIR` 同理
（`blep_.Add(x[i + 1])` 注入的就是原始样本；48k→96k 即 `L=2` 时实测幅度 0.9955 = 设计值，
见 `repo_impl_notes.md`）。

**`L` 只在"离散多速率"实现里才出现**：插零（保留样本值、插入 `L−1` 个零）之后，滤波器必须有
**`L` 的通带增益**才能还原幅度 —— 等价地「输入 ×L + 单位增益滤波器」。§9.4 里用于画类连续频谱的
细网格构造正是这种风格（零插值 + 单位增益的连续响应），所以那里必须有 ×L；它**不属于** HP 理论，
不能带进状态迭代实现。
