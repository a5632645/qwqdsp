## 算法实现要点（与论文式号的对应）

* **相位约定**：`x` 以「周期」为单位，每采样前进 `Δ = f0/fs`；波形表用
  `(X, m, q)` 分段线性表示，段 `j` 覆盖 `[X[j], X[j+1]]`，周期 `T = X[-1]`（论文式 (18)/(19)）。
* **AA-IIR（论文式 (20)–(26)）**：把逐采样递推拆成
  1. 每个采样区间上的积分 `I_n` 用**解析闭式**算（式 (22)–(25) 的等价形式），
     跨段时按表断点切分求和；
  2. 递推 `ŷ_{n+1} = e^β·ŷ_n + 2B·I_n` 用 `scipy.signal.lfilter` 一次算完
     （一阶线性递推，与逐点循环逐位等价）。

  因而实现是**向量化**的，不是逐采样 Python 循环。闭式推导见 `aaiir.py` 模块 docstring。
* **滤波器**：`AA-IIR-1` = 2 阶 Butterworth，`AA-IIR-2` = 10 阶 Chebyshev II（rs = 60 dB），
  极点归一化与参考代码一致（极点本身即「每采样」衰减率）。
* **AA-FIR-1/2（论文 §III-B）**：`F1`/`F2` 为分段线性周期函数的 1/2 阶原函数，
  一阶/二阶差分除以 `Δ`、`Δ²`。原函数用「周期数 + 周期内积分」的精确分解算，
  避免大 `x` 下的抵消误差（论文式 (15)–(17) 的连续性处理）。
* **DPW-2/3**：分数相位 φ 的周期多项式（`φ²-φ`、`φ³-1.5φ²+0.5φ`）作一阶/二阶差分。
  ⚠ 若用不做周期连续性修正的 `s³/12`（`s = 2φ-1`），每个周期跳变处会留下幅值
  `1/(12Δ²)` 的尖峰，与 AA-FIR-2 不再相等；论文声称二者相同，对应的正是**修正后**
  的多项式（二者只差一个「线性于 n」项，被二阶差分消掉）。

## 交叉验证（`check_impl.py`）

实现正确性用三条**互相独立**的证据链锁住（43 项断言，全部通过，退出码 0）：

1. **作者 MATLAB 参考代码（`AA_osc_cplx.m`）逐行移植**：4 组 (波形, 基频) × {AA-IIR-1,
   AA-IIR-2, 实极点} 逐点比对，最大偏差 `1.4e-14`（阈值 `1e-9`）；
2. **卷积积分（论文式 (6)）的高精度数值求积**：`y_n = ∫_0^n 2Re(B·e^{βt})·f(x̃(n-t))dt`
   用 `scipy.integrate.quad`（实/虚部分开；`quad` 不接受复被积函数）逐区间积分，
   与递推实现最大偏差 `2e-13`（阈值 `1e-8`）——这条**验证数学推导本身**，不依赖任何索引技巧；
3. **方法恒等式与核定义**：`DPW-2 ≡ AA-FIR-1`（偏差 0）、`DPW-3 ≡ AA-FIR-2`（`1.2e-11`）、
   AA-FIR-1/2 与「矩形核 / 三角核连续卷积」的数值求积逐点一致（`2e-14`）。

另加两条通带增益不变量（保证滤波器归一化与 `2B` 因子没错）：常数输入的直流增益
`= 1 - A0`，441 Hz 正弦的基波增益 `= 1 - A0`（`A0` 见下）。

> 调试记录：向量化闭式最初漏了「跨段槽位的指数权重应以**整个采样区间的右端**为基准」
> 这一因子，导致每周期跳变处出现幅值 0.26 的误差、随后按 `e^β` 衰减。上面第 1、2 条
> 证据链就是它暴露出来的（单看第 3 条恒等式反而会漏，因为两条路径用同一套错误公式）。

## 与参考实现的两处差异（重要）

1. **直接项被丢弃**。Chebyshev II 的传递函数不是严格真，`residue` 的直接项
   `A0 = 1e-3`（= 阻带增益 = -60 dB）。参考代码 `[r,p,k] = residue(b,a)` 丢掉了 `k`，
   本复现默认同样丢弃（`aa_iir_osc(..., include_direct=False)`），因此
   * 直流/低频增益是 `1 - 1e-3`（-0.0087 dB）而不是 1；
   * AA-IIR-2 的混叠抑制**不受 -60 dB 阻带底限制**，这正是论文能报出 64.6 dB
     （> 60 dB）的原因。`include_direct=True` 可把这 1e-3 补回去（见 `check_impl.py` 第 5 节）。
2. **Chebyshev II 的截止归一化**。论文正文写「`f_bs = 0.61 fs`」，但参考代码传给
   `cheby2` 的是 `pi*0.61`（不是 `2*pi*0.61`），即阻带边沿实际是 **0.61 × Nyquist**
   = 0.305 × fs。本复现照抄参考代码（`AAIIR2_WN = pi*0.61`），否则复现不出论文数值。
   Butterworth 那档没有这个问题（`2*pi*0.45` = 0.45 fs）。

## SNR 定义（论文未给细节，本复现自行规定）

论文只写「谐波功率 / 其余分量功率」。本复现的固定口径（`aaiir.snr_db`）：

* 每音生成 `2^17` 采样（fs = 44100），**丢掉前 4096 采样**（AA 递推的启动瞬态）；
* `blackmanharris` 窗 + rFFT（窗主瓣宽 ±4 bin，泄漏旁瓣 < -90 dB）；
* **信号** = 每个谐波 `k·f0`（k = 1…Nyquist）附近 **±4 bin** 的功率和；
* **噪声** = 其余 bin 功率和；DC 与 Nyquist 各 ±4 bin 两侧都不计，两部分严格互斥；
* `SNR = 10·log10(P_harm / P_noise)`。

标定过程（`calibrate_snr.py`）：论文只给了平均值，口径不可复原。本复现的做法是**先把口径钉死
在可验证的锚点上**——`trivial` 方法的混叠功率有解析表达式，实测必须与它吻合——再扫
(长度 × 窗 × 排除带) 组合看能否命中论文数值（结论：不能，见下）。因此固定采用
`blackmanharris` + ±4 bin + 2^17 采样这一组。

## 复现结果

### 锯齿波 SNR（论文 Fig. 2 侧表）

88 键逐音生成 2^17 采样（fs = 44100）。22 个音因「折叠分量恰好落在谐波栅格上」
（低音区 `fs/f0` 接近整数，谱上无法区分混叠与谐波）被门限剔除，下表是剩余 **66 音**的平均：

| 方法 | 论文 [dB] | 本复现 [dB] | 差 | 本复现范围 [dB] |
|---|---:|---:|---:|---|
| trivial | 8.7 | 17.9 | +9.2 | 9.1 – 28.1 |
| AA-FIR-1 / DPW-2 | 18.8 | 27.5 | +8.7 | 18.0 – 36.3 |
| AA-FIR-2 / DPW-3 | 24.5 | 33.4 | +8.9 | 23.1 – 42.3 |
| OVS-2 | 17.3 | 26.2 | +8.9 | 16.3 – 39.2 |
| OVS-8 | 30.8 | 43.9 | +13.1 | 28.8 – 76.1 |
| AA-IIR-1 | 18.8 | 27.5 | +8.7 | 18.2 – 36.3 |
| AA-IIR-2 | 64.6 | 75.3 | +10.7 | 66.3 – 83.9 |

**排名逐项一致**：trivial < OVS-2 < AA-FIR-1 ≈ AA-IIR-1 < AA-FIR-2/DPW-3 < OVS-8 < AA-IIR-2。
论文说 AA-FIR-1 与 AA-IIR-1「结果几乎相同」——本复现两者平均只差 **0.03 dB**
（27.523 vs 27.497 dB），逐音曲线在图上完全重合。

绝对值整体高 ~9 dB（OVS-8 高 13 dB）。这个偏差**不是实现问题**：本口径已用**解析锚点**锁住
——`trivial` 方法的实测 SNR 与理想锯齿波采样后的解析值 `analytic_saw_snr`
（`Σ_{k≤K}1/k² / Σ_{k>K}1/k²`）在 5 个代表性音上相差 ≤ 0.13 dB（`check_impl.py` 第 6 节），
在全部 66 个良态音上最大 1.9 dB——残余偏差有确定来源：±4 bin 的排除带在低音区占的
相对带宽更大，会把少量谐波附近的折叠分量误计入信号（属已知的口径偏差，方向为**高估**）。
偏差应来自论文未公开的测量细节（截断长度 / 窗 / 排除带宽度），其中 OVS 两档偏离更大，
而 OVS 恰好是对「抽取滤波器实现细节」最敏感的一档。

（旁证：`calibrate_snr.py scan` 扫了 N ∈ {100 ms, 1 s, 3 s} × 窗 ∈ {rect, hann, hamming,
blackmanharris, nuttall} × 排除带 ∈ {0,1,2,4,8} bin，共 75 组组合，**没有任何一组**能让
trivial / OVS-8 / AA-IIR-2 三档同时落到论文的 8.7 / 30.8 / 64.6 dB——例如
`rect` 窗 ±4 bin、1 s 时是 14.7 / 18.1 / 18.5，`hann` 窗 ±4 bin、1 s 时是 22.6 / 43.8 / 53.0。
本目录因此固定采用可被解析验证的那一组，并把论文数值并列展示。
`calibrate_snr.py anchor` 则给出解析锚点的逐音偏差与剔除名单。）

### 扫频谱图（论文 Fig. 3，Escalation II）

`output/fig3_escalation_sweep.png`：5 个面板（trivial / OVS-2 / OVS-8 / AA-IIR-1 / AA-IIR-2），
横轴指数扫频 f0 = 20 Hz → 10 kHz，纵轴 0–20 kHz，下限 -80 dB，全部面板共用同一参考
（便于横向比较）。

定量摘要（256 档 f0 里，低音区谐波带互相重叠、判据失效的档已跳过，剩 189 档；
指标 = 「最坏非谐波分量 / 基波」）：

| 方法 | 中位数 [dB] | 最差 [dB] |
|---|---:|---:|
| trivial | +6.0 | +26.6 |
| OVS-2 | 0.0 | +16.7 |
| OVS-8 | -8.4 | +8.5 |
| AA-IIR-1 | +5.0 | +26.6 |
| AA-IIR-2 | -10.9 | -8.3 |

与论文的定性结论逐条对应：

* **AA-IIR-2 混叠最少**（中位 -10.9 dB，最差也只有 -8.3 dB，全程压在 -80 dB 线附近）✓
* **OVS-8 第二**（中位 -8.4 dB，但最差 +8.5 dB —— 论文说 OVS「无法消除更高频的分量，
  在谱图上表现为背景噪声」，本复现的「最差」列正体现这一点）✓
* **AA-IIR-1 压不住第一族混叠分量**（中位 +5.0 dB，与 trivial 的 +6.0 dB 几乎一样）✓
* **OVS-2 能压低第一族混叠但留下背景**（中位 0.0 dB、最差 +16.7 dB）✓

### 计算代价

`exp_cost.py` 生成 10 s / 44.1 kHz 音频（Python 3 + numpy 批量实现，3 次取最快）。

| 方法 | 耗时 [s] | µs/采样 |
|---|---:|---:|
| trivial（锯齿） | 0.05 | 0.10 |
| AA-FIR-1（锯齿） | 0.05 | 0.11 |
| AA-FIR-2（锯齿） | 0.09 | 0.21 |
| OVS-8（Escalation） | 0.50 | 1.13 |
| AA-IIR-1（Escalation） | 0.29 | 0.66 |
| AA-IIR-2（Escalation） | 1.39 | 3.15 |

（同机不同负载下绝对值有 ±50% 波动，同一进程内 `run_all` 与单跑就对不齐；看倍数不要看绝对值。）

论文在同一台 3 代 i5 + MATLAB 逐采样循环下是 0.6 s / 0.4 s / 2 s（AA-FIR-1 / AA-IIR-1 / AA-IIR-2）。
**绝对时间不可比**（实现方式与语言都不同），但结构性结论可验证：

| Chebyshev II 阶数 | 2 | 4 | 6 | 8 | 10 |
|---|---:|---:|---:|---:|---:|
| 共轭极点对 | 1 | 2 | 3 | 4 | 5 |
| 耗时相对 1 对 | 1.00 | 1.96 | 3.02 | 4.00 | 5.07 |

即论文 §IV-D 的「代价随极点对数**线性**增长」成立（这里的倍数几乎与极点对数完全成正比）。
论文「AA-IIR-2 约为 AA-IIR-1 的 5 倍」也随之复现（1.39 / 0.29 = 4.8 倍，对应 5 对极点）。
