Thiran 设计法解决的是「用递归滤波器近似分数延迟 D = n + δ 样本」的问题，闭式解只有这一个。
它有两种用法：把多项式 A(z) 整体看作分母得到**全极点**低通，把 A(z) 的镜像当作分子得到**全通**。

## 系数公式

设阶数 n、偏移 δ，两个公式只差一个因子 2：

| 形式 | 系数 | 传递函数 | 直流群延迟 |
|---|---|---|---|
| 全极点（Thiran 1971） | a_k = (-1)^k C(n,k) ∏_{i=0..n} (2δ+i)/(2δ+k+i) | 1/A(z) | δ |
| 全通（Laakso 等 1992） | a_k = (-1)^k C(n,k) ∏_{i=0..n} (δ+i)/(δ+k+i) | z^-n A(1/z)/A(z) | n+δ |

其中 A(z) = 1 + a_1 z^-1 + … + a_n z^-n，a_0 恒为 1（无需归一化）。两者共用同一个分母：
**A_全极点(δ) 与 A_全通(2δ) 逐位相等**，因此 τ_g,全通(0) = n + 2·τ_g,全极点(0)。

全通形式的分子是分母的反序，故 |H| ≡ 1 是恒等式，与系数取值无关。

## 实测性质（n = 1…6）

**全通**

- 直流群延迟精确等于 n+δ（残差 < 1e-9），幅度偏离 1 不超过 1.7e-14。
- 最平坦：τ_g(ω) − (n+δ) 的幂次实测为 2n（n=1/2/3 时斜率 2.000/3.999/5.999）。
- 带内平均群延迟恒等于 n，与 δ 无关（稳定全通滤波器的通用性质）。
- 稳定 ⟺ δ > −1（即 D > n−1）；δ = −1 处公式奇异、极零点正好落在单位圆上（n=6 时 δ=−0.9 → |p|max=0.927，δ=−1.1 → 1.075）。
- δ = 0 时所有 a_k = 0，退化为纯整数延迟 z^-n（误差为 0）。
- 群延迟偏差 τ_g − D 在整个频带内**不变号**：δ>0 时处处下垂、δ<0 时处处上冲，带内均值恰为 −δ，故平均绝对偏差 = |δ|。

**全极点**

- 直流群延迟精确等于 δ（相延迟同样为 δ），最平坦幂次同为 2n（n=1…4 实测 1.999/3.999/5.999/7.999）。
- 稳定 ⟺ δ > −0.5（δ = −0.5 处公式奇异）。Thiran 只证明了 δ > 0 的充分条件，实际稳定域更宽：n=6、δ=−0.4 时 |p|max 仍只有 0.855。
- 幅度完全不受控：它是一个直流增益大于 1 的低通，增益随 δ 与 n 迅速增大（n=6、δ=5 时 |H(0)| = 80.75，|H(π)| = 0.058）。
- 群延迟在带内变号（ω=π 处为负，如 n=6、δ=0.5 时 ≈ −0.97），所以它不能当作宽带分数延迟使用；这也解释了为什么分数延迟普遍用全通形式。

## 工作点：δ 的符号决定高频偏差的形态

D = n+δ，表中是 τ_g(ω) − D（单位：样本）：

| n | δ | 0.5π | 0.75π | π | mean\|dev\| |
|---|---|---|---|---|---|
| 4 | −0.50 | +0.033 | +0.590 | +2.962 | 0.500 |
| 4 | −0.25 | +0.034 | +0.417 | +1.106 | 0.250 |
| 4 | +0.25 | −0.086 | −0.515 | −0.797 | 0.250 |
| 4 | +0.50 | −0.235 | −1.044 | −1.435 | 0.500 |

负 δ（D 略小于 n）在低中频几乎无偏差、代价是奈奎斯特附近上冲；正 δ 则从低中频就开始下垂。
平均绝对偏差对两侧完全对称（都等于 |δ|），所以选哪一侧取决于把误差压到哪个频段：
按「低频优先」（音频与音高感知的实际口径），负侧明显更划算——4 阶、δ=−0.5 时 0.5π 处只有 +0.033，
而 δ=+0.5 时已是 −0.235。文献（Laakso 等）给出的相位误差度量同样偏向负侧，
建议 n−0.5 ≤ D < n+0.5，最优点在 D ≈ n−0.58。

## 本库 ThiranFilter 的行为

`ThiranFilter<n>::Make(delay)` 用全通形式：先把 delay+0.5 取小数部分，把 δ 归一到 [−0.5, 0.5)，
返回需要额外补的整数延迟。于是总延迟 = 整数延迟 + n + δ：

- 请求延迟 ≥ n−0.5 时总延迟等于请求值；小于 n−0.5 时整数延迟被夹到 0，实际延迟大于请求值（最小可实现的分数延迟是 n−0.5）。
- 与双精度参考模型逐样本比对 14 组 (n, delay)：脉冲响应最大差 6.9e-8（float 系数与递推的舍入）。

## 扫描探索（纯 Python，与库实现无关）

`explore_scan.py` 直接照抄公式做扫描（不复用库里的实现），四张图写到 `output/`：

| 图 | 内容 |
|---|---|
| `ap_scan_delay.png` | 全通：固定阶数 n=6，扫描目标群延迟 D（群延迟 + 偏差 + 极点模长） |
| `ap_scan_order.png` | 全通：固定目标 D=6.5，扫描阶数 n |
| `lp_scan_delta.png` | 全极点：固定阶数 n=6，扫描目标群延迟 d（含幅度响应） |
| `lp_scan_order.png` | 全极点：固定目标 d=2.5，扫描阶数 n（含幅度响应） |

目标群延迟扫到远大于阶数时可以看到：

- 目标离阶数越远，带内偏差越大，且几乎按 |D−n| 线性放大：n=6 时 D−n = 0.25/0.5/1/2/4/7
  对应的带内平均绝对偏差正好是 0.250/0.500/1.000/2.000/4.000/7.000（= |D−n|）。
  偏差在带内不变号，负侧贴合理想延迟到很靠高频、代价是奈奎斯特附近上冲，正侧则从中低频就开始下垂。
- 极点模长面板上直接看到稳定边界：全通 D > n−1（D = n−1 处公式奇异）、全极点 d > −0.5；
  D = n（d = 0）时系数全为 0，退化成纯整数延迟、偏差恒为 0。
- 全极点（1/A(z)）的幅度是低通且完全不受控：直流增益随 d 与阶数急剧上升（n=6、d=5 时 +38.1 dB，
  图里的幅度已按直流归一化、括号内标出实际增益），归一化后 n=6 的 |H(π)| 从 d=0.1 的 −3.1 dB
  一路掉到 d=5 的 −62.9 dB；群延迟在带内变号（n=6 时零点从 d=0.1 的 ω/π≈0.67 前移到 d=5 的 ≈0.33），
  所以它不能当宽带分数延迟用。
