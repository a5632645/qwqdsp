# 数字贝塞尔 / 逆切比雪夫的群延迟扫描

`bessel_cheby2_scan.py`（纯 Python，用 scipy 设计）扫描两类数字低通的群延迟，图输出到 `output/`：

| 图 | 扫描 |
|---|---|
| `bessel_scan_cutoff.png` | 数字贝塞尔：`norm='delay'`，N=4 固定，扫 Wn |
| `bessel_scan_order.png` | 数字贝塞尔：`norm='delay'`，Wn=0.2 固定，扫阶数 |
| `cheby2_scan_cutoff.png` | 数字逆切比雪夫：N=6、rs=40 dB 固定，扫阻带边沿 Wn |
| `cheby2_scan_order.png` | 数字逆切比雪夫：Wn=0.3、rs=40 dB 固定，扫阶数 |

数字设计统一用 `fs=2`（`Wn=1` 即 Nyquist，横轴 `ω/π`）。群延迟由零极点解析求
（`-d arg H/dw`），不用多项式系数——高阶时系数式在 ω→π 处会因抵消失真（自检里可见
scipy 系数式与零极点式差到 8.8e+01，零极点式与相位差分的差只有 1e-9 量级）。

## 实测

**数字贝塞尔**（`scipy.signal.bessel`）

- `norm='delay'`（本图）：直流群延迟与阶数无关，恒为 $1/(2\tan(\pi W_n/2))$ 样本
  （Wn=0.2 时 1.5388；阶数 1…10 全都一样），这正是"延迟归一化"的含义。
- 数字群延迟等于模拟原型经双线性频率拉伸：$\tau_d(\omega)=f_s\sec^2(\omega/2)\cdot\tau_a(\Omega)$，
  $\Omega=2f_s\tan(\omega/2)$（n=4/10 实测最大差 1.9e-11 / 4.7e-11）。
  由于 $\sec^2$ 在高频端的拉伸，**数字版在奈奎斯特附近出现群延迟峰**，阶数越高越猛：
  Wn=0.2 时 n=4 峰值 2.66 样本，n=10 峰值 12.58 样本（出现在 ω/π≈0.80）；
  同一阶数下 Wn 越大（标称延迟越短）抬升越猛——N=4、Wn=0.8 时峰值约 17 样本，而它的标称延迟只有 0.27。
  模拟原型的群延迟则单调下降（τ_a(0)=0.7694 秒）。
- scipy 默认的 `norm='phase'`（图中右侧虚线的对比曲线）行为完全不同：直流群延迟随阶数增长
  （Wn=0.2 时 n=2/4/6/10 → 2.67/4.93/7.19/11.72 样本），且 −3 dB 点也不落在 Wn 上
  （分别是 ω/π = 0.159/0.135/0.118/0.097）。选哪个归一化会直接改变"扫 Wn"看到的族形状。

**数字逆切比雪夫**（`scipy.signal.cheby2`，Wn = 阻带边沿）

- 群延迟处处为正（实测最低点也在 0.05 样本以上，没有负群延迟区）。
  各阶数都有一根细到采不到的 **±∞ 尖峰**：双精度下传输零点邻域内 |τ_g| 能到 1e15 量级，
  在 3001 点的作图网格上只采到十几到几十，所以图上表现为被坐标轴截断的竖线。
- 有限范围内的最大峰在通带边沿附近（≈0.7·Wn），高度随 Wn 减小而上升：
  N=6、rs=40 时 Wn=0.1 → 36.1 样本 @ ω/π=0.071，Wn=0.3 → 12.5 @ 0.22，Wn=0.6 → 8.0 @ 0.50。
- 直流群延迟与 Wn 成反比（右图 log-log 上是直线，略有弯曲是双线性预畸变）；
  固定 Wn=0.3 扫阶数时 $\tau_g(0)$ 随 N 下降：N=2/3/4/5/6/8/10 → 9.76/5.57/4.48/4.03/3.80/3.58/3.48 样本，
  而尖峰所在频率越靠向阻带边沿、有限峰越高（N=10 约 27.5 @ ω/π=0.269）。
- 幅度侧自检：阻带波纹峰值恰好等于 −rs（40.0000 dB），通带最大 0.0000 dB（最平坦），
  传输零点处深达 −102 dB（N=6）/ −141 dB（N=10、rs=60）。
