# nc_reassign — 无窗 NC 的时间-频率重分配

本目录研究 **无窗函数 NC**（论文《Window Function-less DFT with Reduced Noise and
Latency for Real-Time Music Analysis》, arXiv:2410.07982v3 的邻域频谱分量合成法）
谱图上的**重分配**（reassignment），只做离线数值实验，语言 Python。

三个目标（与 C++ GUI 侧三个标准帧一一对应）：

| 变体 | 频率轴 | 时间轴 | 对应的 C++ 标准帧 |
|------|--------|--------|-------------------|
| `freq` | 瞬时频率 | 分析窗中心（不重分配时间） | `freq_reassignment_frame.hpp` |
| `time` | bin 中心频率 | 群延迟（窗口内重新定位） | `time_reassignment_frame.hpp` |
| `tf`   | 瞬时频率 | 群延迟 | `tf_reassignment_frame.hpp` |

标准参照 = 加 Blackman-Harris 3 项窗的 STFT（`zeroPad = 1`，与 GUI 的
`kZeroPadFull` 一致），三个算子与上面三个 C++ 帧逐一对应，且**与 NC 共用同一个
log 频率重分配网格**，保证可比。

## 结论速览

1. **三个变体都成立**：对数 chirp 在三种重分配下都成为**锐利直线**（图
   `output/chirp_nc.png`），与解析真值线重合。
2. **NC 的时间+频率重分配现在全面好于标准 STFT**（改进频率估计器后，见「频率估计器」；
   下表全带统计，t ∈ [0.25, 1.75] s）：

   | 指标 | NC·tf | STFT·tf | 谁更好 |
   |------|-------|---------|--------|
   | 线上能量（±50 cent 内功率占比） | **0.9986** | 0.9846 | NC |
   | 脊线偏差（能量重心 vs 真值，中位） | **3.71 cent** | 14.46 cent | NC 3.9× |
   | 带外虚假能量（离真值线 ≥200 cent 的功率占比） | **6.1e-7** | 1.4e-6 | NC 2.3× |
   | Hough 支撑（阈值上像素落在同一直线的比例） | **0.397** | 0.346 | NC |
   | 垂直宽度（10-90 分位，垂直于轨迹） | **0.0461 oct** | 0.0512 oct | NC 10% |
   | 垂直 RMS（同一直线上像素的垂直散布） | **0.476 行** | 0.496 行 | NC |

3. **`verify_time_reassignment.py`（原 lab2 的历史实验）里"NC 时间重分配不聚焦"的结论是错的**：它把群延迟偏移按
   **帧长**（`fft_size/hop` = 16 列）统一折算，而 NC 每个 bin 的时间单位是**它自己
   的窗长 N**（`N·δ/2π` 样本，最大 ±N/2）；符号也反了（它算的是 `−δ/2π`），参考点
   用的是帧中心而不是窗口中心；再加上负偏移（能量落在当前帧之前）被写进了已经发射
   过的环形槽位、随后被清空——等于丢掉一半能量再打散另一半。按正确折算后，单冲激
   的落点误差中位/90 分位都是 **0.5 样本**（`--selftest`），能量确实聚焦。本目录的
   实现用**左垫列**（`col_shift`）保存"落在过去"的能量，不回绕、不丢弃。
4. **多分量**（上行+下行两条对数 chirp 交叉）同样被解析成干净的两条直线
   （`output/crossed_compare.png`）。NC·tf 每列峰数中位 2、均值 **2.00**（STFT·tf 2.06）——
   改善频率估计器后，原先低频/交叉点的多余亮点也没了。
5. **窗长 N 有硬下限**：`N > Fs/(2·f_c)`（窗内至少半个周期的中心频率），否则
   左分量越过 DC、与负频镜像重合，bin 直接失效（输出抖动 50%~80%）。为时间分辨率
   截短 N 只能用在 f_c 足够高的 bin 上。机制与复现见「窗长 N 的下限」。
6. **六方法总对比**（交叉对数 chirp）：`nc-floor4` **0.999** ≳ `nc-cap` 0.998 ≳ `stft-tf`
   0.985 > `nc-free` 0.891 > `nc-plain` 0.665 > `cqt`(librosa) 0.151（线上能量±50 cent）；
   CQT 低频/中频因长窗时间拖糊而掉队、高频 0.901。见「六方法总对比」。
7. **低频也不该"不截短"**：按理论式 (7) 取 N（25 Hz → 8.5 万样本）反而更差——
   非平稳内容的 NC 增益 ∝ 1/N（实测正好 30 倍 ≈ N 之比）、且窗中心不再是有效时间
   参考。低频 20–120 Hz 的线上能量：截短 0.999 vs 理论 N 0.845。见「低频窗长」。
8. **频率估计器已重做**（`Config.if_estimator`）：用 `X_R − X_L` 得到"正弦锥加窗"的
   滑动 DFT 求瞬时频率（零额外乘法、旁瓣低 10 dB），再按 IF 序列斜率一阶外推到落点
   时刻。逐 bin 误差（25 Hz）67.5 → 22.5 cent，端到端线上能量 0.980 → **0.9986**；
   前后对比图 `output/if_estimator_compare.png`。见「频率估计器」。

## 算法

### 无窗 NC 的滑动 DFT 与两个算子

bin 中心频率 `f_c`、窗长 `N`（论文式 5/6/7；低音被 `max_window_s` 夹住），
左右分量 `f_left/right = f_c ∓ Fs/(2N)`。本实现用 FFT 卷积等价于论文的逐样本递归：

```
X(n) = W·X(n-1) + x[n] − x[n−N]·W^N = Σ_{m=0}^{N-1} x[n−m]·exp(−j·2π·f·m/Fs)
```

相位锚定窗口起点，故**无需式(8)的相位校正**（与 `run_sliding_dft.py` 一致）。

- **幅度**（NC，论文式 3）：`gain = sqrt(max(0, −(Re_L·Re_R + Im_L·Im_R))) / N`
- **瞬时频率**（通用相量法，等价于窗口中心处的瞬时频率）：
  `f_inst = −(Fs/2π)·arg(X[n]·conj(X[n−1]))`
  负号是本实现的相位约定所致：滑动 DFT 对正频率的相位随时间**递减**（核为
  `exp(−jωm)`，m 是延迟），与标准 DFT 反号。静止纯音实测误差 −0.4 cent。
- **群延迟**（KFN 谱导数法，两点有限差分；两点恰好就是 NC 的左右分量，间距
  `Fs/N`，与标准方法 `roll` 一格的截断阶数相同）：
  ```
  ψ = arg(X_R·conj(X_L));      δ = wrap(ψ + π)      # δ ∈ (−π, π]
  ⟨m⟩ = N/2 − N·δ/(2π)                             # 能量相对当前样本的延迟（样本）
  相对窗口中心的偏移 = +N·δ/(2π)                      # ∈ (−N/2, N/2]
  ```
  静止纯音时 `ψ` 恒为 −π（与频率、与时间都无关），故以 π 为参考零点；这时
  `δ = 0`、偏移 = 0，即"不重分配"就是把能量放在窗口中心。

### 时间参考约定（全库统一，也是本目录的关键）

图像第 0 列对应第 0 帧的**帧中心**（`fft_size-1)/2` 样本）。所有能量都落在
**被估计出的绝对时刻**上，于是"不重分配"= 落在自己窗中心，静止音对各 bin 都落在
同一列（不会因为各 bin 窗长不同而在图上倾斜）：

| 方法 | 窗中心相对帧中心的偏移 | 时间重分配增量 | 列坐标 |
|------|------------------------|----------------|--------|
| 标准 STFT | 0（窗中心 = 帧中心） | `gd·fft_size`，`gd = 0.5 − frac(arg(X_h·conj(X_pf))/2π)` | `j + gd·fft_size/hop` |
| 无窗 NC | `(fft_size − N)/2` | `N·δ/(2π)` | `j + [(fft_size−N)/2 + N·δ/(2π)]/hop` |

频率轴：两者都把能量铺进同一个 log 网格 `LogReassignGrid`（行 = 对数频率像素，
行内按 `bin_hz·0.25` 细分子格，**子格内求和、行内取 max**，频率与时间都双线性；
`ReassignGrid` 是 `example/gui/spectral/reassignment/log_reassign_grid.hpp` 的
离线等价实现）。NC 的 bin 中心正好落在行中心上（每行一个 bin）。

> 一点刻意的统一：C++ 的 `time_reassignment_frame.hpp` 单独走"行 → FFT bin 区间取
> max"，本目录为三个变体统一用 `LogReassignGrid`，两种方法因此共用完全相同的
> 频率/时间映射，比较不受显示细节干扰。

**为何必须逐 bin 用 `(fft_size−N)/2`**：NC 的每个 bin 窗长不同，低频窗长、高频窗短。
若统一用帧中心当参考，则"能量被估计出的时刻"会随行产生 `(N−fft_size)/2` 样本的
系统性错位（高频端最多 8 列、低频端 1 列），对数 chirp 的直线会被**拉弯**；按上面
的约定则三条变体都落在真值线上。

### 幅度标定

每种方法 × 变体各用一个**单位幅度稳态正弦**（频率取最近的 log 行中心，避免频率插值
衰减）跑完整管线，取其图像最大值作为 0 dB 系数。因此"单位纯音 = 0 dB"在各
方法/变体间可比；chirp 这类铺开的信号自然落在 −20…−45 dB。

## 验证方法（多模态 + 数字图像分析）

`verify_log_chirp.py` 生成解析已知的对数 chirp
`f(t) = 25 Hz·2^(4.5·t)`（2 s 覆盖 9 个八度 = 25 Hz→12.8 kHz），它在
(log f, t) 平面上**就是一条直线**，斜率已知（0.744 行/列）。指标同时来自两路：

**数值（不依赖图像）**

- `--selftest`：静止纯音的瞬时频率误差、群延迟偏移（应 ≈0）；单冲激的落点时刻
  （应与冲激真实时刻一致，检验"绝对时刻"约定与符号）。

**图像（`image_metrics.py`，纯 numpy）**

| 指标 | 含义 | 期望 |
|------|------|------|
| 脊线偏差 | 逐列能量重心（功率加权）与真值线之差（cent），中位/90 分位 | 越小越准 |
| 10-90 宽度 / 垂直宽度 | 列内能量的 10–90 分位宽度（oct），后者乘 `cosθ` 投影到垂直于轨迹 | 越小越锐 |
| 线上能量 | 真值线 ±50 cent 内的功率占该图总功率之比 | 越大越锐 |
| 虚假能量 | 离真值线 ≥200 cent 的功率占比（低频镜像、伪影） | 越小越干净 |
| Hough 直线 | 阈值（峰值下 25 dB）二值化后扫斜率，取最强直线：支撑比例、垂直 RMS、斜率 | 斜率应 = 真值，支撑高、RMS 小 |
| 每列峰数 | 每列超过阈值的局部极大值个数（多分量时 = 谱线条数） | 单分量 1，双分量 2 |

统计只取真值落在显示范围内的列；另给"限带 100 Hz–10 kHz"一版——NC 的窗长被
`max_window_s = 0.075 s` 夹住后，100 Hz 以下的 bin 带宽（13.3 Hz）远宽于该处行宽
（<1 Hz），属于已知的分辨率退化区，单独看不至于把低频的显示增亮算作算法缺陷。

## 窗长 N 的下限（为什么不能为了时间分辨率随便截短）

`probe_n_limit.py` 复现并定位了这件事：**N 不能任意小，它被 bin 自己的中心频率
锁住**——因为左右分量必须是"同一个长度 N 的 DFT 的相邻两箱"，这个前提在小 N 下
会塌掉。

### 机理

纯音居中在 `f_c` 时，单个分量的输出是「正频主瓣 + 负频镜像」两项之和：

```
X(f) = (A/2)[ e^{−jφ}·D(2π(f_c−f)/Fs) + e^{+jφ}·D(2π(−f_c−f)/Fs) ]
```

1. **硬边界（检测器失效）**：左分量 `f_left = f_c − Fs/(2N) ≤ 0` 时，它不再是
   "更低频的邻箱"，而与 `f_c` 的负频镜像重合（镜像/主瓣 = 1）。此条件等价于

   ```
   N > Fs/(2 f_c)      ⟺      bin 带宽 Fs/N < 2 f_c      ⟺      窗内至少半个周期
   ```

   越过这条线后 `X_R·conj(X_L)` 不再是"负相关"，输出抖动 CV 从 0.06 跳到 0.49，
   且均值明显偏离 `A/π`（0.73~1.22 倍），bin 彻底不可用。
2. **渐进衰减（镜像泄漏）**：`N ≫ Fs/(2f_c)` 时镜像仍与正频主瓣在叉积里形成
   `e^{±2jφ}` 交叉项 → 输出叠加一个 **2·f_c 的拍**。实测抖动主频恒为 2·f_c，
   幅度由「镜像/主瓣」比决定：

   | 镜像/主瓣 | 周期数 Nf_c/Fs | CV | 结论 |
   |---|---|---|---|
   | 0.026 | 10 | 0.0% | 干净 |
   | 0.143 | 2 | 1.1% | 可用 |
   | 0.333 | 1 | 5.1% | 勉强 |
   | **1.000** | **0.5** | **48.6%** | **硬边界** |
   | ≥1.3 | <0.5 | 60~77% | 失效，均值也错 |

   工程规则：`N ≳ Fs/f_c`（1 个周期）抖动约 5%，`N ≳ 2Fs/f_c` 约 1%；
   论文/本目录的自然设计（每个 bin ≈ 44 个周期）总是安全。注意镜像比随 N 呈
   **梳状**振荡（`|sin(π(f_c+f)N/Fs)|`），所以别贴着边界取，留 2 个周期以上余量。

   图 `output/n_limit_map.png`：左图是 `(f_c, N)` 平面上的镜像/主瓣（含硬边界线与
   1/2 周期线），右图证明解析污染度能预测实测抖动。

### 第二条独立约束：N ≥ hop（与 f_c 无关的采样问题）

逐帧读出的 NC 输出每 hop 个样本采一次；对瞬态而言检测器只在窗内位置的中间一半
给正值，于是单帧栅格上的检出概率

```
P(检出瞬态) ≈ min(1, N/(2·hop))
```

`N < 2·hop` 时瞬态会被整帧漏掉（显示闪断）。实测（hop=256，`probe_n_limit.py`）：
N=512 → 1.00，N=256 → 0.49，N=128 → 0.32，N=64 → 0.10，N≤32 → <0.05。
这正是 C++ `WindowlessNcFrame` 为 `N < hop` 的箱准备逐样本 EMA 的原因——而当前
代码里那个分支的 `alpha` 被写成 `1.0`（等于**没有 EMA**），短窗箱的瞬态漏检因此
仍在，`--selftest` 里 310 个 bin 只有 233 个对冲激有响应就是它的表现。

### 显示级复现

`probe_n_limit.py` 把窗长上限调短，用同一段对数 chirp 看 [20, 120] Hz 段：

| `max_window_s` | N 上限 | 该上限下 `f_left=0` 的边界 | [20,120] Hz 线上能量 | 脊线偏差中位 |
|---|---|---|---|---|
| 0.075 s（默认） | 3600 | 6.7 Hz | **0.981** | 4 cent |
| 0.020 s | 960 | 25 Hz | 0.595 | 38 cent |
| 0.008 s | 384 | 62.5 Hz | **0.217** | 192 cent |

即：把窗长上限从 75 ms 压到 8 ms（为了时间分辨率）会让 **62.5 Hz 以下的 bin 整片
失效**，低频段从"锐利直线"退化成散点。图 `output/n_limit_display.png`。

### 结论

- 想缩短 N 只能**在 f_c 足够高的 bin 上做**；`f_c ≤ Fs/(2·N_short)` 的 bin 无论
  怎么调都不可用。
- 要"低频也要快时间响应"，不能靠截短 NC 窗——NC 检测器本身要求至少观测半个周期；
  该需求得换结构（例如加窗的短窗 STFT，或单独的宽带瞬态检测器）。

## 低频窗长：截短（C++ 默认）vs 理论 N（不截短）

本目录默认沿用了 C++ 的 `max_window_s = 0.075 s`，即 **N ≤ 3600、590 Hz 以下全部
截短**；理论值（式 7，`N ≈ Fs/W_NC ≈ 2.12e6/f_c`）在 25 Hz 处要 8.5 万样本
（1.8 s）。`verify_log_chirp.py --case window` 用同一段对数 chirp（前面垫 2.3 s
静音让长窗填满，等价于连续运行的实时系统）对比两种策略，**两者都做 NC 时频重分配**、
共用同一标定（1 kHz 标定频率在钳位点之上，所以两种配置的标定完全相同：
tf/plain = 0.3507/0.3183，dB 刻度可直接比）。

| 变体（低频段 20–120 Hz） | 线上能量 | 脊线偏差med | 虚假能量 | 10-90 宽度 |
|---|---|---|---|---|
| clamped（N≤3600）· tf | **0.9989** | 2.4 cent | 7.4e-7 | 0.0432 oct |
| free（理论 N）· tf | 0.8446 | 5.9 cent | 0 | 0.0787 oct |
| clamped · plain / freq / time | 0.514 / **0.9999** / 0.784 | — | — | — |
| free · plain / freq / time | 0.207 / 0.206 / 0.841 | — | — | — |

全带（20 Hz–20 kHz）同向：`clamped-tf` 0.999 vs `free-tf` 0.904。

**结论：不截短（纯理论 N）在重分配显示上更差，而不是更好**（图
`output/window_lowfreq_compare.png`：clamped 的线干净，free 的线发胖、发斑）。
原因是三条被实测钉死的效应：

1. **非平稳内容下 NC 增益 ∝ 1/N（塌缩）**。chirp 的 `|X|` 由驻定相位幅度决定、与
   N 无关，而 NC 归一化要除以 N，于是同一 bin 的峰值增益：clamped(N=3600) = 0.212，
   free(N=105617) = **0.0071 —— 正好小 30 倍（= N 之比，−29 dB）**。稳态纯音则
   `|X| ∝ N`、相除后增益与 N 无关（所以 1 kHz 标定两种配置完全一致、C++ 注释的
   `A/π` 才成立）。结果：超长窗的低频行对音乐/瞬态内容**沉到泄漏与噪声底之下**，
   "线上能量"里剩下的多是别的 bin 漏进来的东西。
2. **时间参考失效 + 每行响应拖长**。`plain`/`freq` 变体把能量放在**窗中心**，而
   窗中心只是"分析的当前时刻"的近似；N=2.2 s 时窗中心与真实能量到达时刻可差
   ±N/2 = ±1.1 s。更要命的是：chirp 穿过 bin 带内的驻留时间只有几毫秒，但这段
   驻留**留在窗内**的时间里该 bin 一直有输出 → 该行在时间上被拖成 **N 长的横条**
   （free-plain 低频段 0.207 vs clamped 0.514）。`free-freq` 同理崩到 0.183
   （全带 0.578）；`tf` 变体靠群延迟（驻留质心）把时间拉回来（0.792），但长窗内
   混入整段扫频带来的相位扰动会让落点散布——线变胖发斑而不是变锐。
3. **代价**：延迟 = 最长窗 = 2.2 s，卷积 FFT 长度 ~2^20。

也就是说，C++ 的 0.075 s 上限不是随手取的折中：它让窗长保持在**内容局部平稳尺度**
以内，从而同时保住 (i) 幅度归一化的意义（纯音 ∝ N）与 (ii) "窗中心 = 分析时刻"这个
重分配算子的前提；代价只是低频的镜像拍（20 Hz/N=3600 处 CV ≈ 2%，已在上一节量化）。
真要低频长窗，就得同时改归一化（按驻定相位/解析长度归一）和改时间参考（用群延迟本身
而不是窗中心），而不是单纯把上限拿掉。

## 超低频用几个周期的窗？（定向实验）

把测试 chirp 下探到 **12.5 Hz**（2 s 内 10 个八度，扫速 5 oct/s），让 20–40 Hz 那几个
`N < 2 周期` 的 bin 真正被激励，比较两类策略（`probe_n_limit.py --only period`，
图 `output/period_cap_compare.png`）：

- **纯周期上限**（`N ≤ k·Fs/f`，等于把全体 bin 的 Q 压到 k）——会同时改掉高频；
- **周期下限 + 保留 0.075 s 上限**（`N ≥ k·Fs/f`，只把超低频顶开，≥53 Hz 完全不变，
  标定与 N@1kHz 都保持原值）——这才是本问题真正要测的东西。

| 策略 | N@20Hz | 周期 | 延迟 | 标定 | 超低频 20–40Hz | 低频 20–120Hz | 全带 |
|---|---|---|---|---|---|---|---|
| 0.075 s 上限（现 C++） | 3600 | 1.50 | 75 ms | 0.3345 | 0.884 / 10.3c | 0.923 / 4.6c | 0.928 / 4.0c |
| 纯 2 周期上限 | 4799 | 2.00 | 100 ms | 0.6962 | 0.837 | 0.868 | 0.853 |
| 纯 4 周期上限 | 9599 | 4.00 | 200 ms | 0.8413 | 0.969 | 0.988 | 0.991 |
| 纯 8 周期上限 | 19199 | 8.00 | 400 ms | 0.8073 | 0.520 | 0.688 | 0.838 |
| 理论值（44 周期） | 105600 | 44.0 | 2200 ms | 0.3345 | 0.501 | 0.600 | 0.657 |
| 下限 2 周期 | 4800 | 2.00 | 100 ms | 0.3345 | 0.848 / 15.5c | 0.901 / 5.0c | 0.907 / 4.1c |
| **下限 4 周期** | 9600 | 4.00 | 200 ms | 0.3345 | **0.969 / 7.8c** | **0.985 / 5.3c** | **0.987 / 4.1c** |
| 下限 8 周期 | 19200 | 8.00 | 400 ms | 0.3345 | 0.520 / 23.1c | 0.691 / 11.0c | 0.762 / 5.0c |

逐 bin 数值探针（20 Hz bin，与图像无关）：

| N 的周期数 | 1.5 | 2 | 4 | 8 | 44 |
|---|---|---|---|---|---|
| 落点时刻误差(中位) | 38.3 ms | 29.1 ms | **5.3 ms** | 7.6 ms | 9.3 ms |
| chirp 峰值增益 | 0.323 | 0.316 | 0.287 | 0.159 | **0.030** |
| 镜像/主瓣 | 0.200 | 0.143 | 0.067 | 0.032 | 0.006 |

**答案：2 个周期是"检测器可用"的下限，但不是重分配显示的最优点。**

- 抖动/镜像比随周期数单调变好（2 周期 → CV ≈1%，4 周期 → 0.2%），这一半支持"至少 2 个
  周期"。但**估计器**（瞬时频率、群延迟）还要面对"窗内信号是否局部平稳"：
  `N ≫ 驻留时间`（信号穿过 bin 带宽所需时间 ≈ 带宽/扫速）时，`|X|` 由驻定相位幅度决定、
  与 N 无关，于是增益按 **1/N 塌缩**（20 Hz：8 周期 −6 dB、44 周期 −21 dB），
  且瞬时频率被整窗内容污染（44 周期时残差 1378 cent）；`N ≪ 驻留时间` 时 bin 带宽宽于
  扫频在窗内走过的范围，瞬时频率同样失去意义（2 周期时落点误差仍有 29 ms）。
  自洽解 `N ≈ 驻留时间` 给出 **k ≈ 2.4–3**，实测最优点 **k ≈ 4**。
- 所以：现 C++ 的 0.075 s 上限在 20–30 Hz 处只有 1.5–2.25 个周期，**略低于**甜点；
  给超低频加一条 **`N ≥ 4·Fs/f` 的下限**（≥53 Hz 完全不变、标定不变）可把低频段
  线上能量从 0.876 提到 **0.942**、全带 0.882→**0.946**，代价是 20 Hz 处延迟
  75→200 ms。
- 只在超低频加下限是安全的；把 Q 上限压到全局（"纯 k 周期"）会改变全体 bin 的带宽与
  幅度平衡（标定 0.3507→1.3600/0.6965），高频也会恶化，不要那样做。

## 频率估计器（改进记录）

### 原实现差在哪

原瞬时频率 = 左右分量各自求逐样本相位差、再按幅度加权平均（`if_estimator="weighted"`）。
两个毛病：

1. **矩形窗旁瓣污染**：两个分量都是长度 N 的矩形窗滑动 DFT，旁瓣只有 −13 dB、滚降
   −6 dB/oct，低频时负频镜像直接进相位。实测（对数 chirp，逐 bin、取最优时间参考后的
   残余误差中位）：

   | f_c | 25 Hz | 50 | 100 | 200 | 1 kHz |
   |---|---|---|---|---|---|
   | 原 `weighted` | 67.5 c | 14.7 | 24.2 | 29.6 | 6.7 |
   | `taper` | **22.5 c** | **12.4** | **12.1** | **23.1** | **2.4** |

2. **等效时间参考漂移**：拟合出的最优参考点 ≈ 0.9–1.1×(N−1)/2（本应 1.00）；而重分配
   把能量搬到"窗中心 + 群延迟偏移"，参考点漂移就等于**频率与落点不同步**。

### 改法

```
Y = X_R − X_L = −2j · Σ_m x[n−m] · sin(πm/N) · e^{−j2π·f_c·m/Fs}
```

即**同一个 NC bin 的两个分量之差，恰好等于对同一段样本做正弦锥（`sin(πm/N)`）加窗的
滑动 DFT**——零额外乘法（两个已有累加器相减），旁瓣低约 10 dB、滚降快一倍，镜像/旁瓣
污染随之大降；参考点也回到精确的窗中心（实测 α = 1.00）。

第二件事是**让频率跟着落点走**（锥形估计忠实于窗中心，而落点被群延迟搬走；不同步外推
反而把落点推离真值线）：

```
f_dep = f_center_ref + rate · (落点相对窗中心的偏移),   rate = d(IF)/dsample（IF 序列斜率）
```

`freq` 变体落点就在窗中心（偏移 = 0）→ 自动退化为窗中心处的频率，无需特判。

### 效果

| 估计器 | 变体 | 全带线上能量 | 脊线偏差 | Hough 支撑 | 垂直宽度 |
|---|---|---|---|---|---|
| `weighted`（旧默认） | tf | 0.9801 | 4.45 c | 0.315 | 0.04807 oct |
| `taper_center`（锥形不外推；诊断档） | tf | 0.9459 | 4.52 c | 0.285 | 0.05150 oct |
| **`taper`（现默认）** | **tf** | **0.9986** | **3.71 c** | **0.397** | **0.04610 oct** |
| `taper`（现默认） | freq | 0.9954 | 2.83 c | 0.334 | 0.05039 oct |

30–300 Hz 段：0.9784 → 0.9388 → **0.9985**。前后对比图
`output/if_estimator_compare.png`（上排整带、下排 20–300 Hz 放大）。

注：`taper_center` 这一档有意保留作诊断——它把估计本身改干净了，但端到端反而更差
（0.9459 < 0.9801），正是"参考点精确了、却与群延迟落点不同步"的直接证据；补上外推
即回到 0.9986。

纯音→横线、chirp→斜线、delta→竖线，三者的锐利度/连续性一眼可比。

（`compare_all.py` 现在只出图；数值对照仍由 `verify_log_chirp.py --case chirp/window`

| 方法 | 总 | 20–100Hz | 0.1–1kHz | 1–12kHz | 每列峰数 中位/均值 |
|---|---|---|---|---|---|
| `nc-floor4` 无窗 NC 时频重分配（超低频 `N ≥ 4 周期`） | **0.999** | 0.999 | 0.999 | 0.999 | 2 / 1.87 |
| `nc-cap` 无窗 NC 时频重分配（现 C++：0.075 s 上限） | 0.998 | 0.998 | 0.999 | 0.999 | 2 / 1.94 |

（"总"与各带 = 该范围内落在任一条真值线 ±50 cent 内的能量占比；分带是因为各方法的

看点：

- **重分配的价值**：同一个 NC 前端，`plain` 0.665 → `tf` **0.999**；低频段 0.418 → 0.999。
- NC 的 `tf` 现在**优于**标准 STFT（0.999/0.998 vs 0.985），`nc-floor4` 略优于现 C++ 的
  `nc-cap`；`nc-free`（理论窗长）在低频明显掉队（0.815 vs 0.998），与上一节结论一致。
- CQT（librosa，无重分配）是典型的恒定 Q 折中：高频 0.901（窗短、够锐），低频 0.062
  / 中频 0.289（窗长、时间上糊成一片），总量因此只有 0.151；面板里低频/角落的**饱和**

  它的每个频率行峰值时刻其实是对的——糊的是时间维。
- 每列峰数：五种 NC/STFT 都是 2（两条 chirp），CQT 是 5~6（低频长时间拖尾在每列造出
  多个极大值）。

方法来源：重分配与无窗 NC 用本目录 `nc_reassign.py`（与 C++ 三个帧逐算子对应）；
CQT 用已安装的 `librosa.cqt`（`bins_per_octave = 31` 使 Q ≈ 44，与显示 log 网格/NC
自然设计的 Q 一致，于是 CQT 的 310 个 bin 与显示 310 行一一对齐；librosa 没有重分配，
所以其余五种都用本目录实现）。

## 已知限制

- **低频段**：`max_window_s` 夹住窗长后，低频 bin 的带宽远宽于 log 行宽，能量在
  图上偏亮、并有少量横向散布（`plain` 就有，不是重分配引入的）。这与 C++
  `WindowlessNcFrame` 的低频行为一致。
- **冲激响应是稀疏的**：NC 的检测条件 `−(Re_L·Re_R + Im_L·Im_R) > 0` 等价于
  "冲激在窗内位置 ⟨m⟩/N ∈ (1/4, 3/4)"，配合帧步进（hop=256），310 个 bin 里只有
  233 个对冲激有响应（`--selftest` 会打印）。窗长比 hop 短的高频 bin 尤其如此，
  检出概率 ≈ `min(1, N/(2·hop))`（见「窗长 N 的下限」）；C++ `WindowlessNcFrame`
  对 `N < hop` 的箱另备逐样本 EMA，但当前代码里该分支 `alpha = 1.0`（未启用）。
- **多分量**：矩形窗旁瓣高，交叉点附近 NC·tf 会多出少量亮点（均值 2.61 峰/列，
  中位仍是 2）。
- 频率轴插值（双线性到相邻行）会让"正好落在两行之间"的能量衰减，标定频率因此取
  行中心；两个方法用同一规则，比较不受影响。
- 频率外推依赖 **IF 序列的斜率**（默认 `np.gradient`，离线用中心差分）：跨帧才有定义，
  所以每段开头 2 帧不外推。C++ 侧用**因果后向差分**（每 bin 存上一帧 IF）：实测中线
  0.9986 vs 因果 0.9977（差 0.1%），是离线/实时两种实现的固有差异。

  结论的 C++ 落地**——无窗 NC 重分配帧，低频带 `N ≥ 4 周期` 下限。**重分配只施加在
  `f_c < 1 kHz` 的 bin**（`reassignMaxHz` 参数，默认 1 kHz）：高频 NC bin 窗短、行宽，
  自身时频分辨率已经跟得上内容，搬瞬时频率/群延迟只会引入估计噪声，且要走网格的
  频率→行映射（bin 中心落在行带交界 → 双线性分到相邻两行）而变暗——实测 2/5/10/16 kHz
  的稳态纯音比不重分配暗 0.9/2.3/4.2/4.8 dB；本目录分带表里 `plain` 在 1–12 kHz 也已
  0.998（与全程重分配持平），而 20–100 Hz 只有 0.418。截止以上退化为 bin 中心 + 窗中心、
  直接落自身行，与 `WindowlessNcFrame` 逐像素一致（注意：本目录的 `tf` 是**全程**重分配，
  所以 1–12 kHz 段的 lab 数字不代表 C++ 现在的口径）。算子、时间参考、环缓冲
  尺寸按本 README 的推导实现；幅度沿用 π 归一化（与 `WindowlessNcFrame` 同刻度），显示
  整体滞后最长窗（4 周期下限下 200 ms）。**已同步本节的锥形 IF + 一阶外推**：`Y = acc_r − acc_l`
  求窗中心瞬时频率，斜率用**因果后向差分**（每 bin 存上一帧 IF，实时拿不到未来帧）——
  lab 实测因果版 0.9977 vs 离线中心差分 0.9986（差 0.1%）；C++ 侧做了数值对拍
  （1 kHz bin：窗中心 IF 991.80 Hz vs 解析 991.1 Hz≈+1 cent，外推项 = rate·offset 的
  符号与量纲一致；1 kHz 处速率 ±12%，来自单跳差分的 ±1 Hz 噪声）。三个变体由模板参数
  `WindowlessNcReassignFrame<ColorMap, NcReassignMode::kFreq|kTime|kFreqTime>` 选，
  demo 里分别是 `[` / `]` / `;` 键（"Windowless NC TF / Freq / Time"）。
- `tf_reassignment_frame.hpp` / `freq_*` / `time_*`：标准重分配的参照实现，
  本目录的 STFT 侧与它们逐算子对应（`zeroPad = 1`、BH 3 项窗、`roll` 求群延迟）。
