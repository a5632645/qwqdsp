# 时间拉伸后的目标相位梯度

## 坐标换算

采用窗中心为时间原点的 STFT，记 `P = ∂t φ`、`Q = ∂ω φ`。对固定采样率和 FFT 长度，物理 bin 间距 `Δω = 2π/M`。论文以整段信号长度归一化频率，分析边乘 `b_a`，合成边乘 `b_s = α b_a`。换回物理坐标，时间边用 `H_s·P_a`，频率边用 `Δω·αQ_a`。两项分析量均取 `t_a = t_s/α`。 [Phase Vocoder Done Right，式 (2)、(6)、(8) 和算法 1](https://arxiv.org/html/2202.07382v1)

因此，论文的连续目标场 `(P_a, αQ_a)` 是 `α·φ_a(t_s/α, ω)` 的梯度，在非零、光滑的局部相位区域闭合。直接复制物理梯度 `(P_a, Q_a)` 才会得到 `(1 − 1/α)·∂t∂ωφ_a` 的旋度。离散差分、解缠及多锚点会另外引入积分冲突。闭合的相位场还需要与合成窗和幅度共同匹配。

## 单分量 Gaussian 模型

设 `σ` 为 Gaussian 窗标准差，`k` 为输入角频率变化率，`Ω` 为当前输入时刻的瞬时角频率，`β = kσ²`。局部线性 chirp 的解析梯度为

```text
P = Ω + β²/(1 + β²) · (ω − Ω)
Q = −σ²β/(1 + β²) · (ω − Ω)
```

保音高地拉伸 `α` 倍后，配对帧的 `Ω` 相同，chirp rate 变成 `k/α`。用相同窗合成时，将公式中的 `β` 换成 `β/α`，两个方向的目标梯度都会变化。`Q_target/(αQ_analysis) = (1 + β²)/(α² + β²)`，包括通往短窗和长窗的两个极限。如果合成窗宽度选 `σ_s = √α·σ_a`，单线性 chirp 的解析相位梯度恰好与论文的 `(P_a, αQ_a)` 一致，目标频谱幅度仍由该合成窗决定。

实验从输入计算三张 STFT，窗分别为 `g`、`(u/σ)g`、`(u/σ)²g`。设 `μ = C₁/C₀`、`ν = C₂/C₀`，则 `h = μ² − ν` 是归一化的二阶对数谱导数。单线性 chirp 满足 `1/h = −1 + jβ`、`−jμ/h = σ(ω − Ω)`。据此估计 `β` 和 `Ω`，用 `β/α` 计算合成梯度。偏离这两个关系的 bin 回退到论文式梯度。这个筛选是局部模型检验，相交分量仍可能通过。 [二阶重分配与线性 chirp 模型](https://membres-ljk.imag.fr/Valerie.Perrier/PUBLI/sst2-TSP2014.pdf)

## 数值结果

48 kHz，合成 hop 128，Gaussian 分析与合成窗相同。参考由保持瞬时频率轨迹、将各分量 chirp rate 除以 `α` 的波形直接采样。所有梯度方案使用相同的幅度优先全局堆和输入 STFT 幅度。各连通分量用同一个参考相位定标，便于测量积分出来的相位误差。表中 `目标边` 从真实目标波形的 STFT 获取相位步长，仍用输入幅度，作为幅度误差的对照。波形 SNR 在去掉边界后的输出上直接计算，不做延时或增益拟合。

| 2× 输入 | Gaussian σ | 论文中心差分 SNR | 估计并修正梯度 SNR | 目标边 SNR |
| --- | ---: | ---: | ---: | ---: |
| 单 chirp | 1 ms | 24.16 dB | 48.47 dB | 48.47 dB |
| 单 chirp | 4 ms | 13.52 dB | 26.06 dB | 26.06 dB |
| 单 chirp | 8 ms | 18.08 dB | 20.03 dB | 20.03 dB |
| 双 chirp 相交 | 4 ms | 18.47 dB | 15.65 dB | 26.70 dB |

单 chirp、σ = 4 ms、2× 时，直接复制物理梯度的小格闭合 RMS 为 0.0787 rad，按论文比例换算的解析梯度约为 `7e-15` rad。后者的积分相位 RMS 仍为 0.258 rad，与中心差分相同。估计修正后的相位 RMS 为 `1.9e-11` rad。把目标的幅度和相位一起交给 WOLA 可在数值精度内重构参考，说明此处修正到 26.06 dB 后的误差来自沿用输入幅度。

双 chirp 相交、σ = 4 ms、2× 时，修正后的相位 RMS 从 0.230 降到 0.174 rad，波形 SNR 却下降。该配置下，目标相位与输入幅度的组合还有可测的误差，局部拟合误差也会经积分扩散。把单 chirp 的修正直接用于相交成分，收益随窗宽和倍率而变。实际约 1.506×、σ = 4 ms 的单 chirp 也从 19.24 dB 提升到 33.34 dB，交叉样本则从 25.97 降到 20.39 dB。

## 相位与幅度联合修正

给每个 bin 计算一个标量相位修正 `D`，再给任意传播边 `u → v` 加上 `D(v) − D(u)`。绕闭环时这项增量相消。即使局部模型的置信度随时频位置变化，这种写法也保留已有的小格闭合误差。

对于单分量 Gaussian 模型，记 `d = σ(ω − Ω)`、`β_s = β/α`，窗内频谱的相位和对数幅度项为

```text
F(β, d) = [atan(β) − β d²/(1 + β²)]/2
L(β, d) = −log(1 + β²)/4 − d²/[2(1 + β²)]
D       = F(β_s, d) − α F(β, d)
logGain = L(β_s, d) − L(β, d)
```

同一个模型置信度衰减 `D` 和 `logGain`。幅度增益只在 WOLA 前施加，堆优先级保持基于分析幅度，便于测量幅度修正的独立作用。`retuned-direct-potential` 以直接相位边为基线，`retuned-potential` 以窗矩算出的论文式梯度为基线。加 `-magnitude` 的变体同时使用幅度增益。

| 2×、σ = 4 ms | 直接差分 | 直接边加相位修正 | 再加幅度修正 | 目标梯度配输入幅度 |
| --- | ---: | ---: | ---: | ---: |
| 单 chirp 波形 SNR | 13.52 dB | 26.06 dB | 144.64 dB | 26.06 dB |
| 相交 chirp 波形 SNR | 18.47 dB | 5.64 dB | 5.47 dB | 26.70 dB |

相交样本中，直接边加相位修正前后的小格闭合 RMS 均约为 `1e-14` rad。相位误差仍从 0.229 增到 0.547 rad。闭合度能验证积分是否与路径一致，目标波形 SNR 还取决于局部模型是否适用。相交时一个 bin 含有多个分量，基于其复数和拟合出的局部参数可能通过置信度筛选。单 chirp 的幅度收益是在模型匹配、使用参考种子相位的双精度合成实验中测得。

## 复现

```powershell
python qwqdsp/labs/rtpghi/chirp_gradient.py --ratio 2 1.5 --out temp/rtpghi/chirp-gradient-potential
python -m unittest discover -s qwqdsp/labs/rtpghi -v
```

默认在 `temp/rtpghi/chirp-gradient` 写出 WAV、CSV 和图。CSV 同时记录时间边、频率边的误差及模 `2π` 的小格闭合误差。当前验证针对 Gaussian 和合成 chirp，合成相位定标使用了参考信号。
