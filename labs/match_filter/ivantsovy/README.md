# ivantsovy — §4 一般形式、双点匹配与精确频率映射

Ivantsov《On the Ideal Bilinear and Biquadratic Digital Filter》
（2026，<https://ivantsovy.com/research/paper1.pdf>）第 4 节的逐因子映射在本目录
被完整实现并数值验证；由它导出的**双点解**把截止/中点与 Nyquist 同时精确匹配；
该变换还存在一条**精确的频率映射**，下面给出闭式与"三点钉死"的形式。
与 Vicanek `match_biquad` 的对照见 `../vicanek/`。

## 映射（§4 一般形式）

连续传递函数写成常数项为 1 的因子串：

```
H(S) = gain · S^m · ∏(1 − S/z_i) / ∏(1 − S/p_i),    S = s/(2π f_ref)
```

| 因子 | 映射 |
|---|---|
| `a S + 1` | `(1 + c z⁻¹)/(1 + c)`，`c = φ(ωa)`（`a < 0` 取 `1/φ`） |
| `a S² + b S + 1` | `(1 + c₁ z⁻¹ + c₂ z⁻²)/(1 + c₁ + c₂)`，(4.4)–(4.6) |
| 原点零点 `S` | `(1 − z⁻¹)·ω/(2π)` |
| 阶数亏欠（`S → ∞`） | `a = 0` 的退化一次因子 |

其中 `ω = fs/f_ref`、`φ(x) = (π − √(x² + σ²))/(π + √(x² + σ²))`。每个因子在
`z = 1`（直流）归一为 1，模拟增益原样保留。响应按因子串联求值——高阶展开成 z
多项式会病态。`s = 0` 处的**极点**（积分器）没有对应规则，入口处显式拒绝；
`s = 0` 的零点按第二行映射，因此 LP / HP / BP / BS 与各种 shelf 都覆盖。

## 论文的自由参数 σ

`σ` 只影响一件事：数字 Nyquist 的增益对应到模拟原型的哪个频率。论文取 (2.5)
`Ω_D(fs/2) = Ω_A(fs/σ)`，于是

- 截止频率的精确位置是 `F(ω) = fs/(2π)·arccos((ω² − π² − σ²)/(ω² + π² − σ²))`；
- 要让截止精确落在 `f_ref`，只能改一处：改 `ω`（预畸变，(2.10)）或改 `σ`
  ((2.11))，两者互斥。

`σ ∈ [2, π√(2/3)]` 时整体幅度误差最小；`σ = 0` 退化为标准双线性（相位最优，
Nyquist 处发散）。48 kHz / f_ref = 5 kHz 下的四组配置：

| 配置 | Butter maxlin | Butter ≥−60 dB | Cheb2 maxlin | Cheb2 ≥−60 dB | `f_ref` 处 Δ | Nyquist 匹配点 |
|---|---|---|---|---|---|---|
| σ=π√(2/3)，无预畸变 | `1.59e-3` | 0.915 dB | `1.47e-4` | 0.057 dB | +0.014 / +0.214 dB | 18.71 kHz |
| σ=2，无预畸变 | `4.66e-2` | 4.867 dB | `1.62e-2` | 2.432 dB | −0.506 / −12.30 dB | 24.00 kHz（精确） |
| σ=2，预畸变 | `1.00e-2` | 3.908 dB | `3.51e-2` | 0.708 dB | 0 / 0 dB | 23.67 kHz |
| σ=π√(2/3)，预畸变 | `7.37e-4` | 0.888 dB | `1.30e-3` | 0.029 dB | 0 / 0 dB | 18.72 kHz |

（原型：Butterworth N=8、Chebyshev II N=8 / 80 dB，截止或阻带边沿 5 kHz；
"Nyquist 匹配点"是数字 Nyquist 精确等于模拟原型之处的频率。maxlin 是全频段
`max|Hd − Ha|`。）

默认配置（σ = π√(2/3)、无预畸变）的细节：

| 指标 | Butterworth N=8 | Chebyshev II N=8 |
|---|---|---|
| ≥ −20 dB 内 `max\|ΔdB\|` | 0.085 | 0.007 |
| ≥ −40 dB 内 | 0.279 | 0.020 |
| ≥ −80 dB 内 | 3.05 | 0.214 |
| 最大数字极点模 | 0.880 | 0.943 |
| 数字零点 | 8 个亏欠零点，`z = −0.1010` | 6 个在单位圆上，2 个在实轴 `z = −0.2838` |

## 双点解：截止与 Nyquist 同时精确

把 `ω` 与 `σ` 都当未知量，(2.5) 的 Nyquist 条件与截止条件联立后，一阶高通、低通、
shelf 以及二阶高通、低通、带通、带阻共用同一组解。记 `u = fs/fc`（要求
`fc < fs/2`）：

```
ω = π cot(π/u) / √(1 − 4/u²)
σ = 2ω / u
```

截止条件对各类原型都是 `cot²(θc/2) = (ω² − σ²)/π²`；Nyquist 处高通幅度为
`ω/√(ω² + σ²)`、低通为 `σ/√(ω² + σ²)`，两者都要等于模拟原型的 `u/√(u² + 4)`，
这就是 `σ = 2ω/u`，代回即得上式。

性质：

- `σ` 不再是自由参数，且恒 `≤ 2`。`u → ∞` 时 `(ω, σ) → (fs/fc, 2)`（退化为论文
  `σ = 2` 的无预畸变设计）；`u → 2` 时两者同趋于 0、极点趋于 `z = −1`，解退化。
- 因此双点解总在论文的幅度最优区间 `[2, π√(2/3)]` 之下。
- `fc ≥ fs/2` 无解：映射的 `F(ω)` 到不了 `fs/2`，30 kHz 以上只能用更高采样率。

## 精确频率映射

对任意由上面的因子规则构造的原型，幅度响应满足

```
|Hd(e^{jθ})| = |Ha(jρ(θ))|,
ρ(θ) = (ω/π)·tan(θ/2) / √(1 + (σ/π)²·tan²(θ/2)),    y = fc·ρ
```

推导一步到位：一次因子 `1 + aS` 的数字幅度是 `√(cos² + κ² sin²)`
（`κ = √(ω²a² + σ²)/π`），提出 `M0 = √(cos²(θ/2) + (σ/π)² sin²(θ/2))` 后正好等于
`M0·|1 + jaρ|`；原点零点 `(ω/π)sin(θ/2)` 也等于 `M0·ρ`。`M0` 在分子分母出现同样
多次（亏欠因子补齐）而相消，所以整条映射与阶数、类型无关。

- `σ = 0` 时退化为双线性 `ρ = (ω/π)tan(θ/2)`（Nyquist 处发散）；
- `σ > 0` 时 `ρ(π) = ω/σ` 有限；双点解给出 `ρ(π) = u/2`，Nyquist 精确映到 `fs/2`。

以 Nyquist 归一后只剩一个形状参数 `A = σ/π`：

```
y/(fs/2) = sin(arctan(A·tan(θ/2)))
```

这条曲线通过 `(0, 0)` 与 `(Nyquist, Nyquist)`，且必然通过 `(fc, fc)`；后者反过来
把 `A` 唯一确定：

```
A = x_c / (tan(π x_c/2)·√(1 − x_c²)),    x_c = 2fc/fs
```

与 `σ/π` 逐点吻合到机器精度。所以三点同时匹配时映射**没有剩余自由度**，高频段
被压平是唯一解，不是参数没调好。`x_c → 1` 时 `A ≈ (π/2)√((1 − x_c)/2) → 0`；
`x_c → 0` 时 `A → 2/π ≈ 0.637`，曲线与 `fc` 无关。

| fc | u | 映射 y(Nyquist/2) /(fs/2) |
|---|---|---|
| 20 / 117.6 / 691.4 Hz | 2400 / 408 / 69 | 0.537 |
| 4065 Hz | 11.8 | 0.533 |
| 23.9 kHz | 2.008 | 0.071 |

23.9 kHz 档的低频斜率只有 `ω/u = 0.112`：数字 0.5·Nyquist 处对应的模拟频率只剩
0.071·Nyquist。高通一族在固定频率上看到的"低频塌陷"就是这个频率压缩，不是增益
出错。

## 各原型的验证

一 / 二阶图与表统一取 5 个截止频率：20 / 117.6 / 691.4 / 4065 / 23900 Hz
（对数等分、含端点，fs = 48 kHz，即 u = 2400 … 2.008）。图里画整条响应（模拟实线、
双点解虚线），表中数字是各自频段的极值。所有类型在匹配点上的误差都是机器精度
（1e-11 量级；`u = 2400` 时 biquad 系数量级悬殊，只剩 ~1e-11 的求值精度）。

**高通。** 两个匹配点精确，代价是低频斜率缩到 `ω/u`：

| fc | u | ω | σ | max\|ΔdB\| 全带 | f ≥ 0.9fc | 低频偏移 |
|---|---|---|---|---|---|---|
| 20 Hz | 2400 | 2399.9995 | 2.000000 | 0.0000 | 0.0000 | 0.00 |
| 117.6 Hz | 408.2 | 408.1933 | 1.999985 | 0.0001 | 0.0001 | −0.00 |
| 691.4 Hz | 69.43 | 69.4082 | 1.999465 | 0.0023 | 0.0022 | −0.002 |
| 4065 Hz | 11.81 | 11.6973 | 1.981212 | 0.0820 | 0.0546 | −0.082 |
| 23.9 kHz | 2.008 | 0.225480 | 0.224541 | 18.99 | 5.10 | −18.99 |

偏差在低频最大、到 `fc` 归零，`fc` 与 Nyquist 之间最多 +0.06 dB。23.9 kHz 档
贴着 Nyquist（`ω/u = 0.112`），低频电平塌 19 dB，这是 `u → 2` 的固有极限。

**全部类型同一口径**（模拟原型 ≥ −20 dB 的频段内 `max|ΔdB|`）：

| fc | u | 一阶HP | 一阶LP | 高shelf | 低shelf | 二阶HP | 二阶LP | 带通 | 带阻 |
|---|---|---|---|---|---|---|---|---|---|
| 20 Hz | 2400 | 0.0000 | 0.0002 | 0.0000 | 0.0000 | 0.0000 | 0.0000 | 0.0004 | 0.0000 |
| 117.6 Hz | 408.2 | 0.0001 | 0.0065 | 0.0002 | 0.0002 | 0.0001 | 0.0012 | 0.0134 | 0.0002 |
| 691.4 Hz | 69.43 | 0.0023 | 0.2192 | 0.0078 | 0.0078 | 0.0041 | 0.0411 | 0.4320 | 0.0056 |
| 4065 Hz | 11.81 | 0.0803 | 0.9005 | 0.1596 | 0.1596 | 0.1459 | 1.2597 | 0.9373 | 0.1898 |
| 23.9 kHz | 2.008 | 18.8802 | 2.0343 | 4.1856 | 4.1856 | 36.4468 | 2.1272 | 18.9593 | 16.7667 |

读表的线索：

- 带原点零点的一族（一阶/二阶高通、带通）在 `u → 2` 时按 `(ω/u)` 的幂塌陷：
  一阶与带通是 `20log10(ω/u)`（−19 dB），二阶是 `40log10(ω/u)`（−38 dB）。
  低通、shelf、带阻没有这一项。
- 低通残差集中在 Nyquist 附近，`fc` 越低越深：20 Hz 档 0.97 dB 处模拟已低于
  −59 dB；4065 Hz 档 0.90 dB（−13 dB）。通带 `f ≤ 0.7fc` 内，除 23.9 kHz 档
  （1.65 dB）外都不超过 0.014 dB。
- 二阶低通的 1.93 dB 出现在 17.9 kHz、模拟已低于 −118 dB（20 Hz 档）；`fc` 越高
  这一项越往过渡带挪，23.9 kHz 档为 +2.13 dB。
- 带通峰值恒为 1、带阻陷波恒为 0；带阻的数字零点精确落在单位圆上的
  `e^{±jθc}`。

**shelf 匹配三点。** 一阶 shelf 的"截止点"是半增益点（幅度 `√g`），条件化简后
仍是 `cot²(θc/2) = (ω² − σ²)/π²`；Nyquist 处高 shelf 幅度
`√(ω²g + σ²)/√(ω²/g + σ²)`，与模拟原型在 `fs/2` 相等同样给出 `σ = 2ω/u`——`g`
在两个条件里对消。DC 增益由因子归一化自动精确（高 shelf 为 1、低 shelf 为 `g`），
所以精确匹配 **DC、中点、Nyquist** 三点（`g` 是 `s → ∞` 的渐近值，数字端只逼近）。
`−12 dB` 与 `+12 dB` 的误差完全相同：数字 shelf 满足
`|H_{+b}|·|H_{−b}| = 1`，与模拟原型一致，互逆到机器精度。残差集中在拐点附近，
约按 boost 线性增长。

**二阶。** 同一组 `(ω, σ)` 直接适用。除上面的映射论证外，逐因子看也是一句话：
在 `θc = 2πF(ω)/fs` 处，一次因子（含 `a = 0` 与原点零点）的数字幅度是对应模拟
因子在 `S = j` 处的 `r = ω/√(π² + ω² − σ²)` 倍，二次因子是 `r²` 倍；分子分母
总次数相同，`r` 的幂次相消。验证覆盖 ζ = 0.5 / 1/√2 / 0.9 / 1.2（含实极点）与
全部 5 个尺度。ζ = 1/√2 时 `|H(fc)|` 恰为 `1/√2`，其它 ζ 匹配的是模拟原型在
`fc` 处的 `1/(2ζ)`（二阶的 fc 是极点频率，−3 dB 点不在那里）。逐系数与
Table 3.1 一致：ζ < 1 走二次因子分支，ζ ≥ 1 走实根的一次因子分支。两元方程另有
一支 `σ ≫ ω` 的根同样满足两个匹配点，但整体偏差 43 dB，不取；闭式解是 `σ ≤ 2`
的物理分支。

**二阶 shelf。** 原型把 `S² + 2ζS + 1` 的根按 `g^{±1/4}` 缩放（分子、分母各一对
根，所以指数是 1/4 而不是一阶的 1/2），中点增益 `√g` 仍在 `fc`。按 `Q = 1/(2ζ)`
取两组阻尼：

| Q | ζ | max\|ΔdB\|（≥ −20 dB 内，5 档同上） |
|---|---|---|
| `√2/2` | 0.7071 | 0.0000 / 0.0001 / 0.0026 / 0.0870 / 4.52 |
| 6 | 0.0833 | 0.0000 / 0.0004 / 0.0149 / 0.5022 / 17.02 |

高 / 低 shelf 数值相同（互为镜像）。`Q` 越大零点对的谐振越明显：`+12 dB` 的棚在
`fc` 之后先上冲（`Q = 6` 时到 +25 dB）再落回棚顶，`fc` 之前下冲到 −12 dB。这是
Table 3.1 那组 shelf 系数在低阻尼下的固有形状，模拟与数字按同一解析式给出，差值
就是上表。

**带通 / 带阻对照。** σ = 2 无预畸变时带阻的陷波根本不在 `fc`（`u = 2.4` 时
`|H(fc)| = 0.198`，只有 −14 dB 深度）；预畸变 + σ = 2 能放准陷波，但 Nyquist
偏 53%。

**实现要点。** `ν + κ` 在 `b = 0`（纯虚轴零点）且 `x > σ` 时解析上为 0，直接相减
只剩舍入噪声；实现按 `κ < 0` 时用 `(ν² − κ²)/(ν − κ)` 求值，于是 `φ₂ = 1`、
带阻零点精确落在单位圆上、深度到机器精度。

## 高阶原型（§4 的直接验证）

同一套因子规则对高阶原型工作，模拟增益原样保留。两族原型（BP / BS 边沿 4–6 kHz，
σ = π√(2/3) + 预畸变）：

| 类型 | Butterworth N=4 maxlin / ≥−20 dB | Chebyshev II N=8, 80 dB maxlin / ≥−20 dB |
|---|---|---|
| LP | `3.2e-3` / 0.124 dB | `1.3e-3` / 0.029 dB |
| HP | `3.0e-4` / 0.012 dB | `1.5e-2` / 0.225 dB |
| BP | `3.5e-3` / 0.113 dB | `5.8e-3` / 0.159 dB |
| BS | `3.1e-3` / 0.058 dB | `1.2e-2` / 0.260 dB |

无预畸变时 N = 4 / 8 / 7 的 maxlin 分别不超过 `6.4e-3` / `1.9e-2` / `2.7e-2`。
奇数阶 Chebyshev II 的高通 / 带通会出现原点零点，由 `(1 − z⁻¹)` 规则处理。
二阶特例与 Table 2.1 / 3.1 逐系数一致。

**Chebyshev II 的虚轴零点。** 纯虚轴零点对应 `b = 0` 的二次因子：零点频率低于
`fs/σ` 时 `c₂ = 1`，数字零点严格落在单位圆上，阻带零点频率与模拟值最大偏差 0.43%
（5100 / 6018 / 9039 Hz 对 5098 / 6013 / 9000 Hz）。模拟零点 25.6 kHz 高于 Nyquist
时 `c₂ < 1`，该对零点落到实轴（`z = −0.2838`），无法再形成零陷——采样率限制，
不是映射失效。−80 dB 等波纹阻带与零点结构都保持。

**增益约定。** scipy 的 zpk 增益不能直接当作本实现的 `gain`：换算成"原点零点 +
常数项 1 因子"形式后，模拟响应才与 `signal.freqs_zpk` 一致。Chebyshev II 低通的
zpk 增益是 `1e-4`，直接使用会整体低 80 dB。

**High shelf。** scipy 没有现成原型，按 `iir_design_shelf.hpp` 的构造复刻：
Butterworth 用 `z = p/s`、`p = p·s`、`s = (10^(boost/20))^(1/N)`；Chebyshev II 取
两个自然归一化的 `cheb2ap` 原型，一个的极点作 shelf 极点、另一个的作零点（传输
零点对消），再乘频率尺度把中点放到 1 rad/s。scipy 没有偶数阶修正原型，故
`even_modify = False`：高频端落在 `boost ∓ ripple` dB，而棚带内极值仍在有限频率
达到 `boost` dB——这是模拟原型本身的性质，不是离散化误差。fs = 48 kHz、
f0 = 1 kHz、σ = π√(2/3) + 预畸变：

| 案例 | `max\|ΔdB\|`（20 Hz–Nyquist） |
|---|---|
| Butterworth N=8，±12 dB | `< 1e-4` |
| Chebyshev II N=8，ripple 1 dB，±12 dB | 0.062 |
| 同上，f0 = 5 kHz | 0.380 |
| Chebyshev II N=8，ripple 3 dB，+12 dB，f0 = 5 kHz | 1.229 |
| Chebyshev II N=16，+24 dB，ripple 3 dB，f0 = 5 kHz | 2.390 |

误差随阶数、boost、ripple、f0 增长；42 组组合（N = 4/8，±12/±24 dB，
ripple 0.5/1/3 dB，f0 = 1k/5k，另加 N = 16 压力项）全部稳定。

## 怎么选

- **只追求整体幅度精度**：论文默认 `σ = π√(2/3)`、无预畸变。Butterworth N=8 的
  maxlin `1.59e-3`，Chebyshev II `1.47e-4`。
- **必须精确截止**：加预畸变。`σ = π√(2/3) + 预畸变` 的整体误差更小
  （`7.4e-4` / `1.3e-3`），但 Nyquist 匹配点落在 18.72 kHz；`σ = 2 + 预畸变`
  让 Nyquist 匹配点到 23.67 kHz，代价是通带 / 过渡带误差增大。
- **截止与 Nyquist 都要精确**（一阶或二阶，任意以上类型）：用双点解。`σ` 被确定
  在 2 以下；高通一族付出 `20log10(ω/u)` dB 的低频衰减（二阶加倍），低通 / shelf /
  带阻的残差集中在高频端（4 kHz 档 ≤ 0.9 dB；23.9 kHz 档分别为 2.0 / 4.2 / 16.8 dB）。
  `fc → fs/2` 时映射必然压平（见上文"三点钉死"），这是约束的代价，不是实现误差。

## 限制

- 只支持实系数、因果、无 `s = 0` 极点（积分器）的有理函数；`s = 0` 的极点会显式
  报错。右半平面极点用 `φ` 的倒数分支，论文提醒存在除零的截止频率，实现对此报错。
- 逐因子映射，高阶时误差累积；高阶表是 N = 8 的实测值。
- 只验证幅度，不涉及相位；论文指出 `σ = 0` 时相位最优，`σ` 落在幅度区间时会有
  相位偏差。
- `fc ≥ fs/2` 无解；双点解在 `u → 2` 时退化（`ω, σ → 0`，极点趋 `z = −1`）。
