# constraint_fit — 一/二阶滤波器：硬约束与有理插值

数字二阶节的功率函数在

    x = sin²(w/2)

下是 2/2 有理函数

    P(x) = (n0 + n1 x + n2 x²) / (1 + d1 x + d2 x²)。

归一化后正好 5 个未知数，所以「在 5 个节点上令 P = Pa」天然是一个
5×5 线性方程组：不需要非线性求根，也不需要预先锁定分子。**分母不是被
额外约束定死的，而是插值的结果**；设计自由度是节点的位置。

## 有理逼近的等幅交替

零缺陷的 n 阶有理最佳逼近在 **2n+1** 个节点上插值，误差在 **2n+2** 个点
等幅交替（Chebyshev 交替定理）。这里 n = 2：5 个节点、6 个交替极值。

BRASIL（Hofreither, RICAM 2020-37）把这条定理变成迭代算法：反复调整
5 个节点把区间切成的 6 段长度，让每段的最大 |ΔdB| 相等。它只动插值节点，
不动极点；线性收敛，600 轮足够。

结果（fs = 48 kHz，全带 max|ΔdB|）：

| fc / Hz | max\|ΔdB\| | 节点（x） |
|---:|---:|---|
| 20 | 0.0795 | 0 / 0.203 / 0.823 / 0.981 / 0.9997 |
| 117.6 | 0.0793 | 0.00006 / 0.214 / 0.824 / 0.981 / 0.9997 |
| 691.4 | 0.0777 | 0.0016 / 0.240 / 0.829 / 0.982 / 0.9997 |
| 4065 | 0.0676 | 0.023 / 0.382 / 0.863 / 0.985 / 0.9998 |
| 23900 | 0.0259 | 0.112 / 0.639 / 0.930 / 0.992 / 0.9999 |

两个容易踩的点：

- **节点必须向 x = 1 聚集**。目标在 x → 1 处有平方根型边界奇点，Nyquist 端
  的相对误差通常是全带最大；均匀的 Chebyshev 节点在低频端会差到 16 dB。
- **首末区间要把 x = 0 与 x = 1 计入误差最大值**，否则迭代看不见边界超调，
  会静默收敛到次优解。

## 一阶高通

高通在直流处必须为零，分子只能从一次项开始：

    P(x) = x (n1 + n2 x) / (1 + d1 x + d2 x²)

只剩 4 个自由参数，所以是 4 个节点、4×4 线性方程组；最佳逼近在 5 个点
等幅交替，BRASIL 把区间切成 5 段等化。直流处两者都为 0，dB 误差取极限
`n1·wc²/4` 并计入全带。

| fc / Hz | max\|ΔdB\| | 节点（x） |
|---:|---:|---|
| 20 | 1.1e-7 | 0 / 0.335 / 0.924 / 0.999 |
| 117.6 | 3.7e-6 | 0.00005 / 0.345 / 0.925 / 0.999 |
| 691.4 | 1.3e-4 | 0.0016 / 0.380 / 0.928 / 0.999 |
| 4065 | 3.8e-3 | 0.029 / 0.527 / 0.943 / 0.999 |
| 23900 | 4.8e-2 | 0.147 / 0.756 / 0.972 / 0.9996 |

对照三点匹配 + 等波纹极点：1.5e-7 / 5.3e-6 / 2.2e-4 / 6.2e-3 / 2.1e-1。
高通在 dB 度量下比低通容易得多——响应在大部分频带接近 0 dB，误差集中在
直流附近很窄的过渡区。

## 二阶低通

二阶低通的功率在 `x` 下仍是 2/2 有理函数，直流增益固定为 1（分子常数项
为 1），剩 4 个自由参数：

    P(x) = (1 + n1 x + n2 x²) / (1 + d1 x + d2 x²)

4 个节点 → 4×4 线性方程组，5 个交替极值。结果（max|ΔdB|）：

| Q \ fc | 20 | 117.6 | 691.4 | 4065 | 23900 |
|---:|---:|---:|---:|---:|---:|
| 0.5 | 0.429 | 0.428 | 0.420 | 0.382 | 0.050 |
| 0.707 | 0.430 | 0.428 | 0.424 | 0.395 | 0.060 |
| 1 | 0.430 | 0.430 | 0.427 | 0.409 | 0.070 |
| 2 | 0.436 | 0.435 | 0.434 | 0.431 | 0.040 |

对照三点匹配 + 等波纹极点（0.61–0.70 dB）全部更低。

误差必须在 `w` 均匀网格上取：`x` 均匀网格在 20 Hz 处的步长约 5e-6，
大于 Q=2 的谐振宽度，会低估约 0.1 dB，并让节点优化看不见该峰。

## 二阶高通

高通在直流是双重零点，功率 ∝ x²，只剩 3 个自由参数：

    P(x) = c x² / (1 + d1 x + d2 x²)

3 个节点 → 3×3 线性方程组，4 个交替极值。最优解恰好落在可实现域边界
`W² + B2 = 0` 上，对应 `b = k(1 - z⁻¹)²`；直接按该形式构造，不能依赖
`solve_b` 的严格可行性检查，否则整条最优边界会被判为不可行。直流误差
取极限 `c·wc⁴/16`。

| Q \ fc | 20 | 117.6 | 691.4 | 4065 | 23900 |
|---:|---:|---:|---:|---:|---:|
| 0.5 | 0 | 0.0001 | 0.0021 | 0.049 | 0.317 |
| 0.707 | 0 | 0 | 0 | 0.0012 | 0.272 |
| 1 | 0 | 0 | 0.0011 | 0.031 | 0.221 |
| 2 | 0 | 0.0001 | 0.0020 | 0.063 | 0.118 |

对照两点匹配 + 等波纹极点：fc ≤ 4 kHz 约 0–0.065，23.9 kHz 为
0.175–0.477。本文在所有档都不高于它，23.9 kHz 误差约为对照的 2/3。

## 二阶带通

带通在直流处为零，只约束一个零点（`n0 = 0`），剩 4 个自由参数：

    P(x) = x (n1 + n2 x) / (1 + d1 x + d2 x²)

4 个节点 → 4×4 线性方程组，5 个交替极值。直流误差取极限
`n1·wc²·Q²/4`；Nyquist 不约束（目标 Pa(π) 是有限值，不是零）。

| Q \ fc | 20 | 117.6 | 691.4 | 4065 | 23900 |
|---:|---:|---:|---:|---:|---:|
| 0.5 | 0.482 | 0.478 | 0.453 | 0.325 | 0.0026 |
| 0.707 | 0.482 | 0.479 | 0.462 | 0.373 | 0.0045 |
| 1 | 0.483 | 0.481 | 0.469 | 0.413 | 0.0075 |
| 2 | 0.483 | 0.482 | 0.477 | 0.459 | 0.019 |

对照三点匹配 + 等波纹极点（0.05–0.97 dB，23.9 kHz 0.05–0.23）：本文最大
0.483 dB，23.9 kHz 为 0.003–0.019 dB。

## 二阶 EQ：peaking / high shelf

原则：硬约束只保留用途/物理必需的，其余交给自由节点——最优插值零点不一定
落在 fc 或 Nyquist 上。

| 类型 | 硬约束 | 自由节点 | 结果（max\|ΔdB\|） |
|---|---|---:|---|
| peaking | `P(0)=1`；`P(x_fc)=A^4` | 3 | 0–0.18（全档可解） |
| high shelf 二阶 | `P(0)=1` | 4 | 0–0.43 |
| high shelf 一阶 | `P(0)=1`；`P(π)=Pa(π)` | 3 | 0–0.052 |

关键收益：shelf 去掉 fc 与 `P(π)` 硬约束后，23.9 kHz / Q=2 / +12 dB 从
2.99 → 0.43 dB；peaking 4 kHz 从 0.30 → 0.13 dB。

低 fc 的关键是**自由度**：3 个节点要同时描述过渡区的多个邻近零点和高频
平台，必然顾此失彼；二阶 shelf 去掉 `P(π)`、换成 4 个自由节点后，低 fc
全部可解（0.0000–0.033）。

## 硬约束法的负结果

固定 `P(0)`、`P(fc)`、`P'(fc)` 后再加两条约束，得到 5 元非线性方程组。
严格检查残差（< 1e-8）后，5 个 fc 上**没有任何一对约束可解**：`root`
返回的 `success=True` 解残差在 1e-6 … 1e-2，属于最小二乘折中而非精确解。
也就是说 5 条硬约束本身不相容，继续挑选约束对没有意义。直接构造
（Ivantsov 分母 + 三条分子约束）同样偏离 0.98–52.7 dB。
