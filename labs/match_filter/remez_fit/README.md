# 带约束的分式 Remez 滤波器匹配

按 48 kHz 下相同的截止频率、Q 和增益参数，重算 10 种模拟滤波器的数字近似。扫描包含 290 组，数字阶数保持与原实验一致。

用 BRASIL 解初始化。Remez 在交替极值上解等幅 dB 误差，同时保留原有硬约束。高通和带通保留直流零点，陷波保留中心零点和直流增益。经过公共零因子约消，零点频率的 dB 误差取连续极限。Peaking 选取交替极值时计入固定中心匹配点两侧的符号关系。波纹高度仍有明显差异时，尝试用倒数增益的解或网格 minimax 解重启。

结果用独立密集网格及局部极值搜索复核。每行 CSV 包含 BRASIL 和 Remez 的峰值误差、交替下界、参考极值数、最大极点半径和 SOS。峰值与交替下界接近时，可以据此判断波纹是否等高。若节点交换无法改善峰值，保留可用初值。二阶结果占一节 SOS，三阶陷波占两节 SOS。

| 模拟目标 | BRASIL 最坏峰值（dB） | Remez 最坏峰值（dB） | 近等波纹 |
|---|---:|---:|---:|
| 一阶低通 | 0.079515 | 0.078555 | 5/5 |
| 一阶高通 | 0.047607 | 0.046327 | 5/5 |
| 二阶低通 | 0.449964 | 0.432379 | 20/20 |
| 二阶高通 | 0.317323 | 0.315958 | 16/20 |
| 二阶带通 | 0.483107 | 0.482757 | 20/20 |
| 二阶 Peaking | 0.183442 | 0.183442 | 68/80 |
| 一阶高 Shelf | 0.052325 | 0.052325 | 20/20 |
| 二阶高 Shelf | 0.358090 | 0.358089 | 63/80 |
| 二阶陷波 | 1.695449 | 1.695448 | 20/20 |
| 三阶陷波 | 0.598564 | 0.596420 | 19/20 |

近等波纹的判据是峰值与交替下界之差不超过峰值的 1% 或 1e−7 dB，两者取较大值。290 组全都通过极点稳定性和硬约束检查，256 组达到近等波纹判据，217 组的峰值改善超过 1e−9 dB。

从工作区根目录运行。依赖 NumPy 和 SciPy。

```powershell
python qwqdsp/labs/match_filter/remez_fit/experiment.py
```

结果写入 `output/constrained.csv`。可用 `--family notch_3rd` 等参数只运行指定类型，生成的文件名会包含所选类型。多个类型可重复传入 `--family`。
