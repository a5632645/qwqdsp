# best_pole_fit — 三点功率匹配与最佳极点（一阶/二阶低通、高通、带通、notch、peaking、高 shelf）

用二阶数字节匹配模拟滤波器：功率函数在 **0、fc、fs/2** 三点精确相等，
分子由三点线性方程组唯一确定，剩下**分母的两个自由值** `p = A(1)`、
`q = A(−1)`；按全带等波纹（最小最大 `|ΔdB|`）选这两个值。各种原型共用
同一套机制，只是三点目标不同。

## 方法

功率函数在 `s = sin²(w/2)` 上是两个二次型之比：

```
|H|² = (B0 p0 + B1 p1 + B2 p2) / (A0 p0 + A1 p1 + A2 p2),
(p0, p1, p2) = (1 − s, s, 4s(1−s)).
```

分母用两端点值参数化，这两个数就是自由值：

```
p = A(1)  = 1 + a1 + a2,
q = A(−1) = 1 − a1 + a2,
A0 = p², A1 = q², A2 = 4 − 2(p + q).
```

稳定域是 `p > 0, q > 0, p + q < 4`。三点目标：

| 类型 | 模拟功率 | `f = 0` | `f = fc` | `f = fs/2` |
|---|---|---|---|---|
| 低通 | `1/(1+(f/fc)²)` | 1 | 1/2 | `T` |
| 高通 | `(f/fc)²/(1+(f/fc)²)` | 0 | 1/2 | `U = 1−T` |
| 高 shelf | `(1+g r²)/(1+r²/g)` | 1 | `g` | `(1+g rₚ²)/(1+rₚ²/g)` |
| 二阶低通 | `1/((1−r²)²+(r/Q)²)` | 1 | `Q²` | `1/((1−rₚ²)²+(rₚ/Q)²)` |
| 二阶高通 | `r⁴/((1−r²)²+(r/Q)²)` | 0 | `Q²` | 不匹配（见下） |
| 二阶带通 | `(r²/Q²)/((1−r²)²+(r/Q)²)` | 0 | 1 | `(rₚ²/Q²)/((1−rₚ²)²+(rₚ/Q)²)` |
| 二阶 notch | `(1−r²)²/((1−r²)²+(r/Q)²)` | 1 | 0 | 不匹配（两点） |
| 二阶 peaking | `((1−r²)²+(rA/Q)²)/((1−r²)²+(r/(AQ))²)` | 1 | `10^(db/10)` | `((1−rₚ²)²+(rₚA/Q)²)/((1−rₚ²)²+(rₚ/(AQ))²)` |
| 二阶高 shelf | `A²[(1−Ar²)²+(√A r/Q)²]/[(A−r²)²+(√A r/Q)²]` | 1 | `10^(db/20)` | 不匹配（0/fc + slope） |

其中 `T = 1/(1+(π/wc)²)`，`g = 10^(db/20)`、`A = 10^(db/40)`、
`r = f/fc`、`rₚ = π/wc`；二阶
低通的 `Q` 是品质因子（`ζ = 1/(2Q)`）。给定 `(p,q)` 后，三个功率约束是关于
`(B0,B1,B2)` 的 3×3 线性方程组；分子可实现的充要条件是 `W² + B2 > 0`、
`W = (√B0 + √B1)/2`（高通允许 `B0 = 0`），再由 Vicanek 的 `Solveb` 反解
`b0/b1/b2`。

**最佳极点**取等波纹解：最小化全带 `max|ΔdB|`。数值上以“第一个极点 =
双线性极点（shelf 取模拟极点 `wc√g` 的双线性像、二阶低通取模拟极点对的
双线性像）、第二个极点扫描”为初值做 Nelder–Mead，粗网格选优后在细网格上
收敛；等波纹条件同时用作核验。二阶高通：三点（0、fc、fs/2）在 fc 接近
Nyquist 时退化——fc 与 fs/2 只差 0.4%，三点矩阵 `cond≈1.2e4`，过渡带误差会
升到 9–16 dB。因此放弃 fs/2 这个点，采用 Vicanek 的两点（DC + fc）+ 直流
双零点 `B(z)=k(1−z⁻¹)²`，`k` 由 fc 条件确定；两个分母自由值按全带等波纹
优化，并与 Vicanek 的脉冲响应不变（II）极点对比。

**二阶 peaking**：模拟原型 `H(S) = (S² + (A/Q)S + 1)/(S² + S/(AQ) + 1)`，
`A = 10^(db/40)`，极点 `Qp = A Q`、零点 `Qz = Q/A`；fc 处峰值功率
`10^(db/10)`，DC/Nyquist 为 1。三点匹配照常。II 基线取 Vicanek 的 Peaking：
II 极点 + **两点（DC + fc）**分子——它不匹配 Nyquist，cut 档尤其明显。

**二阶高 shelf（任意 Q）**：模拟原型
`H(S) = A(A S² + (√A/Q)S + 1)/(S² + (√A/Q)S + A)`，`A = 10^(db/40)`；
极点 `wn = wc·√A`、零点 `wn = wc/√A`，两者 Q 相同；DC 为 1，fc 处功率
`10^(db/20)`（幅度 `√g`），高频渐近 `g`。三点（0/fc/fs2）完全不用；种子取
II 极点与 `(p,q)` 网格。数字端精确匹配 **0/fc 幅度 + fc 处斜率**（Hermite；
0 点斜率恒为 0），fs/2 不约束；给定极点后分子是 3×3 线性解（闭式）。极点
半径限制 `ρ ≤ 0.999`，排除贴单位圆的近对消解。
Vicanek 的 `HighShelf` 只给 II 极点（`wc·10^(db/80)`）+ 目标拟合，三点
不可行时移动匹配点；这里以它的 `highshelf` 作为 II 基线。

## 观察

**低通**：

- 第二极点近乎常数：fc ≤ 1 kHz 时稳定在 `−0.6961 … −0.6970`，第一极点几乎
  就是双线性极点；fc 升高后第二极点向 `−0.8` 移动，接近 Nyquist 时两支重排。
- 误差全在阻带：通带与过渡带误差远小于峰值（fc = 20 Hz 时 1 kHz 以下
  `≲ 0.01 dB`），等波纹出现在 Nyquist 前的阻带。
- 只保留双线性极点（分子仍三点匹配）时峰值 1.39–1.56 dB；最佳第二极点把它
  压到 0.094–0.120 dB。

**高通**：

- 低 fc 时几乎精确：模拟高通的功率在高频趋于 1，数字实现同频只差
  `1/(w/wc)²` 量级，三点匹配的残差随 fc 下降迅速变小（20 Hz 时 `1.5e−7`）。
- 第二极点稳定在 `−0.556` 附近（fc ≤ 4 kHz），几乎与一个零点相消，使二阶节
  在低频段有效退化为一阶；fc 贴近 Nyquist 时两支重排，误差升到 `0.21 dB`。
- 双线性极点 + 三点分子的基线误差是它的 4–32 倍。

**高 shelf**（±12 / ±6 dB × 5 个 fc）：

- 低 fc 几乎精确：20 Hz 档 `2.3e−7 … 5.8e−7 dB`；23.9 kHz 档 `0.079 dB`
  （±6）与 `0.148 dB`（±12）。
- **boost 只明显移动第 1 极点**：它跟随模拟极点 `wc√g` 的双线性像，boost 越
  大越靠内；第 2 极点在小 fc 下几乎与 boost 无关（≈−0.556），只有 fc 接近
  Nyquist 时才随 boost 分开（−0.187 … +0.134）。
- ±b 的误差完全相同（互逆滤波），但极点不同。

**二阶低通**（Q = 0.5 / 0.707 / 1 / 2 × 5 个 fc）：

- Q 改变模拟极点对的半径/角度，最佳数字极点跟随其双线性像；低 fc 几乎重合，
  fc 升高后偏离（Q=0.707、fc=4065：`0.7069±0.2578j` 对 `0.6342±0.2640j`）。
  极点图中虚线/空心是双线性参考：4 kHz 附近差异最大（最佳半径更大、角度略
  小）；23.9 kHz 时 Q>0.5 的双线性仍为复极点，最佳已退化为实极点。
- 全带峰值在 fc ≤ 4 kHz 时为 0.61–0.70 dB，出现在深阻带（模拟已低于
  −100 dB）；`≥−60 dB` 频段内通常更小（如 Q=1、20 Hz 为 0.04 dB）。
- 23.9 kHz 档峰值 0.07–0.39 dB，最佳极点可能落到实轴。

**二阶高通**（Vicanek 两点 + 双零点）：

- 放弃 fs/2 点后高频扭曲消失：23.9 kHz 档 `0.175–0.477 dB`；fc ≤ 4 kHz
  `≤0.065 dB`。
- 同样的两点 + 双零点结构下，极点优化对 II 的优势明显（23.9 kHz、Q=0.707：
  `0.408` 对 `2.501 dB`）；低 fc 两者都接近 0，优化器以 II 兜底，保证不劣于 II。
- 极点图中实线/实心是优化结果，虚线/空心是 II。

**二阶带通**（归一化峰值 1，三点匹配）：

- 三点（DC 0、峰值 1、Nyquist）都能精确；极点优化在 23.9 kHz 明显优于 II
  （`0.05–0.23` 对 `2.58–5.98 dB`），因为 II 极点无法兼顾 Nyquist 点。
- fc ≤ 4 kHz 两者都在 0.54–0.97 dB；BP 的残差集中在下/上裙边，`≥−60 dB`
  频段内的峰值与全带基本相同（Q=2、20 Hz 例外，0.45 dB）。
- 归一化峰值 1 与未归一化（峰值 Q²）只差幅度因子 Q；极点、误差、图形形状不变。

**二阶 notch**（DC + fc 缺口两点）：

- 三点（0、fc、fs/2）在缺口处不可实现：缺口要求 fc 处为 0，三点解把 `B2`
  推到可行性边界外；改用两点（DC 1 + fc 缺口），分子零点在单位圆
  `e^{±j wc}`，`B` 落在边界 `W²+B2=0`。
- fc ≤ 4 kHz 全带误差 `0.000–0.103 dB`（II `0.000–0.322`）；23.9 kHz 档
  `1.64–1.77 dB`（II `34.8–41.3`）。极点优化全程不劣于 II。

**二阶 peaking**（boost × Q）：

- 三点分子 + 极点优化在全部 80 个组合上不劣于 Vicanek 的两点 II。cut 档的
  II 失配集中在 Nyquist：−12 dB、Q=0.5 在 20 Hz 档就有 `12.2 dB`，本方案
  只有 `0.045 dB`；+12 dB 档两者差距小（`0.002–0.026` 对 `0.002–0.034`）。
- +b 与 −b 的本方案误差逐档相同（互逆滤波），但 II 的两点分子对 cut 的
  Nyquist 失配，导致 ± 档的 II 曲线完全不对称。
- 23.9 kHz 档本方案 `0.037–0.144 dB`（II `0.41–3.57`）；fc ≤ 4 kHz 本方案
  `≤0.30`，误差随 boost 和 Q 增大而减小（+12/Q=2 在 691 Hz 为 `0.0021`）。
- 低 Q 的 cut 档（Qp = A Q < 0.5）极点退化为实轴：−12 dB、Q=0.5/0.707 在
  691 Hz 已是两个实极点，Q=1 才刚回到复轴附近。

**二阶高 shelf（任意 Q）**：

- 保留的是 0/fc 幅度 + fc 斜率（Hermite）：0 点斜率恒为 0，自动满足；给定
  极点后分子是闭式 3×3 解，fs/2 不约束。种子取 II 极点与 `(p,q)` 网格。
- 4 kHz 档 `≤0.107`（三点 0.176，二点 0.092），691 Hz 档 `≤0.0032`；
  23.9 kHz 的 Q=1 `0.97`、Q=2 的 ±12 档 `2.99`（三点 3.52）。
- 最高 Q 的 +12/−12 极点仍在 `1.0`（Q 过冲未消）；+6/−6 档 `1.49`，比二点
  的 `1.09/1.45` 略差。这是 slope 约束把过渡带斜率钉死后的代价。
- ±b 的本方案误差逐档相同（互逆）；II 在 cut 的 23.9 kHz 三点不可行、移动
  匹配点，误差 `11.8–13.7 dB`（本方案该档 `0.07–0.18`）。
- Ivantsov 的二阶 shelf（`two_point.high_shelf2`）在 23.9 kHz 的 HF 峰值与
  模拟逐位一致（无过冲），但设计在 1 Hz 附近有零点（`−93.6 dB`），过渡带还
  下凹 8.8 dB；拿它的极点当二点种子也只到 4.5 dB。它的 fc+Nyquist 变换
  不适合超高频 shelf。
- 低/中 fc 几乎精确；Q=2 的模拟原型本身带过冲/下凹（图中虚线），数字端的
  中低频跟随良好。

## 数值条件

低通的 `B2` 是 O(1) 项之差再除以 `8 sin²(wc/2)`。fc 越低抵消越严重：fc = 20 Hz
时 `sin²(wc/2) ≈ 1.7×10⁻⁶`，`q` 变 `2×10⁻⁶` 就能让峰值从 0.12 dB 跳到
2.5 dB，最优点是一条极窄的脊。**求解 `(p,q)` 需要双精度和窄域初值**；要把
峰值复现到 0.01 dB，`(p,q)` 约需 13 位有效数字——表中只保留 6–8 位，应以
程序重算的系数为准。最终 `b/a` 是 O(10⁻³…1)，把 `b/a` 舍入到 float32 后峰值
不变（已核验），病态只存在于设计阶段。高通的 `B0 = 0`、`U ≈ 1`，误差对
`(p,q)` 的敏感度低得多（fc = 20 Hz 时 `q` 变 `1e-6` 只引起 `~1e-6 dB` 变化）；
表中 9 位 `p,q` 可把峰值复现到 0.5% 以内（20 Hz 档 `1.55e−7 → 1.78e−7`）。
即便如此，仍建议以程序重算的 `b/a` 为准。二阶低通在 Nyquist 的目标约 `T²`
（fc = 20 Hz 时 `~5e−13`），`B2` 的抵消比一阶更严重；最优 `(p,q)` 约需 15 位
有效数字，表中只保留 9–10 位，应以程序重算的 `b/a` 为准（`b/a` 对 float32
舍入仍稳定）。
