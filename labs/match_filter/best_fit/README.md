# 一阶模拟低通 / 高通匹配（差分进化）

用三点功率匹配把一阶模拟低通拟合为二阶数字 biquad。模拟原型为
`Ha(jw) = 1 / (1 + jw/wc)`；对与其余实验相同的 5 个 `fc` 逐个优化。

二阶 biquad 的功率函数可写为
`B·phi(w) / (A·phi(w))`，其中
`phi(w) = (1-s, s, 4s(1-s))`、`s = sin²(w/2)`。在 DC、`fc`、Nyquist
三点令数字功率等于模拟功率后，给定分母 `a1,a2` 即可求出分子功率系数
`B`，并还原为实数 `b0,b1,b2`。因此只需迭代优化分母的两个自由参数。

稳定分母用反射系数 `k1,k2 ∈ (-1,1)` 参数化：`a1 = k1(1+k2)`、`a2 = k2`。
优化目标是在 `0..Nyquist` 上最小化最大绝对幅度误差（dB），使用固定种子的
差分进化；三点分子若不可实现为实数系数，该分母候选会被拒绝。

## 结果（fs = 48 kHz）

| fc / Hz | a1 | a2 | 极点 z1 | 极点 z2 | p | q | max\|ΔdB\| |
|---|---|---|---|---|---|---|---|
| 20 | −0.212547 | −0.782787 | −0.784839 | 0.997385 | 0.00466659 | 0.429760 | 0.2001 |
| 117.6 | −1.29006 | 0.300667 | 0.305330 | 0.984725 | 0.0106108 | 2.59072 | 0.5887 |
| 691.4 | −0.528456 | −0.351723 | −0.385033 | 0.913489 | 0.119821 | 1.17673 | 0.2837 |
| 4065 | 0.124162 | −0.415174 | −0.709405 | 0.585243 | 0.708988 | 0.460664 | **0.1114** |
| 23900 | 1.05828 | 0.101528 | −0.951591 | −0.106693 | 2.15981 | 0.0432441 | **0.0938** |

`p = 1+a1+a2`、`q = 1−a1+a2`；极点是 `1 + a1 z⁻¹ + a2 z⁻²` 的两个根
（`a1 = −(z1+z2)`、`a2 = z1 z2`），三个匹配点的功率误差为机器精度。

**读法**：差分进化在 4065 / 23900 Hz 找到了与等波纹最优相同的结果
（0.1114 / 0.0938 dB，与 `best_pole_fit` 一致）；低 fc 时停在不同局部极小
（0.20 / 0.59 / 0.28 dB），没有到达 0.12 dB 的针状最优点。原因是三点匹配的
`B2` 在低 fc 是 O(1) 之差，最优解在参数空间里是一条极窄的脊，全局搜索很难
命中；`best_pole_fit` 用“双线性极点 + 第二极点 ≈ −0.696”的结构初值做局部
收敛，因此能到 0.12 dB。

运行：`python qwqdsp/labs/match_filter/best_fit/lowpass_1st.py`

输出控制台表格和 `output/lowpass_1st_error.png`：左侧是 5 个 fc 的模拟/数字
幅频响应，右侧是 5 条全带误差曲线。

## 一阶高通

模拟原型为 `Ha(jw) = jw/wc / (1 + jw/wc)`，同样在 DC、`fc`、Nyquist 三点匹配，
并用差分进化优化稳定二阶分母。DC 处数字与模拟功率都为零，误差目标采用
`w→0` 时功率比的解析极限。误差图使用对称对数纵轴，以便同时观察低截止频率的
微小误差和接近 Nyquist 时较大的误差。

运行：`python qwqdsp/labs/match_filter/best_fit/highpass_1st.py`

输出五个截止频率的 `p/q`、极点和全带最大误差，并生成
`output/highpass_1st_error.png`。

差分进化结果（`fs = 48 kHz`）：

| fc / Hz | p | q | max\|ΔdB\| |
|---|---:|---:|---:|
| 20 | 0.005042687 | 0.142439871 | 7.264e-7 |
| 117.6 | 0.028931592 | 0.210531489 | 2.255e-5 |
| 691.4 | 0.169088169 | 0.088577300 | 9.409e-4 |
| 4065 | 0.645423344 | 0.694717297 | 0.006112 |
| 23900 | 2.007698989 | 0.060275994 | 0.2134 |

这些是差分进化搜索值；与 `best_pole_fit` 的等波纹解接近。691.4 Hz 一档达到
1000 次迭代上限，故该档不视为已完全收敛。

## 二阶高通

二阶高通模拟原型为
`|Ha(jw)|² = r⁴ / ((1-r²)² + (r/Q)²)`，其中 `r = w/wc`。数字分子保留
二阶零点 `b0(1-z⁻¹)²`。实验匹配 DC 零点和 `fc` 增益，**放弃 Nyquist 匹配**；
分子增益由 `fc` 条件确定，分母的 `p/q` 两个自由值用差分进化最小化全带
`max|ΔdB|`。Nyquist 增益作为误差曲线的一部分参与评估，而不是硬约束。

冲击响应不变（II）极点对应的分母被放入差分进化初始种群，并与优化结果按相同
的三点结构、全带误差计算比较；因此最终结果保留误差更小的一方。结果如下
（`fs = 48 kHz`，每格为“优化 / II 基线”）：

| Q | fc=4065 Hz | fc=23900 Hz |
|---:|---:|---:|
| 0.5 | 0.0541 / 0.1547 dB | 0.4764 / 3.2741 dB |
| 0.707 | 0.00130 / 0.00316 dB | 0.4078 / 2.5013 dB |
| 1 | 0.0323 / 0.0772 dB | 0.3318 / 1.2355 dB |
| 2 | 0.0644 / 0.1397 dB | 0.1750 / 3.1776 dB |

五个截止频率和四个 `Q` 的 20 组计算均未劣于 II 基线。图
`output/highpass_2nd_response.png` 按 `Q` 分面，展示五档响应与有符号误差。
运行：`python qwqdsp/labs/match_filter/best_fit/highpass_2nd.py`
