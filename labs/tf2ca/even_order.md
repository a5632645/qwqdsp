# 偶数阶：两路复系数全通分解

适用范围：`butter` / `cheby1` / `cheby2` / `ellip` 的偶数阶低通，分母极点互异。
分母含重极点时双链是否存在取决于分子，见 [even_order_repeated.md](even_order_repeated.md)。

## 结论

1. **可以分解**。偶数阶低通写成

   ```
   H(z) = alpha*A1(z) + beta*A2(z),     A_i = D_i^#/D_i,   D2 = conj(D1)
   ```

   两条链的极点互为共轭，权重共轭：`beta = conj(alpha)`。对实输入只需算一条复链：

   ```
   y = 2 Re{ alpha * (A1 * x) }
   ```

2. **可归一成经典形式**。把单位相位并进链后是

   ```
   H = 1/2 * (A1' + A2'),     A2' = conj(A1')
   ```

   即 `1/2(A0 + A1)` 的复系数版本。数值上，最小二乘解满足 `|alpha| = 1/2` 的程度为：
   常规规格 `≤ 7e-9`，窄带高阶最差 `1.2e-4`。`alpha` 与 `conj(alpha)` 的相位差为
   `2 arg(alpha)`；在解析滤波器（[hilbert_even.md](hilbert_even.md)）里这个角恰为 45°。

3. **实系数两路全通做不到偶数阶**。`n = dA + dB` 为偶数 ⇒ `dA`、`dB` 同奇偶；
   由 `H(1) = 1` 得两条链的直流增益之和为 2，于是

   ```
   H(-1) = ±(gA + gB)/2 = ±1
   ```

   而低通要求 `|H(-1)| < 1`（默认例 `ellip` 6 阶 @ 0.3 为 `1.0e-2`）。放开复系数后，
   复全通在 `z = -1` 处可以是模长 1 的任意复数，这个约束消失。穷举实系数分法的最佳
   `B` 残差为 `2.2e-2…1.19`。

4. **极点分组规则**：每个共轭对取一个根给 `D1`，另一个由 `D2 = conj(D1)` 承担。
   共轭对按 `|p|` 升序编号，最优分法是交替取上/下半平面根（`n/2` 个共轭对时为
   `0, 01, 010, 0101` 模式）。其余 `2^(n/2) - 1` 种分法的残差是 O(1)，差距 3…13 个数量级。

## 结构推导

设两条链的分母为 `D1, D2`，分子取 `N_i = D_i^#`。通分：

```
H = alpha*N1/D1 + beta*N2/D2 = (alpha*N1*D2 + beta*N2*D1) / (D1*D2)
A = D1*D2,    B = alpha*N1*D2 + beta*N2*D1
```

取 `D2 = conj(D1)` 时，`N2 = conj(N1)`，两个分子项互为系数共轭：

```
alpha*P + beta*conj(P),     P = N1*D2
```

`B` 是实系数，因此 `beta = conj(alpha)`。令 `alpha = x + jy`、`U = P + conj(P)`、
`V = j(P - conj(P))`（均为实向量），得到 2 未知量最小二乘 `B = x*U + y*V`。

### 逐极点判据

把恒等式在 `A` 的极点处取值。`p ∈ D1` 时 `N2*D1` 项为零：

```
p ∈ D1:  alpha = B(p) / (N1(p) * D2(p))
p ∈ D2:  alpha = conj( B(p) / (N2(p) * D1(p)) )
```

正确分组下这 `n` 个值相等。该判据只做点值代入、不展开多项式，条件数远好于系数空间
拟合；但它只对**极点互异**的设计成立（重极点下会假阳性，见
[even_order_repeated.md](even_order_repeated.md)）。

## 窄带高阶为什么退化

`B = alpha*N1*D2 + beta*N2*D1` 把 `A` 的根与 `B` 的系数强绑定。`A, B` 舍入到双精度后，
这条恒等式不再严格成立；窄带高阶设计的条件数很大，残差按条件数放大。判断依据：

- **误差在输入数据，不在算术**：把同一分组的最小二乘放到 60 位精度（`mpmath`，QR）
  重算，残差不变：`cheby1` 8@0.1 `3.071e-03 → 3.071e-03`、`ellip` 8@0.1
  `3.600e-11 → 3.600e-11`、`butter` 8@0.1 `2.436e-05 → 2.436e-05`。
- **奇数阶同样出现**：奇数阶的实系数分组解析上精确（`alpha = beta = 1/2`），在相同的
  窄带高阶下逐极点离散度也升到 `5.9e-11`、实系数最佳残差到 `5.8e-8`。
- **不是缺项**：给拟合加 `gamma*A` 项后残差不变（`cheby1` 8@0.1：`3.071e-03 →
  3.199e-03`，`gamma = 4.2e-11`），两项结构本身完整。

因此判“分对了没有”用逐极点 `alpha` 一致性与其他分法的巨大差距，而不是系数残差的绝对值；
重极点设计则必须改用系数空间残差。

## 边界

- 只研究四族极点互异设计。四族之外的偶数阶低通是否都能这样分解，未做系统验证。
- 重极点设计不适用本文结论：双链是否存在取决于 `B`，LR 明确不可双链。
- Zavalishin《The Art of VA Filter Design》§10.9 的偶/奇全通分解是模拟原型上的结论
  （复权重、复链），结构一致；
  数字域“按 `|p|` 交替”与模拟原型极点序的严格对应未在此推导。
