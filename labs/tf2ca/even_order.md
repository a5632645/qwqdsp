# 偶数阶：两路**复系数**全通分解（research summary）

对应脚本：`even_order.py`（`python even_order.py` 跑单个设计，`--check` 跑批量表）。
奇数阶的实系数分解（`1/2 (A0 + A1)`）不在这里，见同目录 `README.md` / `odd_order.py`。

## 结论速览

1. **可以分解**。四族偶数阶低通都能写成

   ```
   H(z) = alpha * A1(z) + beta * A2(z),        A_i 为 n/2 阶复系数全通， alpha, beta ∈ C
   ```

   实测（`--check`，四族 × 2/4/6/8 阶 × cutoff 0.1/0.2/0.35/0.5 共 64 组）：
   `B` 还原残差 1.9e-16 … 3.1e-3，逐极点 `alpha` 离散度 0 … 1.8e-7，频响误差 4.5e-16 … 2.4e-4。

2. **权重是共轭的，且 `A2` 是 `A1` 的系数共轭**。取 `D2 = conj(D1)`（系数逐个取共轭，即两条链的极点互为共轭）时，
   `B = alpha*N1*D2 + beta*N2*D1` 里两项互为系数共轭，于是实数 `B` **强制** `beta = conj(alpha)`。
   脚本用**不假设共轭**的 4 参数最小二乘独立求 `alpha, beta`，实测 `|beta - conj(alpha)|/max|.| ≤ 2e-15`
   （默认例 ellip 6 阶 @0.3 为 1.6e-15）——所以共轭不是强加的，是解出来的。

   > ⚠️ 「`A2 = conj(A1)`」指**系数**共轭（两条链分母系数逐个共轭），不是逐点共轭。
   > 在单位圆上它是 `A2(e^jw) = conj(A1(e^-jw))`。**不能**写成 `H(e^jw) = 2 Re{alpha*A1(e^jw)}`
   > （那是另一个函数）。对**实输入** `x` 才有

   ```
   y = 2 Re{ alpha * (A1 * x) }        // conj(A1*x) = A2*x，所以只需一条复链再取实部
   ```

   脚本用 `max|2Re(alpha*A1*x) - y_direct|` 直接对比冲激响应验证这一点（默认例 3.7e-14）。

3. **实系数两路全通做不到偶数阶**。`n = dA + dB` 为偶数 ⇒ `dA` 与 `dB` 同奇偶 ⇒
   由 `H(1) = 1` 得 `gA + gB = 2`，于是实系数结构在 Nyquist 处只能是

   ```
   H(-1) = 1/2 [gA*(-1)^(dA) + gB*(-1)^(dB)] = ±(gA+gB)/2 = ±1
   ```

   而低通要求 `|H(-1)| < 1`（默认例设计值 1.0e-2）。穷举全部实系数分法后的最佳 `B` 残差：
   偶数阶 **2.2e-2 … 1.19**（也就是全都做不到）；奇数阶对照 **1.1e-15 … 5.8e-8**。
   放开复系数后复全通在 `z = -1` 处可以是模长 1 的**任意**复数，这个约束才消失。

4. **极点分组规则：共轭对按 `|p|` 升序，交替取上/下半平面根**（bit 模式 `0, 01, 010, 0101`）。
   64 组**全部**是这一种分法；其余 `2^(n/2) - 1` 种分法残差都是 O(1)，差距 3 … 13 个数量级。
   所以「哪种取法对」完全由目标 `B` 决定（与奇数阶按 `|p|` 交替的工程规则同源）。

5. **代价**：`n/2` 个复一阶节 ≈ `n` 个实一阶节的信息量，但每个复一阶节要做复乘；
   可以只算一条复链再取实部（结论 2）。

## 结构推导

设两条链的**分母**为 `D1, D2`，分子取复全通的规范形式 `N_i = conj(反序(D_i))`
（使 `|N_i/D_i| ≡ 1`；任何单位模增益都可并进权重）。代入并通分：

```
H = alpha*N1/D1 + beta*N2/D2 = (alpha*N1*D2 + beta*N2*D1) / (D1*D2)
```

对比 `H = B/A` 得

```
A = D1 * D2          B = alpha*N1*D2 + beta*N2*D1
```

`A` 是实系数、次数 `n` 偶数 ⇒ 其根按共轭对出现；于是「`D2 = conj(D1)`」等价于
「每对共轭根里取一个给 `D1`，另一个给 `D2`」，共 `2^(n/2)` 种取法，`D1*D2` 恒为实数（实测 `A` 还原误差 ~1e-16）。

此时 `N2 = conj(N1)`、`D2 = conj(D1)`，两个分子项互为系数共轭：

```
alpha*N1*D2  +  beta*N2*D1  =  alpha*P + beta*conj(P),   P = N1*D2
```

`B` 是实系数（给定量），而 `alpha*P + beta*conj(P)` 为实的充要条件是 `beta = conj(alpha)`
（`P` 与 `conj(P)` 线性无关时）。令 `alpha = x + jy`、`U = P + conj(P)`、`V = j(P - conj(P))`（两者都是实向量），
就得到脚本里的 2 未知量最小二乘：`B = x*U + y*V`。

**逐极点判据**（脚本判断「分对了没有」的主要依据，条件数远好于系数空间拟合）：
把恒等式在 `A` 的极点处取值，`p ∈ D1` 时 `N2*D1` 项为零，于是

```
p ∈ D1:  alpha = B(p) / (N1(p) * D2(p))
p ∈ D2:  alpha = conj( B(p) / (N2(p) * D1(p)) )
```

正确分组下这 `n` 个值必须相等（实测离散度 0 … 1.8e-7；错的分法离散到 O(1)）。

## 与参考书的关系、未验证的边界

- VAFilterDesign §10.9 *Even/odd allpass decomposition* 给出的是**模拟原型**上的结论：
  `(1 + j f(ω0)) Ho(s) + (1 - j f(ω0)) He(s) = 2 H(s)/H(jω0)`，`f` 为偶函数（偶数阶）时
  系数是复数、`He/Ho` 本身也是复系数全通。这与本目录的结构一致（复权重、复链）。
  但「按 `|p|` 交替」这条**数字域**规则与那里「even/odd poles of `H(s)H(-s)`」的严格对应，
  本目录**没有推导**（未验证，只是数值上 64/64 成立）。
- 前提：`A` 的实极点必须等值成对（`conjugate_splits` 会抛 `ValueError`；四族偶数阶没有实极点，
  所以不受限）。奇数阶则因「实极点重数为奇」而**不适用**该共轭式（脚本表 2 里标「不适用(实根奇重)」）,
  奇数阶走实系数那条路即可。
- 四族之外的任意偶数阶低通是否也能这样分解，本目录**未验证**。

### 窄带高阶为什么会退化（不是分组错了）

`B = alpha*N1*D2 + beta*N2*D1` 是一条把 `A` 的根与 `B` 的系数**强绑定**的代数恒等式。
`A, B` 一旦被舍入到双精度，这条恒等式就不再严格成立；窄带高阶设计里它的**条件数极大**
（`A` 的系数动态范围大、极点挤在一起），于是残差按条件数被放大。证据：

1. **不是浮点算术问题**：`python even_order.py --kind cheby1 --order 8 --cutoff 0.1 --exact`
   把同一个分组的最小二乘放到 60 位精度（`mpmath`，QR 最小二乘）重算，残差与双精度**完全相同**：
   cheby1 8@0.1 `3.071e-03 → 3.071e-03`、ellip 8@0.1 `3.600e-11 → 3.600e-11`、
   butter 8@0.1 `2.436e-05 → 2.436e-05`。高精度救不回来，因为误差在**输入数据**
   （被舍入到双精度的 `A`、`B` 系数）里，不在算术里。
2. **同源现象**：奇数阶那条**已知精确**的实系数分组（`alpha = beta = 1/2`，解析上严格成立）
   在同样的窄带高阶下也退化——`--check` 第二张表里逐极点 `alpha` 离散度 4.4e-16 … 5.9e-11，
   实系数最佳残差 1.1e-15 … 5.8e-8。也就是说：**残差抬升是这类设计的系数表示条件数问题，
   与「奇数/偶数阶」无关**，与 `README.md` 里 `B_c^2 = B^2 - A*A^#` 的消位是同一类问题。
3. **不是缺了第三项**：给拟合加一个 `gamma*A` 项（相当于直通/常数项）后残差**不变**
   （cheby1 8@0.1：3.071e-03 → 3.199e-03，`gamma = 4.2e-11`），所以两项结构本身是对的。
4. 因此判「分对了没有」用**逐极点 `alpha` 一致性**（只做点值代入，条件数好）与其他分法的
   巨大差距，而不是系数空间残差的绝对值。

## 复现

```bash
python qwqdsp/labs/tf2ca/even_order.py                 # ellip 6 阶 @0.3（默认）
python qwqdsp/labs/tf2ca/even_order.py --kind butter --order 4 --cutoff 0.25
python qwqdsp/labs/tf2ca/even_order.py --kind cheby1 --order 8 --cutoff 0.1 --exact   # 60 位精度重算
python qwqdsp/labs/tf2ca/even_order.py --check         # 批量表
```

输出图片在 `output/`（本地生成）。脚本会打印两条链的复系数分母、`alpha/beta`、
逐极点判据、单链形式误差、实系数对照与 Nyquist 处的取值。
