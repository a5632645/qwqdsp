# 偶数阶 + 重复极点：Linkwitz–Riley 的 tf2ca 行为（research summary）

对应脚本：`even_order_repeated.py`（`python even_order_repeated.py` 跑单个设计，`--check` 跑批量表）。

`even_order.md` 的结论是「偶数阶可以分解，代价是**复系数**链 + 复权重（`beta = conj(alpha)`）」。
那一页研究的是四族（butter / cheby1 / cheby2 / ellip），**极点互异**。本页研究它没覆盖的那一类：
分母含**重极点**的设计，典型就是 Linkwitz–Riley

```
LR_{2n}(z) = (n 阶 Butterworth 低通)^2        A = (A_half)^2,  B = (B_half)^2
```

结论是：**它不是「偶数阶要复系数」的一个例外，而是 tf2ca 两条链根本做不到的一类**——两条链
（实/复系数、带不带 `z^-k` 延迟）都不行，`LR` 的自然结构是**三条链**。

## 结论速览

1. **两条链做不到**。脚本穷举 `A*A^#` 的**全部**谱因子后取最优拟合：LR2 … LR12 × cutoff
   0.1/0.25/0.45 的 18 组，残差 **5.0e-02 … 1.00e+00**（O(1) 量级，与浮点精度无关）；
   把截止频率扫到 0.02…0.48（半阶 1…6，共 144 例）**没有一例低于 1e-6**（最小 2.8e-02）。
   同一套代码对四族偶数阶给出 **1e-16 … 1e-13**（对照 A 表），所以差距是 10+ 个数量级的结构差异。
2. **实系数两路全通有解析不可能性**：`n` 偶数 ⇒ 两条实全通链的阶数同奇偶 ⇒
   `|H(-1)| = 1`（由 `H(1) = 1` 定标）。LR 低通 `|H(-1)| ≤ 2e-18`。加 `z^-k` 也不救
   （延迟只翻转符号，这个恒等式对 `j0, j1` 无关）。实系数最佳残差 5.7e-01 … 1.0。
3. **可分解的完整判据**（本脚本据此穷举，所以「不存在」是穷举结论而不是经验观察）：

   ```
   H = B/A 是两条（加权）全通链之和
     <=> 存在谱因子 U（deg U = n、U * U^# = A * A^#，X^# = conj(反序(X))）
         使得 B = alpha*U + conj(alpha)*U^#
   ```

   即 `B` 必须落在某个谱因子 `U` 的 2 维**实**子空间 `span{U + U^#, j*(U - U^#)}` 里
   （`B` 是实多项式时 `alpha*U + beta*U^#` 会自动强制 `beta = conj(alpha)`）。
   四族偶数阶的解里 `|alpha| = 0.5` 精确成立（24/24），此时链可归一成单位模、导出的互补支与
   低通构成功率互补对；**LR 连残差都下不去**，`|alpha|` 也就没有意义（LR4@0.25 给出 0.087）。
4. **LR 的正确结构是三条链**，权重 `1/4, 1/2, 1/4`：

   | LR | 三条链的阶数 | 系数 | 三链频响误差（cutoff 0.1/0.25/0.45） |
   |---|---|---|---|
   | LR_{4k+2}（半阶奇） | (n−1, n, n+1) | 三条**实**链 | 5.6e-16 … 4.4e-09 |
   | LR_{4k}（半阶偶） | (n, n, n) | 外侧两条复链（互为系数共轭），中间实链 | 8.3e-16 … 3.5e-07 |

   原因是「平方」：`H = alpha*A1 + conj(alpha)*A2` 平方后是
   `alpha^2*A1^2 + 2|alpha|^2*A1*A2 + conj(alpha)^2*A2^2`——**两个谱因子变成三个**。
5. **方法论警告（重极点下 `even_order.py` 的主判据会骗人）**：LR4@0.25 的某个分法逐极点
   `alpha` 离散度只有 **4.2e-08**（看起来「分对了」），但系数空间残差是 **0.542**。
   机制：重极点让 A 只有 `n/2` 个相异位置，值条件定不住次数 `n` 的恒等式——该判据解出的
   `alpha` 满足 `B - (alpha*N1*D2 + conj(alpha)*N2*D1) = c * A`（`c ≠ 0`，LR4@0.25 的默认分法 `c = 0.5`），
   这个 `c` 在逐极点代入里完全看不见。另外 `D1 = D2`（共享极点）时判据是 0/0 直接无定义。
   **判分法必须用系数空间残差。**
6. **`LP±HP` 的全通性不蕴含耦合全通分解**：偶数半阶 `|LP+HP| ≡ 1`（LR4 偏差 4.9e-15、
   LR8 2.1e-13），奇数半阶 `|LP-HP| ≡ 1`（LR2 8.9e-16、LR6 1.5e-14）——这是经典 LR 极性结论，
   但另一支不是全通，所以双链判据仍然不满足。别被「和是全通」误导。
7. **对 `even_order.md` 的两点收紧**（都由本脚本的完整枚举重算得到）：
   - 四族偶数阶的解其实可以归一成 `|alpha| = 0.5` + 单位模复链（24/24 精确），也就是
     经典 `1/2 (A0 + A1)` 的**复链版本**，`even_order.md` 里的「复权重」剩的只是链的整体相位。
   - 「四族偶数阶能分解」也有条件数边界：阶数上到 12、截止压到 0.1 时，butter / cheby1 的
     残差也涨到 0.92 / 0.97。所以**判据结论必须同阶同截止比较**（本页的 LR 结论用的就是这个口径）。

## LR 的结构：重极点从哪来

LR 是同一个 Butterworth 级联两次，所以分母每个极点的重数都是 2，分子的所有零点都落在
`z = -1`（重数 `2n`）：

| 设计 | 半阶 n | 极点结构（`nu` = 代表根在 A 中的重数） | 分子 |
|---|---|---|---|
| LR2 = (BW1)² | 1 | `\|p\|=0.4142`（实）×2 | 零点全在 `z=-1`，重数 2 |
| LR4 = (BW2)² | 2 | 一个共轭类 ×2 | 重数 4（镜像对称） |
| LR6 = (BW3)² | 3 | 一个共轭类 ×2 + 一个实根 ×2 | 重数 6 |
| LR8 = (BW4)² | 4 | 两个共轭类 ×2 | 重数 8（镜像对称） |
| LR12 = (BW6)² | 6 | 三个共轭类 ×2 | 重数 12 |

> ⚠️ 想用数值手段判断「A 是不是完全平方」**不可靠**：`butter` 8 阶 @0.05 这种窄带高阶设计，
> A 根本不是平方，但系数级平方根递推的相对残差只有 **2e-7**（真平方在 1e-13 以下）——阈值
> 会误判。所以脚本不猜结构：LR 的 `A = (A_half)^2` 是**已知**的，通过 `sqrt_hint` 显式传进判据
> （`lr_half_denominator()`）。

## 判据推导与「穷举什么」

设两条链为 `alpha*N0/D0`、`beta*N1/D1`（`N_i = D_i^#` 是单位模全通分子），通分后

```
H = (alpha*N0*D1 + beta*N1*D0) / (D0*D1)      =>   A = D0*D1,  B = alpha*N0*D1 + beta*N1*D0
```

记 `U := N0*D1`（`deg U = n`），则 `U^# = (N0*D1)^# = D0*N1 = N1*D0`，于是

```
B = alpha*U + beta*U^# ,       U * U^# = N0*N1*D0*D1 = A^# * A
```

`B` 是实系数 ⇒（`U`、`U^#` 线性无关时）`beta = conj(alpha)` ⇒ `B = alpha*U + conj(alpha)*U^#`，
即 `B` 必须落在实子空间 `span{U + U^#, j*(U - U^#)}` 内。反过来，给定满足 `U*U^# = A*A^#` 的
谱因子 `U`，`H = alpha*U/A + conj(alpha)*U^#/A` 里两项各自都是「常数模全通」
（`|U/A| = 1` 由 `U*U^# = A*A^#` 保证）⇒ 是合法的两链结构。**判据是充要的。**

**穷举范围**（`spectral_factors()`）：谱因子 = 「每个互反共轭根对取一个根」。

- 复共轭类（代表 `p`、重数 `nu`）：根对有两族 `{p, 1/p*}` 与 `{p*, 1/p}` 各 `nu` 份，
  每份二选一 ⇒ `(nu+1)^2` 种取法 `(k, j)`；
- 实根（重数 `nu`）：只有一族根对 `{r, 1/r}` 的 `nu` 份 ⇒ `nu+1` 种；
- `U` 与 `U^#` 给出同一个子空间，故只枚举互补配对的一半。

`even_order.py` 的枚举（每个共轭类「取一个根给 D1」、`D2 = conj(D1)`）只覆盖复类的对角线
`j = nu - k`；重极点下必须放开到全部 `(nu+1)^2`。本脚本全集大小：LR4 **9**、LR8 **81**、
LR12 **729**（去重后 5 / 41 / 365，见下表）。四族在这一步无所谓（极点互异，对角线子集已含最优解），
重极点下差别很大。

## 重极点下的两个数值陷阱（都实测踩到过）

1. **逐极点判据假阳性**（结论 5）。`even_order.py` 用「在 A 的每个极点独立解 `alpha`、
   看离散度」判分法，条件数好、对互异极点很灵。但重极点只有 `n/2` 个相异位置，值条件不足以
   定住次数 `n` 的恒等式：解出的 `alpha` 满足 `B - (alpha*N1*D2 + conj(alpha)*N2*D1) = c*A`
   （LR4@0.25 的 c = 0.5），残留的 `c*A` 在逐极点代入里被当成 0。**重极点判分法必须看系数
   空间残差**（本脚本的 `two_chain_fit`），或者补上导数条件。
   `D1 = D2`（两条链共享极点）的分法更彻底：逐极点公式是 0/0，判据直接无定义（表里的 `nan`）。
2. **手写正规方程会给「假精确」**。`U` 与 `U^#` 近乎共线时（重极点下常见：`D1 = D2` 的退化
   候选），2×2 正规方程的闭式解会给出巨大的 `x, y`，两者在浮点下互相抵消，残差被算成机器精度：
   LR4@0.02 出现过 `3.164e-16` 的假阳性，而 60 位精度（`mpmath`）下真实残差是 **0.927**。
   改用 SVD 最小二乘后，144 例 LR 扫描里**没有任何一例**低于 1e-6。本页所有残差都是修好之后的数。

## LR 的三链结构（正确做法）

`LR_{2n} = (BW_n)^2`，把半阶 BW 的双链分解平方就得到三链：

- 半阶 `n` 奇：BW_n 是实系数双链 `1/2 (A0 + A1)`（`tf2ca.split_by_radius`），
  平方 ⇒ `1/4 A0^2 + 1/2 A0*A1 + 1/4 A1^2`，三条**实**链，阶数 `(n-1, n, n+1)`。
- 半阶 `n` 偶：BW_n 是复系数双链 `alpha*A1 + beta*A2`（`even_order`，实测 `|alpha| = 0.5`），
  平方 ⇒ `1/4 (2alpha)^2 A1^2 + 1/2 (A1*A2) + 1/4 (2conj(alpha))^2 A2^2`：
  权重仍可写成 `1/4, 1/2, 1/4`（单位相位并进链），外侧两条链复系数且互为系数共轭，中间链实系数。

（下表 cutoff = 0.25，末行 0.1；`链内单位缩放` 是乘在 `D^#/D` 前面的单位模常数）

| 设计 | 链阶数 | 链内单位缩放 | 三链频响误差 | 冲激响应误差 |
|---|---|---|---|---|
| LR2 | 2, 1, 0 | 1（实） | 5.594e-16 | 5.551e-17 |
| LR4 | 2, 2, 2 | `-0.6285+0.7778j`（复） | 3.265e-15 | 4.372e-16 |
| LR6 | 2, 3, 4 | 1（实） | 1.023e-14 | 1.030e-15 |
| LR8 | 4, 4, 4 | `-0.6825+0.7309j`（复） | 1.159e-13 | 1.511e-14 |
| LR12 @0.1 | 6, 6, 6 | `-0.9479+0.3187j`（复） | 3.761e-07 | 1.910e-08 |

三链形式是**精确**的（`H(1) = 1`、链平坦度 ~1e-15），误差只是系数条件数：表里 18 例
（cutoff 0.1/0.25/0.45）最大 3.5e-07；把 cutoff 压到 0.02 会退化到 O(1)——因为三链分解继承
半阶设计的条件数（同 `even_order.md` 的「窄带高阶退化」）。

**实用含义**：LR 分频器用「一个滤波器 + 一个加法」省不下来（EMQF / `tf2ca` 的收益不适用）；
LR 的省算实现要么直接级联两次，要么用上面的三链（两条外侧链 + 一条中间链 + 三个加法）。

| LR6 | 9.992e-01 | 1.465e-14 |
| LR8 | 2.108e-13 | 9.989e-01 |
| LR12 @0.1 | 5.388e-07† | 9.985e-01 |

† 随系数条件数漂移，结构上仍是全通。

偶数半阶时 `LP+HP` 全通、奇数半阶时 `LP-HP` 全通（这就是 LR「极性要不要反」的经典结论）。
但双链判据要的是**两支分别是（常数模）全通**，这里另一支不是全通——「和是全通」不构成
耦合全通分解的充分条件，`even_order.md` 里四族偶数阶能分解也**不是**靠这个性质。

## 与参考书/文献的关系

- VAFilterDesign §10.9 的偶/奇全通分解是**模拟原型**上的结论（复权重、复链），
  与本目录 `even_order.md` 的结构一致；但那里的前提是原型上「H(s) 与 H(-s) 的偶/奇部分」，
  **LR（一个滤波器的平方）不满足**：平方把两个谱因子变成三个。
- LR 分频器的经典性质（LP+HP 全通 / 需要反极性）与「能不能写成两条全通之和」是两件事，
  本页第 6 条给出了实测对照。

## 未验证边界

- 只系统扫了 **LR = (Butterworth)²**；一般重极点设计只测了对照 B 的 6 个「四族平方」例子
  （都失败），以及对照 C 的存在性构造。**「任意重极点设计是否都做不到双链」没有结论**——
  对照 C 说明反例存在（可双链的重极点设计随手可造），所以正确答案是「取决于 `B`」。
- **三链的最小性没有证明**：`1` 条不可能（`|H| ≡ 1`）、`2` 条已被穷举排除、`3` 条有精确构造。
  是否存在需要 4 条以上的 LR 类似物未做。
- 延迟搜索只到 `j = 0,1,2`（`--delays`）：`j1 = j2` 与 `j1 ≠ j2` 的情形都试过，都没救。
  「链上任意 `z^-k`」的完整穷举未做（结论 2 的解析论证对**实**链是完整的；复链只做了小偏移搜索）。
- 三链分解继承半阶设计的条件数：本页数据在 `cutoff ≥ 0.1`、阶数 ≤ 12 范围内（最大误差 3.5e-07）；
  更窄带的高阶未验证。
- `spectral_factors()` 的实根分支假设实根重数可拆（`nu+1` 种），复类用 `(nu+1)^2` 种；
  非 LR 的多重实根设计未单独验证过该计数。
