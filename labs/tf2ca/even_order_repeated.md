# 偶数阶 + 重极点：双链判据与 Linkwitz–Riley 三链

研究对象：分母含重极点的偶数阶低通，典型是 Linkwitz–Riley 分频器

```
LR_{2n}(z) = (n 阶 Butterworth 低通)^2        A = (A_half)^2,  B = (B_half)^2
```

结论：LR 不能写成两条（加权）全通链之和；它的正确结构是三条链。一般重极点设计
能否双链取决于分子 `B`，不是“重极点必然不可分解”。

## 结论

1. **可双链的充要判据**：

   ```
   H = B/A 是两条加权全通链之和
     <=> 存在谱因子 U（deg U = n、U*U^# = A*A^#）使得
         B ∈ span{U + U^#, j*(U - U^#)}
   ```

   等价地 `B = alpha*U + conj(alpha)*U^#`。`X^# = conj(反序(X))`。

2. **LR 不满足该判据**。穷举 `A*A^#` 的全部谱因子后，LR2…LR12 的最优双链残差为
   `5.0e-2…1.0`（O(1)，与浮点精度无关）。半阶 1…6 × cutoff `0.02…0.48` 共 144 例，
   最小的双链残差为 `2.8e-2`，没有一例低于 `1e-6`。同一套代码对四族极点互异设计
   给出 `1e-16…3e-5`（常规规格 `1e-16…1e-13`，窄带高阶升到 `1e-5`），LR 的最优值
   仍在 `2.8e-2` 以上（144 例扫描的最小值）。

3. **实系数两路全通有解析不可能性**。`n` 偶数 ⇒ 两条实全通链的阶数同奇偶 ⇒
   由 `H(1) = 1` 得 `|H(-1)| = 1`；LR 低通的 `|H(-1)| ≤ 2e-18`。链上加 `z^-k` 也不改变
   这个恒等式。穷举实系数分法的最佳残差为 `5.7e-1…1.0`。

4. **重极点本身不是障碍**。固定同一个 `A_LR4`，取 `B = (U + U^#)/2`（`U` 取 LR4 的
   谱因子）即可精确双链。障碍是 LR 的 `B` 同时被钉成 `(B_half)^2`。

5. **LR 的正确结构是三条链**：

   ```
   LR_{4k+2} = 1/4*A0 + 1/2*Am + 1/4*A1     三条实系数全通，阶数 (n-1, n, n+1)
   LR_{4k}   = 1/4*A0 + 1/2*Am + 1/4*A1     外侧两条复系数且互为系数共轭，中间实系数
   ```

   结构来自“平方”：`H = alpha*A1 + conj(alpha)*A2` 平方后是
   `alpha^2*A1^2 + 2|alpha|^2*A1*A2 + conj(alpha)^2*A2^2`，两个谱因子变成三个。

6. **判分必须用系数空间残差**。重极点下“逐极点独立解 `alpha`、看离散度”的判据会
   假阳性：它只检查值条件，定不住次数 `n` 的恒等式。LR4@0.25 的某个分法离散度为
   `4.2e-8`，但把同一组 `alpha` 代入后残差为 `0.5*A`（按 `max(abs(B))` 归一化
   `17.5`）。全部谱因子的最优双链残差仍是 `0.542`。

7. **`LP ± HP` 的全通性不蕴含双链分解**。偶数半阶时 `|LP+HP| ≡ 1`，奇数半阶时
   `|LP-HP| ≡ 1`；但另一支不是全通，双链判据仍不满足。

## 判据推导

设两条链为 `alpha*N0/D0`、`beta*N1/D1`，`N_i = D_i^#`。通分：

```
A = D0*D1,    B = alpha*N0*D1 + beta*N1*D0
```

记 `U = N0*D1`，则 `U^# = N1*D0`，所以

```
B = alpha*U + beta*U^#,     U*U^# = A*A^#
```

`B` 为实系数时 `beta = conj(alpha)`，即 `B` 落在 `U` 的 2 维实子空间
`span{U + U^#, j*(U - U^#)}` 内。反过来，给定满足 `U*U^# = A*A^#` 的谱因子，
`H = alpha*U/A + conj(alpha)*U^#/A` 的两项都是常数模全通。判据是充要的。

### 谱因子穷举

谱因子 = “每个互反共轭根对取一个根”：

- 复共轭类（代表 `p`、在 `A` 中重数 `nu`）：根对有两族 `{p, 1/p*}` 与 `{p*, 1/p}`，
  各 `nu` 份，每份二选一 ⇒ `(nu+1)^2` 种；
- 实根（重数 `nu`）：只有 `{r, 1/r}` 的 `nu` 份 ⇒ `nu+1` 种；
- `U` 与 `U^#` 给出同一子空间，只保留互补配对的一半。

全集大小：LR2 `3`、LR4 `9`、LR6 `27`、LR8 `81`、LR10 `243`、LR12 `729`；
去重后 `2 / 5 / 14 / 41 / 122 / 365`。

拟合时用 SVD 最小二乘。`U` 与 `U^#` 近乎共线时（例如 `D1 = D2` 的退化候选），
手写 2×2 正规方程会给出巨大的解并在浮点下互相抵消，残差被算成机器精度；SVD 会截断
退化方向，残差如实反映可实现的拟合精度。

### 重极点的结构信息

LR 的 `A = (A_half)^2` 是**已知**的，通过 `sqrt_hint` 显式传给判据。数值判断
“`A` 是不是完全平方”不可靠：`butter` 8 阶 @ 0.05 不是平方，但系数级平方根递推的
相对残差只有 `2e-7`（真平方在 `1e-13` 以下），阈值会误判。

| 设计 | 半阶 n | 极点结构（`nu` = 代表根在 A 中的重数） | 分子 |
|---|---|---|---|
| LR2 = (BW1)² | 1 | `abs(p)=0.4142`（实）×2 | 零点全在 `z=-1`，重数 2 |
| LR4 = (BW2)² | 2 | 一个共轭类 ×2 | 重数 4（镜像对称） |
| LR6 = (BW3)² | 3 | 一个共轭类 ×2 + 一个实根 ×2 | 重数 6 |
| LR8 = (BW4)² | 4 | 两个共轭类 ×2 | 重数 8（镜像对称） |
| LR12 = (BW6)² | 6 | 三个共轭类 ×2 | 重数 12 |

## 判分方法：系数空间残差

逐极点判据在重极点下失效。机制：重极点让 `A` 只有 `n/2` 个相异位置，
值条件不足以定住次数 `n` 的恒等式；用该判据解出的 `alpha` 满足

```
B - (alpha*N1*D2 + conj(alpha)*N2*D1) = c*A,    c ≠ 0
```

残留的 `c*A` 在每个极点处为零，逐极点代入看不见。默认 LR4@0.25 的分法 `c = 0.5`，
离散度 `4.2e-8`，而同一组 `alpha` 按 `max(abs(B))` 归一化的系数残差为 `17.5`
（全部谱因子的最优拟合仍为 `0.542`）。`D1 = D2` 时判据更是 `0/0`。

重极点设计一律用系数空间残差（SVD 最小二乘），或补上导数条件。

## 三条链

`LR_{2n} = (BW_n)^2`，把半阶 BW 的双链分解平方：

- 半阶 `n` 奇：BW_n 是实系数双链 `1/2(A0 + A1)`，平方得
  `1/4 A0^2 + 1/2 A0*A1 + 1/4 A1^2`，三条实链，阶数 `(n-1, n, n+1)`。
- 半阶 `n` 偶：BW_n 是复系数双链 `alpha*A1 + conj(alpha)*A2`，`|alpha| = 1/2`；平方后
  权重仍是 `1/4, 1/2, 1/4`，外侧两条链复系数且互为系数共轭，中间链实系数。

| 设计 | 链阶数 | 链内单位缩放 | 三链频响误差（cutoff 0.25） |
|---|---|---|---|
| LR2 | 2, 1, 0 | 1（实） | 8.990e-16 |
| LR4 | 2, 2, 2 | `-0.6285+0.7778j`（复） | 3.122e-15 |
| LR6 | 2, 3, 4 | 1（实） | 9.003e-15 |
| LR8 | 4, 4, 4 | `-0.6825+0.7309j`（复） | 1.230e-13 |
| LR12 @0.1 | 6, 6, 6 | `-0.9479+0.3187j`（复） | 3.494e-07 |

三链形式是精确的（`H(1) = 1`、链平坦度 ~`1e-15`），误差来自系数条件数。18 例
（cutoff 0.1/0.25/0.45）最大 `3.5e-7`；cutoff 压到 0.02 会退化到 O(1)，因为三链
继承半阶设计的条件数。

实用含义：LR 分频器无法用“一个滤波器 + 一个加法”省下来；要么级联两次，要么用
三条链 + 三个加法。

## `LP ± HP`：和是全通 ≠ 能拆成耦合全通

| 设计 | `max(abs(LP+HP)-1)` | `max(abs(LP-HP)-1)` |
|---|---|---|
| LR2 | 9.997e-01 | 8.882e-16 |
| LR4 | 4.885e-15 | 9.994e-01 |
| LR6 | 9.992e-01 | 1.465e-14 |
| LR8 | 2.108e-13 | 9.989e-01 |
| LR12 @0.1 | 5.388e-07¹ | 9.985e-01 |

¹ 随系数条件数漂移，结构上仍是全通。

偶数半阶时 `LP+HP` 全通，奇数半阶时 `LP-HP` 全通（LR 的极性结论）。双链判据要求
两支分别是常数模全通；这里另一支不是全通，所以“和是全通”不构成充分条件。

## 边界

- 只系统研究 `LR = (Butterworth)^2`。一般重极点设计只测了 6 个“四族平方”例子
  （全部失败）与上面的存在性构造。**一般重极点设计能否双链取决于 `B`**，不能一概而论。
- 三链的最小性没有证明：1 条不可能（`|H| ≡ 1`），2 条已被穷举排除，3 条有精确构造；
  是否存在需要 4 条以上的 LR 类似物未做。
- 延迟搜索覆盖 `j = 0,1,2`（`--delays`）；`j1 = j2` 与 `j1 ≠ j2` 都试过，都没有改善。
  链上任意 `z^-k` 的完整穷举未做（实链的解析论证是完整的；复链只做了小偏移搜索）。
- 三链分解继承半阶设计的条件数：本文数据在 `cutoff ≥ 0.1`、阶数 `≤ 12` 范围内，
  最大误差 `3.5e-7`；更窄带的高阶未验证。
- 谱因子枚举的实根分支假设实根重数可拆（`nu+1` 种），复类用 `(nu+1)^2` 种；
  非 LR 的多重实根设计未单独验证该计数。
