# iir_hilbert.hpp 是怎么构造出来的

脚本：`hilbert_even.py`（`python hilbert_even.py` 构造 + 出图；`python hilbert_even.py --header` 给头文件里的固定系数打分）。

## 一句话

**半带椭圆低通**（crossover 落在 0.5、极点正好落在 z 平面虚轴上）
→ **复系数两路全通分解**（权重恰为 45°，即两条链天然相差 90°）
→ **频率旋转**（极点乘 `j`，等价 `z -> -jz`）
→ **解析滤波器**：一条实系数 `zeta = z^-2` 多相全通链 + 一条带 1 拍延迟的同型链。

这正是 `qwqdsp/include/qwqdsp/filter/iir_hilbert.hpp` 里的结构。

## 归一化：这个结构要 **除以 2**

教材（VAFilterDesign §10.10 的 analytic filter）取

```
H = 1/2 * [ LP(z) + j * HP(z) ]            // 正频增益 1、负频 0
```

所以基于该结构的解析滤波器输出**要除以 2**：本页与脚本里的 `analytic_metrics` 都按除 2 后
（正频 `|H| = 1`、负频 `|H| = 0`）报告；**头文件的 `Tick` 本身不除 2**，它直接返回
`A_real + j*z^-1*A_imag`，原始输出是这里的 2 倍（`|H| ≈ 2`）。

## 头文件的结构（读代码 + 数值验证）

- `APF` 有**两个**状态 `z0_ z1_`，它的传递函数是

  ```
  (z^-2 - a) / (1 - a*z^-2)          // zeta = z^-2 的"多相"全通，a 是半速率极点
  ```

  （z 域极点为 `±sqrt(a)`，即一组 `±rho` 合成一个 `zeta` 节。）
- `Tick`：`real` = `A_real(zeta)` 级联；`imag = latch_` 是**上一拍**的级联输出，即 `z^-1 A_imag(zeta)`；
  输出 `{real, imag}`。除以 2 后就是解析滤波器。

  实测（统计带 `|w| in [0.05pi, 0.95pi]`；头文件原始输出 ÷2）：

  | 类 | 节数 | 正频 \|H\| | 负频最大 \|H\| | 相差相对 -90° 偏差 |
  |---|---|---|---|---|
  | `IIRHilbert` | 4+4 | 0.9933 … 1.0000（-0.06 dB … 0 dB） | 0.1155（-18.8 dB） | 13.27° |
  | `IIRHilbertDeeper` | 8+8 | 1.0000 … 1.0000 | 1.14e-05（-98.8 dB） | 0.001° |

  台阶数就是精度：`IIRHilbert` 是很粗的设计，实用应选 `IIRHilbertDeeper`。

  `python hilbert_even.py --header` 还会另存一张 **branch phase 图**
  （`output/hilbert_header_branch_phase.png`）：两条链（含结构延迟、不含权重 `j`）的相位差应为
  **正频 -90° / 负频 +90°**。实测带内（`|w| in [0.05pi, 0.95pi]`）偏离该值：

  | 设计 | 带内最大偏离 | 带内偏离 > 1° 的样本数 |
  |---|---|---|
  | `IIRHilbertDeeper`（8+8） | **0.0000°** | 0 / 14398 |
  | `IIRHilbert`（4+4） | 13.265° | 大量（曲线在带内明显起伏） |

  DC 与 `±pi` 附近是真实的过渡（曲线朝 0 或朝 ±180 走），不是绘图假象。

## 让数字极点落在虚轴上：椭圆滤波器的设计要求

用 scipy 的**数字** `signal.ellip(N, rp, rs, Wn)`（`Wn` 对 `ellip` 是**通带**边沿）时，
要让 `A(z) = A_e(z^-2)`（极点精确落在虚轴 `±j*rho`），必须**同时**满足三条：

| # | 条件 | 说明 |
|---|---|---|
| 1 | **`N` 为偶数** | 极点按 ± 成对才可能只占虚轴 |
| 2 | **波纹互补**：`eps_p*eps_s = 1` | 两个波纹只能给一个：**本脚本以阻带深度 `rs`(dB) 为参数**，`rp = 10*log10(1 + 1/(10^(rs/10)-1))` |
| 3 | **边沿对称**：`Wp + Ws = 1` | 等价于 prewarp 后 `tan(pi*Wp/2)*tan(pi*Ws/2) = 1`，即 crossover 落在 0.5。`Wn` 由此定死 |

为什么是这三条：双线性变换把模拟域的 `s -> 1/s` 变成数字域的 `z -> -z`，所以"数字极点 ± 成对"
⟺ "（缩放后的）模拟极点关于 `|s| = 1` 自反"。椭圆滤波器自反要求**边沿互为倒数**（条件 3）
**且**互补波纹（条件 2，EMQF / 半带设计的老条件）。

**反例（数值验证）**：只满足条件 3、波纹随意时，极点明显偏离虚轴：

| 设计 | `Wp`（解 `Wp+Ws=1`） | 极点实部 | 说明 |
|---|---|---|---|
| n=8, rp=0.2, rs=40（不互补） | 0.49332 | 2.9e-01 | ✗ |
| n=12, rp=0.2, rs=40（不互补） | 0.49952 | 2.9e-01 | ✗ |
| n=8, rp=0.2, rs=13.47（互补，数值解 `Wn`） | 0.49982 | 1.1e-06 | 受搜索精度限制 |
| n=8, rs=30（互补，**闭式** `Wn`） | 0.48910 | **8.1e-14** | ✓ |

### `Wn` 的闭式解

第 3 条不必数值搜索：椭圆次数方程写成 **nome 形式**就是闭式

```
eps_s = sqrt(10^(rs/10) - 1),  eps_p = 1/eps_s
k1 = eps_p^2                       # = eps_p/eps_s
q1 = exp(-pi * K'(k1)/K(k1))
q  = q1^(1/N)                      # 次数方程：N = ln(1/q1)/ln(1/q)
k  = theta2(q)^2 / theta3(q)^2     # 级数：k = 4*sqrt(q)*(Sum q^{n(n+1)})^2 / (1+2*Sum q^{n^2})^2
Wp = (2/pi) * atan(sqrt(k))        # 归一化到 Nyquist=1；Ws = 1 - Wp
```

脚本里是 `halfband_Wp()`（`scipy.special.ellipk` + theta 级数）。
**校验**：与高精度数值解 `Wp + Ws = 1` 对比，n=8 时差 `<= 1.5e-13`。

## 前置结论（直接复用本目录已有结果）

本页只补"半带 + 频率旋转"这条新链路，以下结论不再重复推导：

- **极点分组规则**：共轭对按 `\|p\|` 升序交替（含 `arg(p)` 交替为何在 cheby2 上失败的复测）→ 见 `README.md`；
- **偶数阶两路复全通分解**（`H = alpha*A1 + conj(alpha)*A2`、`alpha` 恰 45°、逐极点判据）→ 见 `even_order.md`；
- **实系数两路全通做不到偶数阶**（Nyquist 奇偶性论证）→ 见 `README.md` / `even_order.md`；
- 本页新增的只有：半带的三条设计条件（含 `Wn` 闭式解）、频率旋转、以及 `iir_hilbert.hpp` 固定系数的打分。

## 构造步骤（`hilbert_even.py`，每步都有数值校验）

1. **半带椭圆**（= 三条条件 + 闭式 `Wn`）：直接 `scipy.signal.ellip(N, rp, rs, Wp)`。
   **极点取 `output='zpk'` 直给的数字极点**（`p = ±j*rho` ⇒ `rho^2 = |p|^2`），
   不要用 `np.roots(A)`：高阶时多项式求根的极点分离条件数会崩（实测 N=32 时
   `np.roots` 与 zpk 的 `rho^2` 差 0.18，N=64 差 2.0，而 zpk 直接可用）。
   默认 `rs = 30 dB` 时：

   | 不变量 | 实测（N=8, rs=30 dB, rp=0.00435 dB, Wp=0.489099601） | 含义 |
   |---|---|---|
   | `A` 的奇次系数 | 8.8e-13 | `A(z) = A_e(z^-2)`，极点关于虚轴 `±` 成对 |
   | 极点实部（zpk） | 8.1e-14 | 极点**正好落在虚轴上** |
   | `\|H(0.5)\|` | 0.707106781 | `= 1/sqrt(2)`，crossover |
   | 功率互补误差 | 5.3e-12 | `\|H\|^2 + \|H(-z)\|^2 = 1` |

2. **复系数两路全通分解**：`H = alpha*A1 + conj(alpha)*A2`，穷举共轭对取法后实测

   ```
   alpha = 0.353553391 + 0.353553391j = (1+j)/(2*sqrt(2))     |alpha| = 0.5, arg = 45.0000°
   残差 ~1e-14
   ```

   **45° 是关键**：两条链的权重相差 90°，所以它们的和能拼成解析滤波器。
   （偶数阶**实数**两路全通做不到这一步，见 `README.md`、`even_order.md`
   里的 Nyquist 奇偶性论证。）

3. **频率旋转** `z -> -jz`：把半带的响应整体搬移 `-pi/2`。等价地，实极点 `±j*rho` 变成实轴极点 `∓rho`。
4. **复权重合成**：`H(z) = alpha*A1'(z) + conj(alpha)*A2'(z)`（`A_i'` 是旋转后的**实系数一阶链**，
   `alpha = (1+j)/(2*sqrt(2))`）。这就是"把半带整体旋转"的结果，因此

   * 正频增益 = 半带通带增益（≈1，dB 接近 0）
   * **负频阻带 = 半带阻带 = 设计给的 `rs`**（实测 `-30 / -60 / -80 / -90 / -100 dB` 逐一等于 `rs`）
   * 与"旋转后的半带"响应最大偏差 1e-13 … 1e-8（取决于 N 与 rs）

   | N | rs | 节数 | 通带最差 | 负频最大 | 与目标偏差 | 两链相差偏离 90° |
   |---|---|---|---|---|---|---|
   | 8 | 30 dB | 8 | -0.004 dB | **-30.00 dB** | 2.6e-13 | 3.62° |
   | 8 | 60 dB | 8 | -0.000 dB | **-60.00 dB** | 1.9e-14 | 0.115° |
   | 16 | 60 dB | 16 | -0.000 dB | **-60.00 dB** | 2.4e-08 | 0.115° |
   | 16 | 90 dB | 16 | -0.000 dB | **-90.00 dB** | 3.2e-11 | 0.004° |

### ⚠️ 头文件那个 `zeta` 节 + 延迟的形式**不是**这个旋转

`iir_hilbert.hpp` 的结构是"`zeta = z^-2` 多相全通节 + 1 拍延迟"（`A_real + j*z^-1*A_imag`）。
早期版本我用"偶数阶半带的 `rho^2` 直接填进去"来构造它 —— **那是错的**：实测它与
"旋转后的半带"最大偏差 **0.75**，负频只能到 `-36 dB`（rs=60 时），即**完全不是同一个滤波器**。
原因：偶数阶半带没有"原点极点"，也就没有理由出现那个延迟单元；而且偶数阶半带的
真实旋转结果是上面那个 `alpha` 复权重形式，不是"两个 `±rho` 成对的多相节"。

由此可得一条**未完全验证**的线索（见下）：头文件里的延迟单元很可能来自**奇阶**半带 ——
奇阶半带的极点是 `±j*rho` 成对 **外加一个落在原点的极点**（数值已验证：`a[-1] ≈ 1e-15`、
极点里恰好 1 个在原点、`|H(0.5)| = 1/sqrt(2)`、功率互补 ✓），那个原点极点分配给某条全通链后
就退化为 `z^-1` 延迟。但把它直接写成 `[A0(z^2) + z^-1*A1(z^2)]/2` 再拟合，残差仍高达 0.71，
所以"奇阶 + 延迟"这条路线**还差一步没弄通**（可能需要不同的支路/延迟分配或归一化）。

图（`output/hilbert_n16_rs60.png`，2x3 版式，第 6 格留空）：

- (0,0) 半带极点（虚轴、按复全通分组着色）；(0,1) 半带原始 `|H|`(dB)（标注 `rs`/`Wp`/crossover）；
- (0,2) 旋转后的实轴一阶极点（两符号交错）；(1,0) 解析滤波器 `|H|`(dB) 与目标叠加；
- (1,1) 两链相位差（标准约定：第二支滞后 90°）：正频 **-90°**、负频 **+90°**，两带内平直；曲线在 DC 处*连续*穿过 0（不需要 unwrap）；(1,2) 空。

## 奇阶半带：见 `hilbert_odd.md`

奇阶是**另一条路线**，已拆到 `hilbert_odd.py` + `hilbert_odd.md`：

- 奇阶半带（同样两条设计条件）的 `A` 末位系数为 0，有效分母阶 `N-1`（只含 `z^-2`）；
- 它可以用 **两组 `z^-2` 实系数全通链 + 一个延迟单元**精确复原：
  `H(z) = 1/2*[A0(z^-2) + z^-1*A1(z^-2)]`（权重恰 0.5/0.5，N=9/15/17 残差 5e-12…6e-9）；
- 两条链的 ζ 阶数之和 = `(N-1)/2`，**可以不等**（N=15 是 4+3）——只枚举等分是找不到解的；
- 本文件的**共轭（alpha）形式对奇阶不适用**（原点极点自共轭，无法按共轭对拆分）。

## 质量由什么决定

| N | rs | rp | `0.5-Wp` | 节数 | maxRe(zpk) | 通带最差 | 负频最大 | 相差偏差 |
|---|---|---|---|---|---|---|---|---|
| 8 | 30 dB | 4.4e-03 dB | 1.1e-02 | 4 | 8.1e-14 | -0.024 dB | -22.5 dB | 8.563° |
| 16 | 40 dB | 4.3e-04 dB | 7.4e-04 | 8 | 3.2e-12 | -0.007 dB | -27.9 dB | 4.611° |
| 16 | 60 dB | 4.3e-06 dB | 7.1e-03 | 8 | 9.1e-08 | -0.001 dB | -36.3 dB | 1.748° |
| 16 | 80 dB | 4.3e-08 dB | 2.3e-02 | 8 | 7.7e-04 | -0.0003 dB | -41.8 dB | 0.935° |
| 32 | 60 dB | 4.3e-06 dB | 3.9e-05 | 16 | 1.0e-09 | -0.001 dB | -36.3 dB | 1.748° |
| 64 | 60 dB | 4.3e-06 dB | 1.2e-09 | 32 | 9.3e-09 | -0.001 dB | -36.3 dB | 1.748° |

两条经验规律（都可从上表读出）：

- **负频最大是怎么测的**：在负频网格（16001 点）上直接取 `max|H|`，**不是寻峰**；
  同时排除 DC / Nyquist 附近的过渡区，保护带按设计的过渡带宽度自适应
  （`guard = max(0.05, 0.5 - Wp)`，因为过渡带宽度就是 `0.5-Wp`）。输出里会打印取得
  最大值的频率，若它落在保护带边缘说明保护带偏小、量到的是过渡区而不是真阻带。
- **`rs` 决定负频抑制**：负频底噪 ≈ **正交误差的一半**（`|H_neg| ≈ delta/2`，`delta` = 相差偏离 90° 的量）。
  验证：相差 1.748° = 0.0305 rad → `0.0305/2 = 0.0153` = -36.3 dB，与实测 -36.33 dB 完全吻合；
  头文件 `Deeper` 的 0.001° → -98.8 dB 同理。
- **`N` 只决定过渡带离 DC/Nyquist 多近**（固定 `rs` 时，N=16/32/64 在测量带内数值完全相同，
  差别只在 `0.5-Wp`：7.1e-03 → 3.9e-05 → 1.2e-09）。想要更陡的边沿就加节数。

固定 `N=16` 时，`rs` 越深（`rp` 越小）`0.5 - Wp` 越**宽**：rs=40 → 7.4e-04、rs=60 → 7.1e-03、rs=80 → 2.3e-02；
所以「深阻带 + 陡边沿」要同时加 `rs` 和 `N`。

## 数值包线

用 zpk 取极点后，本脚本可用到 **N=64（32 节）**（上表最后一行 ✓）。
再深会撞到 `Wp` 下溢（`rs = 100 dB @ N=64` 时闭式 `Wn` 落到 0，scipy 直接报
`filter critical frequencies must be greater than 0`）。

另外，**`A` 的奇次系数在高阶不再是可靠诊断**：N=64/rs=80 时它高达 33（多项式展开的条件数问题），
但 zpk 直给的极点、以及最终响应都正常 —— 所以脚本同时报告 `maxRe(zpk)` 与响应指标。

## 头文件固定系数与本次构造的关系

- **结构完全一致**：`alpha` 就是旋转后的半速率极点 `rho^2`，`APF` 是 `zeta` 多相节，`imag` 支路带 1 拍延迟。
- **数值来源未完全反推**：`IIRHilbert` 的 8 个 alpha ⇔ 父半带阶数 16、`IIRHilbertDeeper` 的 16 个
  ⇔ 阶数 32；具体 `rs`/带宽没拟合（很可能还带频率 warping / 专门优化，**未验证**）。
  本次验证的是"用半带的 `rho^2` 搭出来的结构确实是同一类解析滤波器"。
- `iir_hilbert4.hpp` 的 `IIRHilbertFull` 不查表，而是用闭式

  ```
  preal = exp(-pi / 2^(2i)),  pimag = exp(-pi / 2^(2i+1))
  ```

  生成半速率极点；这正是它注释里引用的那个 dsp.stackexchange 答案（Ross Wilkinson）的
  "几何极点序列 `p_n = exp(-pi/2^n)` + 交替分链 + 单位延迟"近似式（**不是**精确半带设计）。
  同目录 `iir_cpx_hilbert.hpp` 是同一结构的复数输入版本。

## 注意

- 自由参数只有**阶数 `N`（偶数）与阻带深度 `rs`**；`rp` 与 `Wn` 都被条件 2、3 定死。
  想换带宽只能 `N`、`rs`，或者对频带做 **warping**（`kb = (beta-1)/(beta+1)`、
  `beta = sqrt(tan(w1/2)*tan(w2/2))`），把目标频带 `[w1, w2]` 映成对称边沿再设计 ——
  这是第二条"频率调整"，本次未实现。
- 本页的闭式解是**独立重推**的；原先那份草稿的 pyc（`temp/even_order_draft_2026-10-02.pyc`）
  已在第一次 `import even_order` 时被 Python 重编译覆盖（只剩 docstring 存于
  `temp/even_draft_docstring.txt`），无法逐行对照。若你手头还有该草稿源码，可用它交叉验证
  `halfband_Wp()` 的 `q = q1^(1/N)` 写法。
