# 偶阶半带 → 解析滤波器

构造链：

```
偶数阶椭圆半带低通（crossover 落在 0.5，极点落在 z 平面虚轴上）
    → 复系数两路全通  H = alpha*A1 + conj(alpha)*A2，alpha = (1+j)/(2*sqrt(2))
    → 频率旋转 z -> -jz
    → 解析滤波器  A_real(z) + j*z^-1*A_imag(z)
```

最后一行就是 `iir_hilbert.hpp` 的 `APF` / `Tick` 结构：`APF` 的传递函数是
`(z^-2 - a)/(1 - a*z^-2)`（`zeta = z^-2` 的多相全通），`a = rho^2`；`imag` 支路
多走一拍（`latch_`）。奇阶半带对应另一条路线，见 [hilbert_odd.md](hilbert_odd.md)。

## 归一化

教材取 `H = 1/2 [LP(z) + j*HP(z)]`：正频增益 1、负频 0。头文件的 `Tick` **没有**除 2，
它直接返回 `A_real + j*z^-1*A_imag`，原始输出是解析滤波器的 2 倍（`|H| ≈ 2`）。
本文与脚本里的指标都按除 2 后报告。

## 半带设计条件

用 scipy 的数字 `ellip(N, rp, rs, Wp)` 时，要让 `A(z) = A_e(z^-2)`（极点精确落在
虚轴 `±j*rho`），必须同时满足：

| # | 条件 | 说明 |
|---|---|---|
| 1 | `N` 为偶数 | 极点按 `±` 成对才可能只占虚轴 |
| 2 | 波纹互补 `eps_p*eps_s = 1` | 两个波纹只能给一个：以 `rs` 为参数，`rp = 10*log10(1 + 1/(10^(rs/10)-1))` |
| 3 | 边沿对称 `Wp + Ws = 1` | 等价于 prewarp 后 `tan(pi*Wp/2)*tan(pi*Ws/2) = 1`，crossover 落在 0.5 |

只满足边沿对称而波纹不互补时，极点会明显偏离虚轴（例如 `N=8, rp=0.2, rs=40`：
`max Re p ≈ 0.29`）。

### 闭式 `Wp`

条件 3 不必数值搜索。把椭圆次数方程写成 nome 形式：

```
eps_s = sqrt(10^(rs/10) - 1),   eps_p = 1/eps_s
k1 = eps_p^2                    # = eps_p/eps_s
q1 = exp(-pi * K(1-k1^2) / K(k1^2))
q  = q1^(1/N)
k  = theta2(q)^2 / theta3(q)^2
Wp = (2/pi) * atan(sqrt(k))     # Nyquist 归一；Ws = 1 - Wp
```

`K(m)` 是参数为 `m` 的完全椭圆积分（scipy 的 `ellipk` 约定）。

对扫描的 `(N, rs)`，`tan(pi*Wp/2)*tan(pi*Ws/2) - 1` 在 `1e-16` 量级。闭式给出的是
**设计目标**；scipy `ellip` 能否实际达到它，受过渡带宽度限制（见“数值包线”）。

## 构造步骤

1. **半带椭圆**：`ellip(N, rp, rs, Wp)`。极点取 `output='zpk'` 直给的数字极点
   （`p = ±j*rho` ⇒ `rho^2 = |p|^2`），不要用 `np.roots(A)`：高阶时多项式求根的
   极点分离条件数会崩。默认 `N=8, rs=30 dB`：

   | 不变量 | 值 | 含义 |
   |---|---|---|
   | `A` 的奇次系数 max | 4.40e-14 | `A(z) = A_e(z^-2)` |
   | 极点实部 max（zpk） | 5.07e-15 | 极点落在虚轴 |
   | `abs(H(0.5))` | 0.707106781 | `= 1/sqrt(2)`，crossover |
   | 功率互补误差 | 5.50e-13 | `abs(H)^2 + abs(H(-z))^2 = 1` |
   | `rho^2`（zpk vs 多项式求根） | 1.9e-14 | 两条路径一致 |

2. **复系数两路全通**：`H = alpha*A1 + conj(alpha)*A2`，穷举共轭对取法：

   ```
   alpha = 0.353553391 + 0.353553391j = (1+j)/(2*sqrt(2)),   |alpha| = 0.5, arg = 45°
   残差 5.35e-16
   ```

   两条链的权重相差 90°，这是它们能拼成解析滤波器的原因。

3. **频率旋转** `z -> -jz`：半带响应整体搬移 `-pi/2`；极点 `±j*rho` 变成实轴极点
   `∓rho`，系数变实。默认例：旋转后 `D` 的虚部 max `1.13e-14`，与目标
   `H_halfband(-jz)` 的最大偏差 `2.63e-13`。

4. **解析滤波器**：`H(z) = alpha*A1'(z) + conj(alpha)*A2'(z)`，`A_i'` 是旋转后的
   实系数一阶链。正频增益 = 半带通带增益（≈1）；负频阻带 = 半带阻带 = `rs`。

### 精确构造的实测点

| N | rs | 正频最差 | 负频最大 | 与 `H(-jz)` 偏差 | 两链相差偏离 90° |
|---|---|---|---|---|---|
| 8 | 30 dB | -0.0043 dB | -30.00 dB | 2.63e-13 | 3.624° |
| 16 | 60 dB | -0.0000 dB | -60.00 dB | 2.39e-08 | 0.115° |
| 16 | 80 dB | -0.0000 dB | -80.00 dB | 3.90e-10 | 0.011° |

负频抑制与正交误差满足 `|H_neg| ≈ delta/2`（`delta` = 相差偏离 90° 的量）：
`rs=30` 时 `3.624° = 0.0633 rad`，`0.0633/2 ≈ 0.0316 = -30 dB`；`rs=60` 时同理。

## 数值包线

闭式 `Wp` 满足边沿对称，但 scipy `ellip` 在**过渡带过窄**时会失去半带性质：
`|H(0.5)|` 偏离 `1/sqrt(2)`，功率互补误差变大。代表性扫描：

| N | rs | `0.5-Wp` | `abs(H(0.5))-1/sqrt(2)` | 功率互补误差 | 半带 |
|---|---|---|---|---|---|
| 8 | 30 | 1.09e-02 | -1.4e-13 | 5.5e-13 | 是 |
| 12 | 30 | 1.01e-03 | 1.1e-08 | 3.7e-08 | 是 |
| 16 | 40 | 7.39e-04 | 2.6e-04 | 7.5e-04 | 否 |
| 16 | 60 | 7.07e-03 | 2.2e-08 | 6.5e-08 | 是 |
| 20 | 60 | 1.93e-03 | 1.1e-03 | 3.0e-03 | 否 |
| 20 | 80 | 8.73e-03 | -4.5e-07 | 1.3e-06 | 是 |
| 24 | 100 | 9.95e-03 | -1.0e-04 | 2.8e-04 | 勉强 |
| 32 | 60 | 3.92e-05 | -5.0e-01 | 1.86 | 否 |
| 64 | 60 | 1.21e-09 | 3.8e-02 | 7.07 | 否 |

当前实现可靠到 `N ≤ 16` 的常规规格（`N=12` 在过渡带 `1e-3` 仍可用）；`N=20` 需要
过渡带 `≥ 8e-3`；`N=24` 只在过渡带约 `1e-2` 时勉强可用，`N ≥ 32` 在扫描点上全部
失败。更高阶需要更高精度的椭圆设计，当前未实现。

半带不变量失效时，旋转后的通带/阻带仍接近设计值（例如 `N=32, rs=60` 的负频仍是
`-60 dB`），但 `H(-jz)` 目标偏差可到 O(1)，crossover 与功率互补不再成立。脚本在
功率互补误差 `> 1e-6` 时会打印提示。

## 头文件结构与固定系数

`iir_hilbert.hpp` 的结构是 `A_real(z) + j*z^-1*A_imag(z)`，每个 `APF` 为
`(z^-2 - a)/(1 - a*z^-2)`；`Tick` 的 `real` 是 `A_real` 级联，`imag` 是上一拍的
级联输出。两条链（含结构延迟、不含权重 `j`）的相位差应为 **正频 -90° / 负频 +90°**。

| 类 | 节数 | 正频幅度 | 负频最大 | 相差相对 -90° 偏差 |
|---|---|---|---|---|
| `IIRHilbert` | 4+4 | 0.9933 … 1.0000 | 1.155e-01（-18.75 dB） | 13.265° |
| `IIRHilbertDeeper` | 8+8 | 1.0000 … 1.0000 | 1.144e-05（-98.83 dB） | 0.001° |

台阶数就是精度：`IIRHilbert` 是粗设计，实用选 `IIRHilbertDeeper`。`--header` 还会
输出 branch phase 图；带内（`|w| in [0.05pi, 0.95pi]`）相位偏离为 `Deeper ≤ 0.001°`、
`IIRHilbert 13.265°`。

固定系数的**数值来源**未反推：`IIRHilbert` 的 8 个 alpha 对应父半带阶数 16，
`IIRHilbertDeeper` 的 16 个对应阶数 32；具体的 `rs`/带宽没有拟合，可能还带
warping 或专门优化。能确认的是结构同类：`a = rho^2`、两支路交替、`imag` 支路带
一拍延迟。

`iir_hilbert4.hpp` 的 `IIRHilbertFull` 不查表，而用

```
preal = exp(-pi / 2^(2i)),   pimag = exp(-pi / 2^(2i+1))
```

生成半速率极点。这是几何极点序列 `p_n = exp(-pi/2^n)` + 交替分链 + 单位延迟的
近似式（Ross Wilkinson），不是精确半带设计。`iir_cpx_hilbert.hpp` 是同一结构的
复数输入版本。

## 边界

- 自由参数只有阶数 `N`（偶数）与阻带深度 `rs`；`rp` 与 `Wp` 被条件 2、3 定死。
- 换带宽只能改 `N`、`rs`，或对频带做 warping：
  `kb = (beta-1)/(beta+1)`、`beta = sqrt(tan(w1/2)*tan(w2/2))`。warping 未实现。
- 更高阶（`N ≥ 24`）需要更高精度的椭圆设计；当前 scipy 路径在窄过渡带下失去半带
  不变量。
- 复全通分解穷举 `2^(N/2)` 种分法；超过 16 对（`N > 32`）时直接报错，不做剪枝。
- 头文件固定系数的父设计参数未反推。

## 复现

```bash
python qwqdsp/labs/tf2ca/hilbert_even.py                      # N=8, rs=30 dB
python qwqdsp/labs/tf2ca/hilbert_even.py --order 16 --rs 60
python qwqdsp/labs/tf2ca/hilbert_even.py --header             # 头文件固定系数评分
```
