## 一、音频开发为什么要用并行全通？

在数字音频处理中，低通/高通滤波最普遍的实现是双二阶（Biquad / SOS 级联）。但如果深入观察**并行全通结构（Coupled-Allpass / Two-Path Allpass）**，你会发现在很多音频核心场景下，它是极度降维打击的武器。

并行全通将一个数字 IIR 滤波器拆分成两条独立全通滤波链的和与差：

$$H_{LP}(z) = \frac{1}{2} \left[ A_0(z) + A_1(z) \right] \quad (\text{低通})$$

$$H_{HP}(z) = \frac{1}{2} \left[ A_0(z) - A_1(z) \right] \quad (\text{互补高通})$$

其中 $A_0(z)$ 与 $A_1(z)$ 是一连串一阶或二阶全通滤波器的串联。

```
          ┌────────────┐
       ┌─►│  A0(z) 全通 ├───────┬────────► (+) ───► H_LP (低通)
       │  └────────────┘       │         ▲
x[n] ──┤                       │         │
       │  ┌────────────┐       ▼         │
       └─►│  A1(z) 全通 ├─────►(+)───────┴────────► (-) ───► H_HP (高通)
          └────────────┘
```

### 1.1 相比传统 Biquad 的压倒性优势

| 维度 | 传统 Biquad SOS 级联 | 并行全通结构（Two-Path Allpass） |
| :--- | :--- | :--- |
| **计算复杂度** | 每个二阶节需要 5 次乘法、4 次加法 | 一阶全通节仅需 **1 次乘法**；二阶全通仅需 **2 次乘法**。<br>整体乘法量**直接减少约 40% ~ 50%**。 |
| **分频器成本** | 低通与高通需分别独立滤波，或阶数翻倍（Linkwitz-Riley） | **算一次低通，减法免费附赠高通**。天然功率互补：$\|H_{LP}\|^2 + \|H_{HP}\|^2 = 1$。 |
| **数值灵敏度** | 窄带高 Q 时系数极易发生量化舍入问题 | 内部每个节点增益严格为 1（无损 Lossless / Bounded Real），极抗定点/单精度量化噪声，抗极限环振荡。 |
| **衍生应用** | 仅做常规滤波 | **半带重采样抽取/插值**的最高效结构；通过频域旋转天然衍生为 **IIR Hilbert 解析滤波器**。 |

### 1.2 它在音频领域的杀手级场景
1. **多带分频器（Crossover）与多带压缩（Multiband Compressor）**：低通与高通完全能量守恒（功率互补），重构后没有多余能量起伏。
2. **重采样半带滤波（Halfband Decimation / Interpolation）**：半带滤波时全通节降采样为 $z^{-2}$，一半的计算量直接被时钟跳过。
3. **实时移频器（Frequency Shifter）与单边带调制（SSB）**：利用衍生出的正交解析对（Hilbert Transform），摆脱超大延迟的 FIR，以几个浮点指令实现超低延迟的 90° 正交相位差。

## 二、奇数阶实系数分解：经典四族低宽/高通

### 2.1 什么样的数字滤波器可以这样分解？
将两条全通链通分：

$$H(z) = \frac{1}{2}\left(\frac{N_0}{D_0} + \frac{N_1}{D_1}\right) = \frac{N_0 D_1 + N_1 D_0}{2 D_0 D_1} = \frac{B(z)}{A(z)}$$

由于全通滤波器的分子是分母的系数反序镜像多项式（$N_i = D_i^\#$），代数上要求：
1. **总阶数 $n$ 必须为奇数**（$D_0$ 与 $D_1$ 阶数一奇一偶，从而保证在 Nyquist 处 $B(-1)=0$ 形成低通）。
2. **分子多项式 $B(z)$ 镜像对称**（即 $b[k] = b[n-k]$）。
3. **通带增益归一化**：$H(1) = 1$。

> **结论**：数字信号处理中的经典四族设计 —— **Butterworth（巴特沃斯）**、**Chebyshev I（切比雪夫I型）**、**Chebyshev II（逆切比雪夫）**、**Elliptic（椭圆 / Cauer）**，其奇数阶低通**全部严格天然满足上述条件**，均可无损分解！

### 2.2 互补高通与代数判据
定义互补高通分子 $B_c(z) = (N_0 D_1 - N_1 D_0)/2$。利用全通特性可推导出：

$$B_c^2(z) = B^2(z) - A(z) A^\#(z)$$

对于系统极点 $p$（满足 $A(p)=0$），必然有 $B_c(p) = \pm B(p)$：
- 若 $B_c(p) = +B(p)$，则极点 $p$ 归属于 $D_0$；
- 若 $B_c(p) = -B(p)$，则极点 $p$ 归属于 $D_1$。

虽然这一代数判据在数学上严谨，但在**窄带或高阶**情况下，$B^2 - A A^\#$ 会因为两个极大项相减发生**严重的浮点消位误差**。因此工程落地时**禁止**先求根再套多项式消位判据。

## 三、核心避坑：极点分组到底怎么分？（模长 vs 角度）

这是音频开发者查阅学术文献或网贴时**最容易掉进的大坑**。

### 3.1 致命陷阱：数字域幅角 $\arg(p)$ 交替会导致频响崩溃！
经典文献（如 R. Lyons 等）常提到：“两条全通链的极点是交替分布的（Pole Interlacing / 按角度交错）”。

很多开发者便在代码里写出这样的逻辑：
> “把所有极点按复数角度 $\arg(p)$ 从小到大排序，奇数号给链 0，偶数号给链 1。”

**这是严重错误的！** 在切比雪夫 II 型（Chebyshev II）和部分椭圆滤波器上，数字域极点角度会被双线性变换严重扭曲挤压。
例如对 **Chebyshev 2 (9 阶, cutoff=0.2)** 进行极点观察：
- 节点 0：$|p|=0.3147, \ \arg = 0.000^\circ$（实极点）
- 节点 1：$|p|=0.4820, \ \arg = 33.221^\circ$
- 节点 2：$|p|=0.7002, \ \arg = 35.264^\circ$
- 节点 3：$|p|=0.8485, \ \arg = 32.701^\circ$ $\leftarrow$ **角度不仅没增大，反而回退了！**
- 节点 4：$|p|=0.9531, \ \arg = 31.046^\circ$ $\leftarrow$ **继续倒退！**

如果按数字域 $\arg(p)$ 排序交替，分组顺序会被彻底打乱。实测频响误差直接飙升到 **$1.7$**（严重畸变，完全失去低通特性）。

### 3.2 经过 6020 组极端用例验证的统一黄金法则
实验室脚本（`split_rule.py`、`arg_s_plane.py`、`arg_s_stress.py`）针对四族滤波器，在覆盖 3~71 阶、极度极限截止频率（$10^{-4} \sim 0.499999$）的 **6020 组严苛用例** 下进行了压力测试。

**结论**：
1. **工程统一法则：一律按数字极点的模长 $|p|$ 升序交替分配！**
   - 包含 1 个实极点与 $(n-1)/2$ 个共轭复极点对；
   - 共轭对作为一个二阶节点单位，实极点作为一个一阶节点单位；
   - 按模长 $|p|$ 升序排序，第 0, 2, 4... 项归链 0，第 1, 3, 5... 项归链 1；
   - 6020 个用例全部完全吻合，机器精度级复原（残差 $\sim 10^{-13}$）。
2. **文献中“角度交替”的真实含义**：文献里有两种写法。
   - **Vaidyanathan, _Multirate Systems and Filter Banks_, 1993, §3.6**（可在 CaltechAUTHORS 开放获取）把这个性质称为 *pole interlace property*，原文写的是 **$z$ 平面极点角** $\theta$（"the poles … with pole angles θ0, θ1, …; θ0<θ1<…"），并引用 **Gazsi 1985**。按字面用数字域 $\arg(p)$ 排序，在 butter/cheby1/ellip 常规规格下成立，但 **cheby2 整族失败**、极限规格下 ellip 也会失败（实测见下）。
   - **Gazsi, "Explicit Formulas for Lattice Wave Digital Filters", IEEE TCS-32(1):68–88, 1985, §2.2「Alternating Distribution of Poles Among the Lattice Branches」** 是原始出处，**原文已核对**（论文无合法开放版本，文字取自用户复制的 Scribd 页面文本层）："the zeros of g₁(ψ) and g₂(ψ) will lie in **alternating order in the left half-plane** of the complex frequency"，且明确说该性质对 **inverse Chebyshev**、Chebyshev、Butterworth 同样成立。ψ 与 `s` 只差正实因子（ψ=(z−1)/(z+1)），故这就是按 `arg(s)` 交替。
   - 于是：把数字极点经双线性逆变换映回模拟域后按 $\arg(s)$ 排序，与数字域按 $|p|$ 排序在实测范围内**完全等价**（`arg_s_plane.py`/`arg_s_stress.py`，0/6020）。

### 3.3 最佳落地方式：跳过多项式，直取设计原型
在 C++ 工程落地中（见 `qwqdsp/include/qwqdsp/filter/parallel_allpass.hpp`）：
- **永远不要在运行时求多项式根（不要跑 Durand-Kerner 或伴随矩阵）**；
- 依据阶数与指标，直接查/算模拟低通原型的极点公式；
- 通过双线性变换映射出数字极点，并直接构造一阶/二阶全通系数。

## 四、偶数阶真的做不了吗？复系数分解与单链实信号优化

翻阅国内外大多数教材与 MATLAB `tf2ca` 文档，无一例外都写着：“阶数必须为奇数”。很多开发者因此放弃了将偶数阶滤波器（如经典的 4 阶、8 阶 Linkwitz-Riley，6 阶音频低通）改造成全通链的想法。

偶数阶真的在数学上被判死刑了吗？

### 4.1 为什么实数全通做不到偶数阶？（Nyquist 奇偶性限制）
假设阶数 $n = d_A + d_B$ 是偶数，则两条链的分母多项式阶数 $d_A$ 和 $d_B$ 必然**同奇同偶**。
由通带归一化 $H(1)=1$ 可知：在 Nyquist 极限频率 $z = -1$（即 $\omega = \pi$）处：

$$H(-1) = \frac{1}{2} \left[ g_A (-1)^{d_A} + g_B (-1)^{d_B} \right] = \pm 1$$

这意味着：**任何实系数两路全通，在 Nyquist 点的增益要么是 $+1$，要么是 $-1$！**
然而音频低通滤波器要求在 Nyquist 处深度衰减（$|H(-1)| \ll 1$）。实系数在代数上产生了根本性的矛盾。

### 4.2 破局之道：放开复系数与复权重！
实验室研究表明（详见 `even_order.md` / `even_order.py`）：如果允许全通链使用**复系数**，偶数阶低通完全可以完美分解！

$$H(z) = \alpha A_1(z) + \beta A_2(z)$$

其中：
- $A_1, A_2$ 为 $n/2$ 阶**复系数全通链**；
- $\alpha, \beta \in \mathbb{C}$ 为复数权重。

数学推导与实验证明，当令 $D_2 = \text{conj}(D_1)$（即两条链的分母系数互为共轭，极点成共轭对）时，实数低通分子**强制要求**：

$$\beta = \text{conj}(\alpha)$$

并且每对共轭极点按模长 $|p|$ 升序排列，交替取上半平面根与下半平面根给链 1，其余给链 2（bit 模式如 `0, 01, 010, 0101`）。

### 4.3 音频工程师的惊人红利：实信号只需算一条复全通链！
复系数全通看起来需要两倍的计算量，但请注意：**音频输入信号 $x[n]$ 永远是实数！**

对于实数序列 $x[n]$，由于两条链系数共轭，有恒等式：

$$A_2 * x = \text{conj}(A_1 * x)$$

将输出求和写出：

$$y[n] = \alpha (A_1 * x) + \beta (A_2 * x) = \alpha (A_1 * x) + \overline{\alpha} \, \overline{(A_1 * x)} = 2 \text{Re} \left\{ \alpha \cdot (A_1 * x)[n] \right\}$$

> **🔥 核心结论**：
> 对于任何偶数阶低通，音频开发者在实时处理中**只需要运行一条 $n/2$ 阶复系数全通链**，然后乘以复常数 $\alpha$ 并取实部，即可精准复现完整的偶数阶数字低通！
> 该结构冲激响应与传统直接实现的最大误差在 **$3.7 \times 10^{-14}$**（机器精度极限）。

## 五、解析滤波器与 IIR Hilbert 变换器原理与落地

在吉他单块移频器（Frequency Shifter）、立体声微相移（Phaser / Spatializer）、SSB（单边带调制）和动态包络检测中，我们经常需要一个能将实音频信号转换为复数解析信号的滤波器（即实部直通，虚部给出精确的 $-90^\circ$ 相移）。

传统的做法是用上百阶的 FIR 滤波器（如 Parks-McClellan），但 FIR 会带来几十毫秒的不可接受延迟。
而 `qwqdsp/include/qwqdsp/filter/iir_hilbert.hpp` 采用的是仅有极少阶数、接近零群延迟的 **IIR 并行全通解析滤波器**。

这个结构到底是怎么来的？

### 5.1 构造路线：半带椭圆 $\to$ 全通分解 $\to$ 频率旋转
整个推导链路非常精妙：

```
[半带椭圆低通原型]
(Crossover 落在 0.5 处，极点成对落在虚轴 ±j*rho 上)
        │
        ▼ 极点旋转 90 度 (z -> -jz)
[全通分解]
(复权重 alpha 辐角恰好为 45°，两条全通链天然形成 90° 相位差)
        │
        ▼ 落地为工程结构
[实系数多相全通链 + 单拍延迟]
```

### 5.2 奇阶半带与 `iir_hilbert.hpp` 代码的物理对应
在 `iir_hilbert.hpp` 中，核心代码片段如下：
```cpp
real = real0_.Tick(x); real = real1_.Tick(real); ...
imag = latch_;
latch_ = imag0_.Tick(x); latch_ = imag1_.Tick(latch_); ...
return {real, imag};
```
很多开发者会疑惑：**为什么实部链是级联直接出，而虚部链多了一个 `latch_`（单拍延时 $z^{-1}$）？这个延时是硬凑出来的吗？**

实验室在 `hilbert_odd.md` 中给出了严格的极点度数（Degree）论证：
1. **奇阶半带的有效分母阶是偶数**，极点严格呈 $\pm j\rho$ 对分布，可以两两配对合并为 $\zeta = z^{-2}$ 的多相全通节 $\frac{z^{-2} - a}{1 - a z^{-2}}$（节系数 $a = \rho^2 > 0$）；
2. 但半带分子的阶数是奇数。为了配平度数，必须写为：
   $$H(z) = \frac{1}{2} \left[ A_0(z^{-2}) + z^{-1} A_1(z^{-2}) \right]$$
3. **那个单拍延时 $z^{-1}$，本质上就是全通链 $A_1$ 落在原点 $z=0$ 的极点！**
   - 链 0 有偶数个极点（例如 4 组共 8 个极点）；
   - 链 1 有奇数个极点（例如 3 组共 6 个极点，加上原点极点 $z=0$，共 7 个极点）；
   - 两条链的极点总数恰好闭合到滤波器的总阶数 $8 + 7 = 15$。
4. 频率旋转后，$z^{-1}$ 退化为时间延迟器 `latch_`，各多相节系数全部保持正实数。

### 5.3 阻带衰减 $r_s$ 与 Hilbert 正交相位误差的刚性对应
解析滤波器的一个核心指标是**带内两路相移是否精准正交（$90^\circ$）**，以及**负频率抑制比有多高**。

在椭圆设计中，两者存在直接关联（见 `hilbert_even.md` 实测）：

$$|H_{\text{neg}}| \approx \frac{\delta}{2} \quad (\delta \text{ 为正交相位偏离 } 90^\circ \text{ 的弧度误差})$$

| 头文件类名 | 节数配置 | 带内正交偏离 | 负频抑制比 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| `IIRHilbert` | 4 节 + 4 节 | $13.27^\circ$ | 约 **-18.8 dB** | 低算力单片机、粗糙过载移相、对泄漏不敏感的调制 |
| `IIRHilbertDeeper` | 8 节 + 8 节 | **$< 0.001^\circ$** | 约 **-98.8 dB** | **专业级母带移频、高质量包络抽取、声学探测** |

> ⚠️ **幅度归一化注意**：
> 严格的解析滤波器数学定义要求正频增益为 1，此时输出需要除以 2。
> `iir_hilbert.hpp` 内部直接返回全通链原值，正频输出幅度为 2（$+6\text{ dB}$）。如果你的算法流对绝对增益敏感，外层调用需乘以 $0.5$。

### 5.4 DC 处相位差是 0° 还是 180°？
在 `hilbert_odd.md` 中揭示了一个关键数学事实：
在直流（DC, $\omega = 0$）处，两条链的相位差恒等于：

$$\Delta \theta_{\text{DC}} = 180^\circ \cdot (n_1 - n_0) = 180^\circ \cdot m \pmod{360^\circ}$$

其中 $m = (N-1)/2$ 为半带原型的极点对数。
- 当 $m$ 为偶数（如 $N=17, 33$）：DC 处相差为 $0^\circ$；
- 当 $m$ 为奇数（如 $N=15, 31$）：DC 处相差为 $180^\circ$。

这是纯粹的奇偶代数拓扑决定的，**两种情形在全频带上都是极其精准的解析滤波器**，切勿试图通过交换实虚部槽位去“修平”DC 相位（交换槽位会导致解析方向反转，正频被杀光，负频全通）。

## 六、音频工程场景选型与落地代码对照

### 6.1 场景选型决策树

```
需要什么滤波功能？
 ├─► 低通 / 高通 / 分频器 (Crossover)
 │    ├─► 想要极高效率、极低算力、零量化噪声？
 │    │    └─► 选 [并行全通滤波] (qwqdsp::ParallelAllpass / qwqdsp::ButterworthPrototype 等)
 │    │         ├─ 奇数阶：最推荐，直接输出完全互补的 LP/HP
 │    │         └─ 偶数阶：使用单复数链 + 取实部形式
 │    └─► 需要线性相位？
 │         └─► 放弃 IIR，使用对称 FIR
 │
 └─► 90 度移相 / 解析信号 / 移频 / 包络提取
      ├─► 超低延迟（几乎 0 样点延迟）、高质量负频抑制？
```
