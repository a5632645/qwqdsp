# 奇阶半带：两组 AP 链 + 延迟单元 → 频率旋转 → `iir_hilbert.hpp` 的形式

脚本：`hilbert_odd.py`（`python hilbert_odd.py`，`--check` 扫表）。本页只讲**奇阶**；
偶阶那条路线见 `hilbert_even.md`（`hilbert_even.py`，复权重 `alpha` 形式）。

## 前置结论（直接复用本目录已有结果）

- **极点分组 / 半带设计条件 / `Wn` 闭式解 / 头文件归一化** → 见 `hilbert_even.md` 与 `README.md`；
- 本页新增的只有：奇阶半带"两组 `z^-2` 实数 AP 链 + 延迟"的**精确性**（含不等分那条关键点）、
  延迟 = 链 A1 上 `z=0` 的极点、以及旋转后与 `iir_hilbert.hpp` 形式的对应。

## 一、先用两组 AP 链 + 延迟把半带原样复原（不旋转）

```
H(z) = 1/2 * [ A0(zeta) + z^-1 * A1(zeta) ]          zeta = z^-2
```

**精确成立**，权重恰好 `0.5 / 0.5`（实测）：

| N | rs | 链的 ζ 阶数 | 残差 |
|---|---|---|---|
| 9 | 30 dB | 2 + 2 | 5.1e-12 |
| 11 | 40 dB | 3 + 2 | 5.3e-11 |
| 15 | 60 dB | **4 + 3** | 1.3e-09 |
| 17 | 80 dB | 4 + 4 | 6.0e-09 |
| 21 | 60 dB | 5 + 5 | 1.8e-01（数值极限，见"数值包线"） |
| 25 | 80 dB | 7 + 5 | 5.5e-01（同上） |

**关键点：两条链的 ζ 阶数之和 = `(N-1)/2`，且可以不等**（N=15 是 4+3、N=11 是 3+2）。
早期版本只枚举"等分"，因此得到 0.71 的残差并误判"该形式不成立"——枚举补全后立刻到 1e-9 量级。

### 为什么奇阶正好长这样（degree 论证）

- 奇阶半带的 `A` 末位系数为 0（`a[-1] ~ 1e-15`）⇒ 有效分母阶是 `N-1`（**偶数**、只含 `z^-2`）
  ⇒ 极点全是 `±j*rho` 对，可两两合成 `zeta = z^-2` 节（节参数 `a = rho^2`）。
- 结构的分母 `D0(zeta)*D1(zeta)` 的 z 阶 = `N-1`；分子 `N0*D1 + z^-1*N1*D0` 的 z 阶 = `N`
  —— 与半带分子 `B` 的阶（`N`）**正好一致** ✓。其中的 **`z^-1` 就是延迟单元**，
  它负责合成 `B` 的"奇"（反对称）部分。
- **偶阶为什么不能这样**：偶阶的有效分母阶是 `N`，同样形式会让分子变成 `N+1` 阶 ✗ ——
  度数差一挡；所以偶阶走复权重形式（`H = alpha*A1 + conj(alpha)*A2`，见 `hilbert_even.md`）。

### 延迟单元 = 链 A1 上 `z=0` 的极点

那个 `z^-1` 乘在 **A1** 这一支上，所以在极点图里它是**链 A1 的一个极点（落在原点）**，
不是独立于两条链之外的部件。极点计数正好闭合到 `N`（脚本会打印）：

```
链 0：zeta 阶 4                     -> z 极点 8 个（4 组 ±rho）
链 1：zeta 阶 3                     -> z 极点 6 个（3 组 ±rho）+ 1（z=0 延迟极点）= 7 个
合计 8 + 7 = 15 = N
```

即 A0 是**偶**阶、A1 是**奇**阶，奇阶半带"多出来的那一个极点"就在 A1 上、被实现成延迟单元。

---

### 该相位差在 DC 处的取值 = 两条链阶数的奇偶（与库中 Deeper 的差异来源）

> **一句话**：`DC 相位差 = 180° · (n1 − n0)`，其中 `n0 + n1 = m = (N-1)/2`（父半带的极点对数）。
> 因为 `n1 − n0 ≡ m (mod 2)`，所以 **`m` 为偶 ⇒ DC = 0°，`m` 为奇 ⇒ DC = 180°**。
> **`m` 为奇（DC = 180°）时，在保持解析的前提下这个相位问题修不掉** —— 见本节末尾。


旋转后每条链在 DC（`z = 1`、即 `zeta = z^-2 -> -zeta = -1`）处的取值是 `(-1)^n`（`n` = 该链的 ζ 阶），
于是"两链相位差（含结构延迟）"在 DC 处 = `180° * (n1 - n0)`：

| 情形 | 链阶 `n0 + n1 = m = (N-1)/2` | DC 处相位差 |
|---|---|---|
| `iir_hilbert.hpp` 的 `IIRHilbertDeeper`（库） | 8 + 8 = 16（偶） | **0°** |
| 本脚本 N=17 | 4 + 4 = 8（偶） | **0°** |
| 本脚本 N=15 | 4 + 3 = 7（奇） | **180°** |
| 本脚本 N=9 / 13 | 2+2 / 3+3（偶） | 0° |
| 本脚本 N=11 / 19 | 3+2 / 5+4（奇） | 180° |

所以 DC 是 0 还是 180，只取决于 `m` 的奇偶（= 父半带极点对数），**不是对错问题**：两种情形都是
精确的解析滤波器（`|H|` 正频 1 / 负频 = `-rs`，与目标偏差 1e-9 量级）。

### `m` 为奇（DC = 180°）时，这个相位问题修不掉

- 乘单位模复常数只改**整体**相位，不改两条链之间的**相对**差（DC 的 0/180 是相对差）；
- 唯一的"翻转"手段 —— 把延迟换到另一个输出槽 —— 实测会得到**反解析**镜像：

| 结构（N=15） | 正频 `|H|` | 负频最大 |
|---|---|---|
| 延迟在**虚部**槽（本脚本、也是 `iir_hilbert.hpp` 的 `Tick`） | 1.00000 | **-60.00 dB = rs** |
| 延迟在**实部**槽 | 0.001 | -0.00 dB |

  原因是那等价于对系数取共轭，而系数共轭把 $w \to -w$ 镜像掉（$H \mapsto j\,\overline{H}$），
  不是相位自由度；
- 结论：**要在 DC 处得到 0°，只能选 `m` 为偶的父滤波器**（$N \equiv 1 \pmod 4$，如 N=17：
  两条链阶数相等）。给定 `m` 为奇的 N，解析方向与 DC = 0° 二者不可兼得。

## 二、频率旋转：转完就是 `iir_hilbert.hpp` 的形式

对上面那两条链做频率旋转（`zeta -> -zeta`，延迟项 `z^-1 -> j*z^-1`）：

```
H_an(z) = 1/2 * [ A0(-zeta) + j * z^-1 * A1(-zeta) ]      zeta = z^-2
        = A_real(z) + j*z^-1*A_imag(z)                    （头文件 Tick 的结构）
```

实测（N=15, rs=60 dB）：

| 量 | 结果 |
|---|---|
| 与"旋转后的半带" `H_hb(-jz)` 的最大偏差 | **1.65e-09** |
| 正频 `\|H\|` | 1.00000（0.0000 dB） |
| 负频最大 `\|H\|` | **-60.00 dB = rs** |
| 两链相位差（含结构延迟） | 两带内恒为 ±90°：正频 **-90.000 ± 0.081°**、负频 **+90.000 ± 0.081°**（符号随频带翻转） |
| 旋转后节参数 `a = rho^2` | 链0 `[0.098, 0.564, 0.861, 0.980]`、链1 `[0.327, 0.744, 0.933]`，**全为正** |

- 旋转把 ζ 极点从 `-1/rho^2` 变到 `+1/rho^2`，于是节参数 `a = -1/p = rho^2 > 0`
  —— 与 `iir_hilbert.hpp` 的 `APF` `(z^-2 - a)/(1 - a*z^-2)` **同号同形**。
- 0.081° 的残余不是 bug：它就是 `rs = 60 dB` 对应的正交误差（`delta/2 = 10^-3`），
  与负频抑制互为印证（同样关系在偶阶一侧也成立）。
- 实现上要注意：`A(-zeta)` 要**直接代自变量** `-zeta`，不能"把极点取负再评估"
  —— 后者会多出 `(-1)^n` 因子（链 1 有奇数个极点，符号一翻，本该相加的地方就变成相消）。
- 头文件的 `Tick` 输出的是这里的 **2 倍**（它没除 2），见 `hilbert_even.md` 归一化一节。

## 与 `iir_hilbert.hpp` 的对照

| 本页的构造 | 头文件里的东西 |
|---|---|
| `zeta = z^-2` 全通节 `(zeta - a)/(1 - a*zeta)`，`a = rho^2`（一个 `±rho` 对一节） | `APF`（**两个**状态，传递函数就是这个） |
| 延迟单元 `z^-1`（= 链 A1 上 `z=0` 的极点，奇阶半带特有） | `latch_`（imag 支路多走一拍） |
| 权重 `1/2` / `1/2` | `Tick` 输出 real/imag（头文件本身**不除 2**，见 `hilbert_even.md`） |

也就是说：头文件里"两组 AP 链 + 延迟单元"的形状，在**奇阶半带**这条路上是自然出现的。

## 数值包线

`N <= 17` 时残差 1e-12…1e-9；`N >= 21` 起退化（ζ 极点全部挤在 `-1` 附近，
双精度下 `np.roots` 出来的极点分离条件数不够）。要更高阶需要更高精度实现。
