# 奇阶半带：两组 zeta 全通链 + 延迟

奇阶半带低通写成

```
H(z) = 1/2 * [ A0(zeta) + z^-1 * A1(zeta) ],     zeta = z^-2
```

`A0`/`A1` 是 `zeta = z^-2` 上的实系数全通链，每个 `±rho` 对合成一个 `zeta` 节，
节参数 `a = rho^2`（与 `iir_hilbert.hpp` 的 `APF` 同形）。`z^-1` 是延迟单元。
旋转 `zeta -> -zeta` 后即解析滤波器

```
H_an(z) = 1/2 * [ A0(-zeta) + j*z^-1*A1(-zeta) ] = A_real(z) + j*z^-1*A_imag(z)
```

也就是头文件 `Tick` 的结构。偶阶半带走复权重路线，见 [hilbert_even.md](hilbert_even.md)。

## 为什么奇阶长这样

- 奇阶半带的 `A` 末位系数为 0（`a[-1] ≈ 1e-15`），有效分母阶为 `N-1`（偶数），
  只含 `z^-2`。极点全是 `±j*rho` 对，两两合成 `zeta` 节。
- 结构分母 `D0(zeta)*D1(zeta)` 的 z 阶为 `N-1`；分子 `N0*D1 + z^-1*N1*D0` 的 z 阶
  为 `N`，与半带分子 `B` 的阶一致。`z^-1` 负责合成 `B` 的反对称部分。
- 偶数阶不能这样：有效分母阶为 `N`，同形式会让分子变成 `N+1` 阶；所以偶阶走
  复权重形式。

两条链的 `zeta` 阶数之和固定为 `(N-1)/2`，且**可以不等**（N=15 是 4+3，N=11 是 3+2）。
分解必须枚举非等分；只枚举等分找不到解。

## 延迟单元 = 链 A1 上 z=0 的极点

`z^-1` 乘在 A1 支路上，所以它是链 A1 的一个极点（落在原点），不是两条链之外的部件。
极点计数正好闭合到 `N`。N=15：

```
链 0：zeta 阶 4                  -> z 极点 8 个（4 组 ±rho）
链 1：zeta 阶 3                  -> z 极点 6 个（3 组 ±rho）+ 1（z=0 延迟极点）= 7
合计 8 + 7 = 15 = N
```

A0 是偶阶、A1 是奇阶；奇阶半带“多出来的那一个极点”就在 A1 上，被实现成延迟。

## 复原数据

| N | rs | 链的 ζ 阶数 | 复原残差 | 权重 |
|---|---|---|---|---|
| 9 | 30 dB | 2 + 2 | 5.08e-12 | 0.5 / 0.5 |
| 11 | 40 dB | 3 + 2 | 5.33e-11 | 0.5 / 0.5 |
| 15 | 60 dB | 4 + 3 | 1.32e-09 | 0.5 / 0.5 |
| 17 | 80 dB | 4 + 4 | 6.01e-09 | 0.5 / 0.5 |
| 21 | 60 dB | 5 + 5 | 1.77e-01 | — |
| 25 | 80 dB | 7 + 5 | 5.53e-01 | — |

`N ≤ 17` 的复原是精确的（残差 `1e-12…1e-9`）。`N ≥ 21` 的退化来自半带设计本身的
数值包线：scipy `ellip` 在窄过渡带下失去半带不变量（`|H(0.5)|` 与功率互补），
不是 `zeta` 链分解的问题。包线见 [hilbert_even.md](hilbert_even.md) 的“数值包线”。

## DC 处的相位差：只由链阶数的奇偶决定

旋转后每条链在 DC（`z = 1`、`zeta = z^-2 -> -zeta = -1`）处的取值为 `(-1)^n`
（`n` = 该链的 `zeta` 阶）。两链（含结构延迟、不含权重 `j`）的相位差：

```
DC 相位差 = 180° * (n1 - n0)           n0 + n1 = m = (N-1)/2
          = 180° * (m - 2*n0)
```

所以 **`m` 偶 ⇒ DC = 0°，`m` 奇 ⇒ DC = 180°**：

| 情形 | 链阶 `n0 + n1 = m` | DC 相位差 |
|---|---|---|
| `IIRHilbertDeeper` | 8 + 8 = 16（偶） | 0° |
| 本构造 N=17 | 4 + 4 = 8（偶） | 0° |
| 本构造 N=15 | 4 + 3 = 7（奇） | 180° |
| 本构造 N=9 | 2 + 2（偶） | 0° |
| 本构造 N=11 | 3 + 2（奇） | 180° |

在 `N ≤ 17` 的测点上，两种情形都是精确的解析滤波器（正频 `|H| = 1`、负频 `= -rs`）。
DC 的 0/180 不是对错问题；它只取决于 `m` 的奇偶。

### `m` 为奇时修不掉

- 乘单位模复常数只改整体相位，不改两条链之间的相对差。
- 把延迟换到另一个输出槽会得到反解析镜像（N=15）：延迟在虚部槽时正频 `|H| = 1`、
  负频 `-60.00 dB = rs`；延迟在实部槽时正频 `|H| = 0.001`、负频 `-0.00 dB`。
  这等价于对系数取共轭，把 `w -> -w` 镜像掉，不是相位自由度。

因此要在 DC 处得到 0°，只能选 `m` 为偶的父滤波器，即 `N ≡ 1 (mod 4)`（例如 N=17）。

## 旋转后的实测

默认 N=15, rs=60 dB：

| 量 | 值 |
|---|---|
| 与 `H_halfband(-jz)` 的最大偏差 | 1.65e-09 |
| 正频幅度 | 1.00000（0.0000 dB） |
| 负频最大幅度 | -60.00 dB = rs |
| 两链相位差（含结构延迟） | 两带内 ±90°，正频核心段偏离 0.115° |
| 旋转后节参数 `a = rho^2` | 链0 `[0.098, 0.564, 0.861, 0.980]`、链1 `[0.327, 0.744, 0.933]`，全为正 |

0.115° 的残余就是 `rs = 60 dB` 对应的正交误差：`0.115° = 0.00201 rad`，
`0.00201/2 ≈ 0.001 = -60 dB`。旋转把 `zeta` 极点从 `-1/rho^2` 变到 `+1/rho^2`，
所以 `a = rho^2 > 0`，与头文件 `APF` 同号同形。

实现上，`A(-zeta)` 要直接代自变量 `-zeta`；不能“把极点取负再评估”，后者会多出
`(-1)^n` 因子（链 1 有奇数个极点，符号一翻会把相加变成相消）。

## 与 `iir_hilbert.hpp` 的对照

| 本文的构造 | 头文件 |
|---|---|
| `zeta = z^-2` 全通节 `(zeta - a)/(1 - a*zeta)`，`a = rho^2` | `APF`（两个状态） |
| 延迟单元 `z^-1`（链 A1 上 `z=0` 的极点） | `latch_`（`imag` 支路多走一拍） |
| 权重 `1/2` / `1/2` | `Tick` 输出 real/imag；头文件不除 2，原始输出是 2 倍 |

## 边界

- 头文件固定 alpha 表的逐值对照未做：那 16 个值全为正、量级 `0.04…0.999`，形态与
  `a = rho^2` 一致，但父设计的 `rs`/带宽未反推。
- `N ≥ 21` 需要更高精度的半带设计；当前 scipy `ellip` 路径在窄过渡带下失去半带
  不变量。
- 两条链的分配穷举 `2^m` 种（`m = (N-1)/2`）；`m > 16` 时直接报错，不做剪枝。
