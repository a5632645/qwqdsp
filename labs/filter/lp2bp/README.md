# LP2BP 椭圆带通：结构、量化噪声与速度考究

## 1. 问题

二阶模拟 SVF 低通原型为

$$
H(s)=k\frac{s^2+|z|^2}{s^2-2\Re(p)s+|p|^2},
$$

其中极点共轭成对，零点必须位于虚轴上。给定数字边沿 \(w_1<w_2\)，先做预扭曲

$$
\omega_1=\tan(w_1/2),\qquad \omega_2=\tan(w_2/2),
$$
$$
B=\omega_2-\omega_1,\qquad \omega_0^2=\omega_1\omega_2,
$$

再做 LP→BP 替换

$$
s\longmapsto \frac{s^2+\omega_0^2}{B s}.
$$

这个替换既可以作用在传递函数/零极点上，也可以作用在 SVF 信号流图的积分器上。后者是本文比较的重点。

## 2. 四种实现

### 2.1 直接结构 LP2BP

把每个积分器 \(1/s\) 替换为带通积分器

$$
H_{BI}(s)=\frac{\omega_c B s}{s^2+\omega_0^2}
=S\cdot\frac{\omega_0 s}{s^2+\omega_0^2},
\qquad S=\frac{\omega_c B}{\omega_0},
$$

其中 \(\omega_c=|p|\)。每个带通积分器由一个零阻尼 SVF 实现，产生两个状态（BP 输出 \(b\)、LP 输出 \(l\)），整个滤波器有四个 TPT 状态。外层 \(2R\) 反馈保留，ZDF 需要解一个 2×2 线性系统。

### 2.2 转置结构 LP2BP

与 2.1 同一个传递函数，但采用转置信号流：输入分别注入 HP/BP/LP 三个节点，反馈矩阵的耦合项换到另一条对角线。状态数仍是四个，同样需要 2×2 ZDF 求解。

### 2.3 两级转置 SVF 级联

先对原型零极点做 LP→BP 根映射，得到两个二阶节，再用两个转置 TPT SVF 串联。每个节独立更新，没有全局 2×2 求解；实现最简单、运算量最少。

### 2.4 TDF2 基线

把 LP→BP 后的两个模拟节双线性变换到数字域，再转成两个 TDF2 双二阶节。可选按级联峰值重新分配节增益（gain normalization）。TDF2 每个节只有两个状态，运算量最少，但直接型结构对系数舍入更敏感；窄带高 Q 时，即使只有 float 系数舍入，频响也可能出现可见偏差。

## 3. 量化噪声实验

设置：

- 椭圆低通原型：0.5 dB / 40 dB；另加 0.1 dB / 60 dB 对照。
- 频带 Q≈188、984、1871、18710。
- 白噪声输入，1–2M 采样。
- **状态量化**：各状态按参考运行峰值 +10% 缩放，量化到 \(N\) 位小数；系数保持 double。
- **系数量化**：统一 Q1.(N-1) 网格；状态保持 double。
- 误差为相对 double 参考的稳态 RMS，跳过前 20%。

“直接/转置/级联”三种 TPT 实现之间的 double 参考差约 \(10^{-15}\)，即同一传递函数。TDF2 的参考差明显更大（约 \(10^{-6}\)–\(10^{-2}\)），主要来自 `TfToBiquad` 的 float 系数舍入；增益归一化会改变这个误差的分布。

### 3.1 状态量化 SNR（16 / 20 / 24 bit，dB）

| 场景 | Q | 直接 | 转置 | 级联 | TDF2（归一化） |
|---|---:|---:|---:|---:|---:|
| 0.200–0.201π | 188 | 65.1 / 89.2 / 113.4 | 65.5 / 89.3 / 113.3 | 64.0 / 88.0 / 112.0 | 59.5 / 83.5 / 107.6 |
| 0.2000–0.2001π | 1871 | 58.5 / 82.7 / 107.3 | 57.9 / 82.4 / 107.0 | 58.1 / 83.1 / 105.4 | 51.4 / 76.5 / 101.3 |
| 0.20000–0.20001π | 18710 | 32.8 / 81.9 / 104.9 | 57.1 / 80.8 / 104.1 | 56.1 / 80.0 / 105.6 | 49.0 / 76.1 / 97.2 |
| 同上，0.1/60 dB | 18710 | 31.5 / 75.2 / 98.3 | 51.0 / 74.6 / 98.3 | 50.2 / 74.7 / 97.4 | 21.8 / 68.5 / 92.9 |

要点：

- 极端 Q、16-bit 状态时，转置结构和级联结构比直接结构高约 20–25 dB。
- TDF2 在中等 Q 下比 TPT 结构低约 5–10 dB；极端 Q 下介于直接结构和转置结构之间。
- 20/24-bit 时三种 TPT 结构之间缩小到约 1–2 dB；TDF2 通常仍低约 4–8 dB。

### 3.2 系数量化 SNR（16 / 20 / 24 bit，dB）

| 场景 | Q | 直接 | 转置 | 级联 | TDF2（归一化） |
|---|---:|---:|---:|---:|---:|
| 0.200–0.201π | 188 | 32.6 / 56.9 / 79.9 | 32.6 / 56.9 / 79.9 | 32.0 / 60.4 / 79.4 | 34.2 / 69.2 / 89.0 |
| 0.2000–0.2001π | 1871 | 23.5 / 42.7 / 65.6 | 23.5 / 42.7 / 65.6 | 13.2 / 40.6 / 59.6 | 16.7 / 50.8 / 66.1 |
| 0.20000–0.20001π | 18710 | 9.9 / 36.2 / 57.2 | 9.9 / 36.2 / 57.2 | 8.1 / 20.6 / 44.3 | 3.3 / 35.3 / 53.1 |
| 同上，0.1/60 dB | 18710 | 3.4 / 23.3 / 50.1 | 3.4 / 23.3 / 50.1 | 3.1 / 21.5 / 39.3 | 2.9 / 17.7 / 42.8 |

要点：

- 直接结构与转置结构的系数敏感度几乎完全一致。
- 级联方案在高 Q 下明显更差（24-bit 时约差 6–15 dB）。
- TDF2 在低 Q / 较高字长下系数敏感度最好；高 Q 下不如两种结构性 TPT 实现。TDF2 的 float 系数舍入本身就是窄带高 Q 设计的一个风险点。

## 4. 速度

Release、`-O3 -DNDEBUG -mavx`，每轮 512 样本，Q≈1871，10 次重复：

| 实现 | 中位时间 / 512 样本 | 吞吐 | 每样本 |
|---|---:|---:|---:|
| TDF2 级联 | 4534 ns | 113.9 M/s | 8.9 ns |
| 两级转置 SVF 级联 | 5134 ns | 100.3 M/s | 10.0 ns |
| 直接结构 LP2BP | 7770 ns | 66.5 M/s | 15.2 ns |
| 转置结构 LP2BP | 8044 ns | 64.0 M/s | 15.7 ns |

TDF2 最快；级联约慢 1.14 倍；两个结构性 LP2BP 慢约 1.7–1.8 倍。`-mavx` 对强状态依赖的标量滤波循环基本不能跨样本向量化，主要影响标量指令编码。

## 5. 结论

| 需求 | 推荐 |
|---|---|
| 固定点系数 + 高 Q，综合最稳 | **转置结构 LP2BP** |
| 只关心 16-bit 状态、极端 Q | 转置结构或两级级联；不要用直接结构 |
| 系数精度足够，速度优先 | TDF2；其次是两级级联 |
| 系数敏感度优先，状态字长 ≥18 bit | 直接结构 |
| 两级级联 | 状态噪声好，但高 Q 系数敏感度差，适合系数精度高的场景 |

设计要点：

1. 高 Q 椭圆带通优先考虑 **拓扑替换的 TPT 结构**，不要只做传递函数层面的零极点映射再级联直接型。
2. 若必须用 TDF2，务必检查窄带高 Q 下的 float 系数舍入；增益归一化能改善状态范围，但会改变系数的舍入误差分布，需要实测。
3. 直接结构与转置结构的系数敏感度相同；差别主要在状态舍入噪声。极端 Q、低状态字长时，转置结构明显更稳。
4. 两级级联是三个 LP2BP 实现里最快的，但高 Q 系数敏感度最差；只有在系数精度足够时才优先选它。

## 6. 复现

量化实验是普通 lab target，不依赖 Google Benchmark：

```text
cmake --build build --config Release --target qwqdsp-lab-lp2bp_noise
```

按 CMake 输出目录运行生成的 `qwqdsp-lab-lp2bp_noise`。

速度基准是独立实验文件，**不加入任何 CMake target**，因为 qwqdsp 本身不依赖 Google Benchmark。需要时手动编译：

```text
clang++ -std=c++20 -O3 -DNDEBUG -mavx \
  -D_DLL -D_MT -Xclang --dependent-lib=msvcrt \
  -Iqwqdsp/include -Ibenchmark/include \
  qwqdsp/labs/filter/lp2bp/bench.cpp \
  build/benchmark/src/Release/benchmark.lib -lshlwapi \
  -o lp2bp-benchmark.exe
```

运行时建议：

```text
lp2bp-benchmark --benchmark_repetitions=10 --benchmark_report_aggregates_only=true --benchmark_min_time=1s
```
